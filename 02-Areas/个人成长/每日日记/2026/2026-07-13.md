# 2026-07-13 每日日记

## 今日 AI 三块思考

今天开会从公司层面对接下来 AI 能力做了对齐。当前 AI 方向仍然偏散，公司统一希望先从 **SaaS+AI** 出发：PC 后台先添加数据解读能力，App 侧围绕导购 + 门店能力做智能辅助。

我的判断是：这个切入点务实，但不能停在“给 SaaS 加 AI 功能”。接下来必须继续研究 **AI+SaaS 的能力配合**，也就是让 AI 能调用 SaaS 的会员、商品、交易、导购、门店、营销等能力，完成“识别问题 → 给出建议 → 推动执行 → 结果回写”的闭环。

### 补充思考
晚上补充了三份 AI 方向材料：内部提效、外部赋能、元工智能与 EZR SaaS 能力结合。

今天的判断进一步清晰：
- 内部提效先打 CSM：需求助手、工单助手、知识问答助手。
- 外部赋能围绕导购、门店、品牌三个角色做场景化 Agent。
- 元工智能负责 Agent 创建、运行和编排；EZR SaaS 通过 MCP 提供租户权限、业务数据和业务操作能力。

核心主线不是“多做几个 AI 助手”，而是：

```text
SaaS+AI 先出样板
→ AI+SaaS 开放能力
→ MCP / Skill 沉淀底座
→ 品牌专属 Agent 规模化
```

### 明日要追的三个问题
1. PC 后台数据解读先选哪 3 个高频经营问题？
2. App 导购 + 门店先选哪个最小闭环：导购跟进、门店任务，还是沉默会员唤醒？
3. 哪些 SaaS 能力要优先 API 化 / Skill 化，支撑后续 AI+SaaS？
4. AI 项目是否可以按三层归类：SaaS+AI 快速落地、AI+SaaS 能力开放、Agent 平台化？
