# 2026-07-20｜每日日记

## 今日关键词

AI 项目协作方式、研发协作 Agent、内部提效、流程规范化、智能导购、SaaS 能力 Agent 化

## 今日重要思考

今天共识了 AI 项目的协作方式。这个进展比较关键：AI 不再只是个人工具使用，而是开始进入项目协作机制本身。

后续需要把协作过程中的 Agent 体系规划起来，让内部产品、研发、测试、质量、项目管理、运维可以在同一套 AI 协作框架下提效和规范化。

今天梳理出的 Agent 方向包括：
- 需求助手 Agent
- 需求评审 Agent
- 需求设计 Agent
- 开发助手 Agent
- 测试助手 Agent
- 质量管理 Agent
- 项目管理 Agent
- 运维管理 Agent

这些 Agent 覆盖项目生命周期的两个阶段：

1. 产品阶段：需求、评审、设计
2. 开发阶段：开发、测试、质量、项目管理、运维

## 今日判断

真正有价值的不是“规划很多 Agent 名称”，而是要把每个 Agent 放进真实项目流程里，明确输入、输出、知识来源、人工确认点和复盘指标。

内部协作 Agent 的建设，本质上是技术中心 AI 转型的一个抓手：
- 让需求分析更标准
- 让设计参考更可复用
- 让开发规范和历史案例更容易被调用
- 让测试 checklist 和用例生成进入流程
- 让 Bug 分析和质量复盘形成闭环
- 让项目异常和资源风险更早暴露
- 让运维告警和客户活动评估有智能辅助
