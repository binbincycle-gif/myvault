## 管理摘要

本周期确认 **1 条高置信新增信号**：Zoho 加码中国市场投入，并以 API First、MCP 连接、预置/可编排/可分发智能体为企业 AI 的产品化路径。对 EZR 的直接启示不是跟随“大而全”，而是优先把零售 CRM 的高频闭环沉淀为**可控权限、可审计、能实际执行**的 Agent Skills。

## 高置信新增动态

### 1. Zoho 加码中国市场：4.25 亿元投入 + AI/开放底座/伙伴生态并行

- **厂商**：Zoho
- **产品/能力**：Zoho CRM 与业务应用中的 Zia、Zia Agents、Agent Studio、Agent Marketplace；API First 与 MCP 外部 AI 工具连接。
- **时间**：2026-10-29（媒体报道/沟通会披露）
- **一句话摘要**：Zoho 宣布将当年中国市场投资计划由 3.5 亿元上调至 4.25 亿元，投向本地数据中心、AI、本土研发和伙伴生态，并推出预计投入 6000 万元起的“海鸥计划”；同时将 CRM 等业务系统定位为可被 AI Agent 调用、可直接执行任务的业务底座。
- **产品影响点**：
  - **用户价值**：在 CRM 内用自然语言完成客户查询、拜访摘要/录音解析回写、报价创建等跨步骤工作，减少多系统切换和重复录入。
  - **功能差异**：产品路径从单点 Copilot 转为“预置 Agent + 低代码 Agent Studio + Marketplace 分发”；MCP/API 让外部 AI 办公平台能够在权限范围内调用 CRM。
  - **商业化路径**：以本地数据中心与本土研发降低大型企业顾虑，以伙伴生态和智能体分发提高行业场景覆盖；“海鸥计划”通过使用权益、诊断、培训降低出海客户获客门槛。
- **客户案例/成交或效率信号**：报道披露，汽车零部件客户已用 Agent Studio 搭建成本预测智能体，处理关税、运输等变量导致的材料成本波动；未披露具体成交金额、付费率或效率指标。
- **定价信号**：未披露 CRM/智能体具体售价；披露“海鸥计划”预计投入 6000 万元起，属于市场投入而非产品定价。
- **是否真实上线**：**部分能力已上线/对外展示，高置信**。报道明确说明 Zia 已嵌入 CRM、邮箱、财务、客服等应用，并介绍 Zia Agents、Agent Studio、Agent Marketplace 与 MCP 连接实践；但各能力在中国区的可用范围、版本、收费方式仍需实测核验。
- **合规风险**：跨系统 Agent 访问 CRM 数据会放大越权调用、提示注入、敏感客户信息外泄与自动执行误操作风险；Zoho 表述“不拿客户数据训练通用模型”，但数据驻留、审计粒度、MCP 工具授权边界和中国区合同条款仍需逐项确认。
- **对 EZR 的产品动作建议**：
  1. **观察（本周）**：建立 Zoho 中国区 Agent 能力清单，核验 CRM 回写、报价、权限继承、MCP 接入、审计日志和计费方式，不以媒体演示替代实测。
  2. **试点（2 周）**：选服饰零售 CRM 的一个低风险闭环做 Agent MVP：`导购/客户沟通摘要 → 客户档案回写 → 待跟进任务 → 店长复核`；要求每一步可撤销、带操作日志。
  3. **决策（下个版本评审）**：把“可调用的零售业务 Skills”列为 CRM AI 的产品底座，不做泛问答。优先沉淀会员洞察、客群机会、导购跟进、活动复盘四类可量化闭环。

## 一线补采信号（下周必须回收）

1. **真实上线与采用**：目标竞品的 Agent/MCP 能力是否已在中国区客户租户开通；收集产品截图、版本号、权限模型和 1 个真实客户使用场景。
2. **商业化**：收集 AI/Agent 是否单独收费、按席位/调用量/项目收费，以及销售报价中是否作为标配或增购项出现。
3. **零售闭环效果**：针对会员运营、导购跟进、活动复盘三个场景，收集上线前后的人均处理时长、回写完整率、触达转化率或复购提升等至少一个量化指标。

## 今日 3 个产品动作

1. **增长｜定义“导购成交机会 Agent”试点包**：锁定沉睡高价值会员唤醒或到店未购跟进一个场景，输出人群规则、话术、任务回写、转化指标四件套；以 1 家服饰客户做两周验证。
2. **效率｜上线沟通摘要到 CRM 的可复核回写链路**：先覆盖导购/销售拜访记录，自动提取客户诉求、异议、下一步和标签，人工一键确认后回写，目标将录入时间降低 50%。
3. **风险控制｜补齐 Agent 操作治理最小集**：所有跨客户数据读取、批量触达、价格/权益变更必须具备权限继承、人工审批、操作日志、撤销/熔断四项能力，再扩大自动执行范围。
