## 结论
本周未发现可由厂商一手资料独立核验的、面向中国零售/CRM SaaS 的高置信重大产品新增。不要把营销稿、旧功能帮助页或二手转载计入新增。

## 值得持续跟踪的竞争面

### 1. 纷享销客：CRM 以 MCP + Skills 进入外部 Agent 平台（既有能力，仍是关键商业化信号）
- 证据：2026-09-15 帮助中心说明，纷享销客 CRM 连接器已上架 Workbuddy、千问办公、豆包工作；接入方式为 MCP + Skills。企业需开通 MCP 服务，管理员可获得 15 天试用；调用次数按工具调用计数。
- 状态：已上线/可接入；不计作本观察窗口内新增。
- 产品影响：CRM 的竞争单位从“功能页面”转向“能否安全地被外部 Agent 调用”；MCP 被单独产品化与商业化。
- 对 EZR：优先建设身份、租户、字段、数据范围实时判权下的 Skill 接口，不把会员明细复制进 Agent 记忆。
- 来源：https://help.fxiaoke.com/ee88/a823/6c9c

### 2. 有赞：连锁库存调拨的异常库存与审计能力（既有能力，反映零售执行纵深）
- 证据：有赞帮助中心说明，店间/店内调拨覆盖直营、加盟门店与仓库；支持负库存出库、后续成本回补、总部审核编辑与完整操作日志。
- 状态：帮助页显示 2026-09-14 更新，不计作本观察窗口内新增。
- 产品影响：连锁零售竞争已把“异常库存可执行 + 可追溯”做成标准能力，单纯库存可视化不足以形成差异。
- 对 EZR：智能导购/经营 Agent 若建议跨店调货，必须同时输出库存口径、审批责任、成本影响和操作审计。
- 来源：https://help.youzan.com/displaylist/detail_5_5-2-33709

## 一线本周应补采的三条信号
1. 有赞/微盟近期是否有面向会员卡、拼团、分销、限购的正式公告与灰度范围；必须拿到公告链接、上线日期、适用版本。
2. 纷享销客 MCP 是否更新了工具目录、权限粒度、套餐/调用计价；这是 CRM Agent 商业化的直接标尺。
3. 重点服饰客户是否开始为“外部 Agent 调 CRM”提出权限、审计、数据驻留要求；把真实采购条件写入 EZR 产品需求池。

## 今日产品动作
- **增长：** 选 1 个品牌做“老带新拼团/分销/限购”组合需求访谈，先验证愿付费的业务结果，不先堆营销功能。
- **效率：** 产出《EZR 可调用经营 Skill v0.1》：续费风险查询、会员跟进建议、活动复盘三项，逐项标出输入、工具、输出和回写。
- **风险：** 为每个 Agent 可执行动作补齐“谁可调用、可见数据、是否需审批、结果如何审计”四项基线。
