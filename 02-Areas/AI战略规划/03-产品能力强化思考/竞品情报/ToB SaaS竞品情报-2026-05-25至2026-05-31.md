# ToB SaaS竞品情报（近7天，产品情报版）

## 管理摘要

本期检索并核验中国国内 ToB SaaS / 零售 SaaS / CRM 相关公开来源后，发现 **2 条高置信新增产品信号**：

1. **百胜软件**于 2026-05-25 官方发布其亮相 2026 有赞春季发布会，展示 **胜券 AI + E3+ 企业智能中台**，将商品、订单、数据分析、补货调拨、VOC 洞察等零售中后台流程智能体化。
2. **纷享销客**于 2026-05-25 在官方帮助中心发布 **2026 年 05 月 AI 产品更新**，灰度开放移动端 AI 语音“边说边录”智能填单，并开放 CRM CLI 与 MCP，把 CRM、营销、服务、审批、BI、文件、日程等能力对接给 AI 客户端。

对 EZR 的判断：竞品正在从“AI 助手/分析”进入 **业务系统可被 Agent 调用 + 业务结果可回写** 阶段。百胜压的是零售中后台智能中枢，纷享压的是 CRM 能力开放协议与 AI 客户端入口；EZR 要尽快把“会员经营、导购任务、营销触达、复盘指标”做成可调用、可审计、可计费的 AI 能力包。

## 近7天高置信新增动态

### 1. 百胜软件亮相 2026 有赞春季发布会：胜券 AI + E3+ 企业智能中台强化零售智能运营

- **厂商**：百胜软件（Baison）
- **产品/能力**：胜券 AI、胜券助手、胜券商品、胜券订单、胜券有数、E3+ 企业智能中台
- **标题**：百胜软件亮相2026有赞春季发布会，胜券AI赋能零售智能运营新体验
- **一句话摘要**：百胜软件官方披露胜券 AI 解决方案与 E3+ 企业智能中台，把订单、商品、补货、调拨、VOC 洞察和经营分析等零售中后台场景通过智能体重构。
- **来源链接与时间**：
  - 官方来源：<https://www.baison.com.cn/index.php?m=home&c=View&a=index&aid=2784>
  - 官方发布时间：2026-05-25 11:29:22
  - 核验时间：2026-05-31 08:00 Asia/Shanghai
- **产品影响点**：
  - **用户价值**：覆盖新品首配、新店配货、日常补货、日常调拨、断码调拨、二次流转、AI 审单、订单全链路监控、VOC 洞察、经营分析等场景，目标是把零售中后台从经验驱动推进到数据驱动/智能决策。
  - **功能差异**：百胜更靠近 ERP / 订单 / 商品 / 仓储 / 财务 / 中台，与有赞前端全域营销、私域运营能力形成互补；若生态合作加深，会形成“前端会员营销 + 后端商品订单智能中台”的组合压力。
  - **商业化路径**：依托 E3+ 企业智能中台与 30,000+ 品牌零售客户基盘做 AI 增强模块/中台升级，并通过有赞生态合作形成联合方案。
- **建议动作**：
  - **观察**：跟踪胜券 AI 是否形成独立 SKU、标准报价、客户上线名单，以及 AI 审单/智能补货/VOC 洞察的真实效率指标。
  - **试点**：EZR 先做轻量“商品/库存/天气/节假日信号 → 会员分层 → 导购任务 → 营销触达 → 成交复盘”链路，不重做深库存，但吃掉中台信号后的成交转化价值。
  - **决策**：明确 EZR 与 ERP/中台厂商边界：EZR 不下沉重供应链，但要成为商品、库存、订单信号的会员经营执行层。
- **是否真实上线**：中高置信。官方稿明确现场展出胜券 AI 解决方案及 E3+ 企业智能中台系列产品，但仍需补充核验正式 SKU、报价、客户上线名单。
- **客户案例/定价/成交或效率信号**：
  - 官方称 E3+ 企业智能中台已服务超 30,000 家品牌零售客户，覆盖服饰时尚、日化美妆、母婴用品等消费品行业。
  - 官方提到与有赞曾于 2023 年共同打造新零售融合舱解决方案，打通全渠道数据与融合服务。
  - 本期未披露明确新增成交金额、标准定价或单客户效率提升数据。
- **合规风险**：
  - 自动补货/调拨使用天气、舆情等外部变量时，应保留决策依据、人工确认、回滚机制，避免库存策略黑箱。
  - VOC 洞察涉及客户评价、售后、会员/订单隐私数据，需要关注授权、脱敏、跨系统调用边界。
  - 与前端营销/私域系统打通时，会员身份、订单、导购行为同步必须有权限与审计闭环。
- **对 EZR 的产品动作建议**：把 CRM 定位为“中台信号的成交转化层”：接收商品/库存/订单/天气/节日信号，自动生成会员分层、导购任务、营销画布和复盘指标。

### 2. 纷享销客 2026 年 05 月 AI 产品更新：CRM CLI / MCP 开放，移动端 AI 语音填单进入灰度

- **厂商**：纷享销客（Fxiaoke）
- **产品/能力**：移动端 AI 语音智能填单“边说边录”、纷享销客 CLI、纷享销客 MCP
- **标题**：【26年05月】AI产品更新说明
- **一句话摘要**：纷享销客官方帮助中心披露 AI 产品更新，灰度开放移动端实时语音填单，并通过 CLI / MCP 将 CRM 业务能力开放给 AI 客户端自然语言调用。
- **来源链接与时间**：
  - 官方来源：<https://help.fxiaoke.com/ee88/51a7/e011>
  - 页面时间：2026-05-25
  - 核验时间：2026-05-31 08:00 Asia/Shanghai
- **产品影响点**：
  - **用户价值**：销售拜访时可边说边录，语音实时转写并自动填充 CRM 表单；官方描述单次拜访效率提升 40%，同时降低信息遗漏风险。
  - **功能差异**：纷享不只做 CRM 内部 AI 功能，而是通过 CLI / MCP 把 CRM、营销、服务、审批、BI、文件、日程等业务域封装为 AI 可调用工具，开始抢占企业 AI 客户端入口。
  - **商业化路径**：短期可能作为灰度能力提升续费与客户粘性；中期可演化为企业级 AI 连接器 / Agent 工作流 / Skill 生态的增购能力。
- **建议动作**：
  - **观察**：跟踪纷享 CLI / MCP 的权限模型、部署方式、是否收费、可调用工具清单，以及是否支持私有化/专属模型接入。
  - **试点**：EZR 立刻梳理“会员查询、导购任务、营销活动、券核销、客诉/回访、经营指标”6 类可被 Agent 调用的 API/Skill 清单，先做内部 OpenClaw 可调用样板。
  - **决策**：把 AI 能力从“页面助手”升级为“业务能力开放层”，否则未来客户可能直接在 AI 客户端里调用竞品 CRM，而不是进入 SaaS 页面。
- **是否真实上线**：中高置信。官方帮助中心显示发布状态为“灰度”，不是全量；能力说明、场景、终端和操作手册链接完整。
- **客户案例/定价/成交或效率信号**：
  - 官方披露“边说边录”可使单次拜访效率提升 40%。
  - 官方未披露客户名单、成交金额、独立定价或正式 SKU。
  - CLI 示例提到本机 OpenClaw + 飞书；MCP 示例提到 Aily 配置后可自然语言操作 CRM 系统。
- **合规风险**：
  - AI 客户端自然语言操作 CRM 数据必须有用户授权、字段级权限、操作审计、敏感数据脱敏与撤销机制。
  - 语音实时填单涉及客户需求、拜访记录和潜在个人信息，需明确录音/转写授权、存储周期和模型处理边界。
  - MCP / CLI 若开放写操作，需要区分查询、生成、修改、审批等风险等级，避免 Agent 越权操作业务数据。
- **对 EZR 的产品动作建议**：建立“EZR CRM Skill / MCP 能力地图”：先把高频只读查询与低风险生成能力开放给内部 Agent，再逐步开放需人工确认的写操作。

## 今日 3 个产品动作

1. **增长动作**：启动“AI 导购增收包”最小闭环：会员画像 + 商品/库存/券信号 + 导购话术 + 企微触达 + 成交/核销回写，先找 1 个品牌、2 个门店跑离店成交和复购样板。
2. **效率动作**：整理 EZR 可被 Agent 调用的 6 类能力清单：会员查询、导购任务、营销活动、券核销、客诉/回访、经营指标；每类先定义 3 个只读查询 + 1 个需人工确认写操作。
3. **风险控制动作**：建立 AI 操作 CRM 的权限分级：只读查询、生成建议、待确认写入、自动执行四级；所有 AI 写入动作必须记录用户、数据来源、模型/提示词版本、审批人、回滚方式。
