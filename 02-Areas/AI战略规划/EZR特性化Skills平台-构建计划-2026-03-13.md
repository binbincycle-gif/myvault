# EZR特性化Skills平台：构建计划（2026-03-13）

## 背景与目标
- 目标：将 CRM 能力从“功能交付”升级为“可被 AI 调用的 Skills 能力交付”。
- 战略方向：从 AI+SaaS 过渡到 AI应用+Token 模式。

## 技术路线（已确认）
1. 保留既有 OpenAPI 作为底层能力层。
2. 新增 Agent API 作为统一编排层。
3. 对接指标平台 API 作为统一口径层。
4. 通过 Skill Registry 对外提供可调用能力。

## 权限与安全（强约束）
- 客户端仅传 token，不接受外部传 scopes。
- 服务端按 digital employee + role 动态判权。
- 必须前置落地：
  - 租户隔离
  - 公共/私有 Skill 隔离
  - API 授权管理
  - 审计日志链路

## 关键设计原则
- 先系统设计，再反推表结构与接口实现。
- 核心平台表统一使用 `ezr_` 前缀。
- 优先保证可治理（权限、审计、计量），再扩充技能数量。

## 近期动作

3. 明确指标平台接入方式与口径一致性。
4. 确定首批可上线 Skills 与里程碑排期。
