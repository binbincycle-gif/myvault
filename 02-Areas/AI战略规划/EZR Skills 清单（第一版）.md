# EZR Skills 清单（第一版）

## 一、先说原则

这份清单的目标不是“罗列所有功能”，而是定义：

> **哪些 EZR 现有能力，值得优先封成 AI 可调用的 skill。**

判断标准只有四个：
1. 高频
2. 可标准化
3. 能形成价值闭环
4. 风险可控

## 二、Skill 分类总览

我建议第一版先分三类：

## A. 查询型 Skills
回答：**发生了什么？现在是什么状态？**

## B. 判断型 Skills
回答：**问题是什么？优先级是什么？建议怎么做？**

## C. 动作型 Skills
回答：**能不能真正往前推进一步？**

## 三、查询型 Skills（第一批优先做）

这类 skill 风险最低，最适合第一阶段先铺开。

## Q1. 查询会员画像
### 作用
返回指定会员的核心画像与最近状态

### 输入
- member_id / 手机号 / 会员标识
- 查询范围（品牌 / 门店）

### 输出
- 基本信息
- 标签
- 生命周期阶段
- 最近消费时间
- 累计消费
- 偏好摘要
- 活跃状态

### 调用角色
- 导购
- 店长
- 运营
- 管理层

### 风险级别
- **低**

## Q2. 查询会员最近行为轨迹
### 作用
查看会员近期浏览、到店、互动、购买、触达情况

### 输入
- member_id
- 时间范围（默认30天）

### 输出
- 最近行为时间线
- 最近触达记录
- 最近交易记录
- 最近互动摘要

### 调用角色
- 导购
- 运营

### 风险级别
- **低**

## Q3. 查询会员价值分层
### 作用
返回某会员或某客群的价值等级与分层标签

### 输入
- member_id / customer_group_id

### 输出
- 会员价值等级
- RFM / 类似价值分层结果
- 是否高价值 / 沉默 / 流失预警

### 调用角色
- 导购
- 店长
- 运营
- 管理层

### 风险级别
- **低**

## Q4. 查询商品信息与库存状态
### 作用
查看商品基础信息、库存、热销/滞销状态

### 输入
- product_id / sku_id / 类目条件
- 门店范围

### 输出
- 商品信息
- 价格带
- 库存状态
- 销售状态
- 热销/滞销标记

### 调用角色
- 导购
- 店长
- 运营

### 风险级别
- **低**

## Q5. 查询门店经营概况
### 作用
查看门店某个时间范围内的核心经营指标

### 输入
- store_id
- 时间范围

### 输出
- 销售额
- 客单价
- 连带率
- 复购率
- 新客/老客情况
- 活动影响摘要

### 调用角色
- 店长
- 区域负责人
- 管理层

### 风险级别
- **低**

## Q6. 查询导购会员池
### 作用
返回某导购负责会员池的规模、结构和关键状态

### 输入
- guide_id

### 输出
- 会员池数量
- 高价值会员数
- 沉默会员数
- 最近7/30天跟进情况
- 转化摘要

### 调用角色
- 导购本人
- 店长
- 管理层（按权限）

### 风险级别
- **低**

## Q7. 查询活动效果
### 作用
查看某次营销活动的执行与结果摘要

### 输入
- campaign_id
- 时间范围

### 输出
- 触达人数
- 到店人数
- 成交人数
- 转化率
- 发券核销情况
- ROI 摘要

### 调用角色
- 运营
- 管理层

### 风险级别
- **低**

## 四、判断型 Skills（第二批核心能力）

这类 skill 才开始体现 AI 差异化价值，是 Copilot 的核心层。

## J1. 识别高价值沉默会员
### 作用
找出“值得激活但最近沉默”的会员

### 输入
- 门店 / 导购 / 品牌范围
- 时间范围
- 价值筛选条件

### 输出
- 高价值沉默会员列表
- 沉默原因摘要
- 优先级排序

### 调用角色
- 导购
- 店长
- 运营

### 风险级别
- **低**

## J2. 识别流失风险会员
### 作用
识别未来有流失风险的会员

### 输入
- 品牌/门店/导购范围
- 风险模型参数（可默认）

### 输出
- 风险会员列表
- 风险等级
- 风险原因标签
- 推荐跟进行动

### 调用角色
- 导购
- 店长
- 运营

### 风险级别
- **低**

## J3. 门店经营问题诊断
### 作用
对门店经营异常做问题定位

### 输入
- store_id
- 时间范围
- 对比维度（环比/同比/区域对比）

### 输出
- 主要问题点
- 可能原因（会员 / 商品 / 导购 / 活动）
- 优先级建议

### 调用角色
- 店长
- 区域负责人
- 管理层

### 风险级别
- **低**

## J4. 商品结构诊断
### 作用
识别商品结构是否失衡，如断层、库存积压、推荐不匹配

### 输入
- store_id / category_id / 时间范围

### 输出
- 商品结构问题摘要
- 高风险商品清单
- 调整建议

### 调用角色
- 店长
- 运营
- 商品负责人

### 风险级别
- **低**

## J5. 导购优先跟进建议
### 作用
为导购生成“今天最值得跟进的人”

### 输入
- guide_id
- 时间范围
- 跟进容量（如10人）

### 输出
- 优先跟进会员列表
- 每人建议原因
- 推荐触达方向

### 调用角色
- 导购
- 店长

### 风险级别
- **低**

## J6. 营销活动方案建议
### 作用
基于历史活动、当前客群和商品情况，生成活动建议

### 输入
- 活动目标
- 客群范围
- 商品范围
- 历史活动参考

### 输出
- 活动主题建议
- 客群建议
- 商品建议
- 触达方式建议
- 风险提示

### 调用角色
- 运营
- 管理层

### 风险级别
- **中**

## J7. 管理层问题优先级排序
### 作用
对多个门店 / 多个问题做统一优先级排序

### 输入
- 区域 / 门店范围
- 时间范围
- 管理目标（增长 / 复购 / 客单）

### 输出
- TOP 问题列表
- 问题影响评估
- 优先级排序
- 建议责任归属

### 调用角色
- 管理层
- 区域负责人

### 风险级别
- **低**

## 五、动作型 Skills（第三批，开始形成闭环）

这类 skill 最接近业务闭环，也最需要权限与安全治理。

## A1. 创建导购跟进待办
### 作用
把建议动作真正变成导购待办任务

### 输入
- guide_id
- member_id 列表
- 跟进目标
- 截止时间

### 输出
- 待办任务 ID
- 分派结果
- 失败原因（如有）

### 调用角色
- 导购本人
- 店长
- 系统 Agent

### 风险级别
- **中**

## A2. 生成个性化触达话术
### 作用
根据会员画像与目标生成可直接使用的话术

### 输入
- member_id
- 场景目标（召回 / 上新 / 节日 / 关怀）
- 品牌风格要求

### 输出
- 推荐话术
- 话术版本 A/B
- 适用原因说明

### 调用角色
- 导购
- 运营

### 风险级别
- **低**

## A3. 创建客群包
### 作用
根据筛选条件创建可执行的客群名单

### 输入
- 筛选条件
- 客群名称
- 使用目标

### 输出
- 客群包 ID
- 人群数量
- 人群特征摘要

### 调用角色
- 运营
- 管理层

### 风险级别
- **中**

## A4. 创建活动草案
### 作用
将营销建议转成系统中的活动草案

### 输入
- 活动主题
- 客群范围
- 商品范围
- 时间范围
- 预算约束

### 输出
- 活动草案 ID
- 活动配置摘要
- 待审批状态

### 调用角色
- 运营
- 管理层

### 风险级别
- **中**

## A5. 提交审批流
### 作用
把高风险动作正式提交审批

### 输入
- action_type
- action_payload
- approver_id / 审批链路

### 输出
- 审批单 ID
- 当前审批状态
- 审批链信息

### 调用角色
- 运营
- 管理层
- Agent（受控）

### 风险级别
- **中**

## A6. 写回执行记录
### 作用
把 AI 推荐 / 导购动作 / 活动执行结果写回系统

### 输入
- action_id
- 执行结果
- 执行人
- 时间
- 补充备注

### 输出
- 写回结果
- 状态确认

### 调用角色
- 导购
- 店长
- 系统 Agent

### 风险级别
- **低**

## A7. 触发小范围触达
### 作用
对限定客群执行低风险触达动作

### 输入
- 客群包 ID
- 触达渠道
- 触达内容
- 触达规模限制

### 输出
- 触达任务 ID
- 发送结果
- 风险提示

### 调用角色
- 运营
- Agent（确认后）

### 风险级别
- **高（需确认/审批）**

## 六、第一批最值得优先做的 10 个 Skills

如果你下周就要开始排优先级，我建议先做这 10 个：

## 查询型（4个）
1. 查询会员画像  
2. 查询会员最近行为轨迹  
3. 查询门店经营概况  
4. 查询导购会员池  

## 判断型（4个）
5. 识别高价值沉默会员  
6. 识别流失风险会员  
7. 导购优先跟进建议  
8. 门店经营问题诊断  

## 动作型（2个）
9. 创建导购跟进待办  
10. 生成个性化触达话术  

### 为什么是这 10 个
因为它们：
- 离业务价值最近
- 风险相对可控
- 最容易支撑 **导购日常经营 Copilot** 这个 MVP

## 七、这一版清单怎么和你前面的规划衔接

## 1. 和能力地图的关系
- 能力地图定义“要开放什么能力”
- Skills 清单定义“先把哪些能力做成 AI 可调用单元”

## 2. 和安全治理图的关系
- 每个 skill 都必须挂权限与风险级别
- 动作型 skill 必须进审批 / 审计链路

## 3. 和总体架构图的关系
- Skills 是总体架构中最关键的中间层
- 上接 Copilot / Agent
- 下接 EZR 业务基础能力

## 八、我建议你下周内部就这么讲
> **我们不是先做一个大而全的 Agent，而是先把最关键的业务能力做成 skill。**  
> **skill 做出来，Copilot 就能落地；skill 体系成熟，Agent 才能真正闭环。**
