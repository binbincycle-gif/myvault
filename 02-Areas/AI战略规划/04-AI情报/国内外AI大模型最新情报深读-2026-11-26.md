# 国内外AI大模型最新情报深读｜2026-11-26

> 定位：前沿 AI 学习与感知。以厂商官方发布/文档为优先证据；已过滤无日期的榜单、营销软文及未获一手证实的传闻。

## A. 今日结论

1. **海外的主战场继续从“模型能力”移向“受控执行运行时”。** Google 将大文件按页/单元格/媒体片段读取下沉到 Gemini API；Meta 把个人 Agent 的独立虚拟机、连接器授权和重要动作确认产品化。企业 Agent 的关键能力已经是“可控地读、可控地做、可追溯”。
2. **国内的成本优势正向多模态与工具调用扩展。** DeepSeek 从 11 月 18 日起免除模型触发的服务端搜索/抓取工具费，只收工具结果进入上下文后的 token；Qwen4-Max 已进入代码 Agent 工作流并具备多模态与并行 worktree。国内模型可承担中文业务主负载，但需以真实工具链任务验证可靠性。
3. **EZR 不应押注单一模型或把 CRM 直接交给 Agent 写库。** 先建设模型路由、数据最小化、权限感知工具库和“建议—人审—写回—审计”闭环；海外模型用于脱敏的复杂文件/专业任务质量标杆，国内模型承接日常规模化负载。

## B. 重点情报

1. **[国外｜Google DeepMind｜2026-11-23] Gemini API 发布原生 file slicing controls。**
   - **能力变化：**PDF、Office/ODF、表格、音频和视频可服务端按页、工作表/单元格、时间片、内容层、分辨率加载；只按实际检查的部分计 token；适用于所有 Gemini 4 模型。
   - **企业影响：**合同、巡店视频、经营表格不再需要全量 OCR/转码/入上下文。应采用“先低成本粗定位，再对证据页高精度读取”的 Agent 模式。
   - **证据：**[Google 官方](https://blog.google/innovation-and-ai/technology/developers-tools/file-slicing-controls/)

2. **[国外｜OpenAI｜近7天主线；2026-11-17 更新] GPT-6 Sol / Luna 以成本效率扩展 Agent 与代码能力。**
   - **能力/价格：**Sol、Luna API 单价分别为输入/输出 **$2/$10**、**$0.10/$0.50 每百万 token**；较 GPT-5.6 对应模型各降 50%。官方同时称缓存输入可获得 90% 折扣，并提供缓存诊断能力。
   - **企业影响：**适合作为代码、复杂流程与高质量文本产出的质量层；应按任务价值路由，避免作为全量营销/客服默认模型。
   - **证据：**[OpenAI 官方](https://openai.com/index/introducing-gpt-6-sol-and-luna/)

3. **[国外｜Meta｜2026-11-24] Muse 在英国开放：把“可被监督的行动型 Agent”推向大众连接器生态。**
   - **能力/部署：**基于 Muse Spark，可跨连接应用和网站持续执行；每个用户有独立云端虚拟机；重要动作（邮件、购买）需批准；用户可控制连接器、访问范围和记忆，并可关闭训练使用。
   - **生态信号：**已接邮件、日历、WhatsApp、Stripe Onelink、Shop Pay 与英国零售品牌连接器。
   - **企业影响：**CRM Agent 的产品门槛已不只是对话和工具调用，而是身份隔离、细粒度授权、动作预览、长期任务与审计。
   - **证据：**[Meta 官方](https://about.fb.com/news/2026/11/introducing-muse-in-the-uk-a-personal-ai-agent-you-control/)

4. **[国外｜Google DeepMind｜2026-11-18；近7天影响持续] Gemini 4 Neon 进入 Gemini API 与企业产品。**
   - **能力/部署：**官方称其已在 Gemini API/AI Studio 及企业侧推出，主打长程 Agent 与企业多模态知识工作；需结合 file slicing、缓存与任务拆分控制长上下文成本。
   - **企业影响：**海外领先能力的有效使用方式正变成“文件处理 + 工具 + Agent 编排”，不再是把所有材料一次性塞进长上下文。
   - **证据：**[Google 官方](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-neon/)

5. **[国外｜xAI｜2026-11-11/16；近7天] Grok Bot 1.0 定位为团队级主动工作与多角色协作。**
   - **能力：**官方称 Bot 可面向团队工作、主动承担任务；后续以会计团队展示多 Bot 分工。
   - **企业影响：**“数字岗位”会包含队列、交接、职责和例外处理。CRM 写操作必须保留人工确认、幂等、回滚和责任人。
   - **证据：**[Grok Bot 1.0](https://x.ai/news/grok-bot-1-0)｜[xAI 新闻页](https://x.ai/news)

6. **[国外｜Mistral｜2026-11-05；开源生态] Mistral Large 4 开放权重。**
   - **能力/部署：**官方强调组织可检查、定制和自部署模型；开放权重为数据不出域/主权部署提供了替代路径。
   - **企业影响：**开源模型可作为私域数据场景的备选，但需额外核验许可、算力 TCO、中文、工具调用与运维安全，不能只看“模型免费”。
   - **证据：**[Mistral 官方](https://mistral.ai/news/mistral-large-4-oss/)

7. **[国外｜Anthropic｜2026-10-08 生效；安全政策趋势] Anthropic 更新使用政策，明确高风险与自主行动边界。**
   - **合规变化：**健康、金融、法律权利、生计或基础服务等高风险用途要求具备可改写建议的合格人工审核，并告知受影响者使用了 AI；对自主物理动作另要求可观察、可停止和失联安全状态。
   - **企业影响：**这与 CRM 的授信、客户权益、绩效推荐等场景直接相关：不能让 Agent 形成无申诉/无人工复核的决策链。
   - **证据：**[Anthropic 官方](https://www.anthropic.com/news/2026-usage-policy-update)

   - **企业影响：**检索型经营助手的边际成本下降；但搜索结果注入会增加 token、提示词攻击与数据泄漏面，仍须设域名白名单、内容隔离和预算阈值。
   - **证据：**[DeepSeek 模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)

## C. 对中国 ToB SaaS / CRM / EZR 的影响判断

### 增长
- **把“AI 对话”升级为“带证据的经营动作”。** 可从导购跟进建议、商机健康度、合同/经营报表精读、巡店录音质检做起；每项结论必须能回溯到原始字段、文档页或音视频片段。
- **实时语音是导购与客服副驾的下一窗口。** 但价值不在录音转写，而在实时提醒、客户画像召回、话术建议和结果写回的闭环。

### 效率
- **模型路由是最直接的降本抓手。** 日常中文分类、摘要、检索走国内成本层；跨文件高难推理、复杂代码和脱敏的国际资料走海外质量层；每月以同一脱敏任务集复测。
- **文件切片优于全量喂数。** 对合同、经营报表和巡店素材按“粗定位—证据精读—引用输出”执行，可减少 token、缩短时延，也减少无关数据出域。

### 风险
- **私域数据外流：**会员、导购聊天、合同、交易明细不能默认进入境外模型或跨境连接器；必须按租户、地区、字段敏感度路由和脱敏。
- **Agent 越权与误写：**模型不得直接决定客户权益、信用、绩效或营销触达；写 CRM 前需用户身份二次校验、操作预览、审批、幂等、回滚及审计。
- **成本与供应商漂移：**免费工具费不等于免费任务；检索结果会占 token。对模型版本、定价、退役建立台账与降级策略。
