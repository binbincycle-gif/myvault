## A. 今日结论（3条）

1. **海外主线不是单纯“模型更强”，而是 Agent 生产系统化。** OpenAI 5/27 发布 Codex 自改进税务 Agent 案例；Google Gemini API 的 Managed Agents / Antigravity 仍在近 7 天更新；Mistral、Anthropic 也都把远程沙盒、MCP、长程任务作为企业落地关键。
2. **国内主线是低成本长上下文 + 平台聚合。** DeepSeek V4 1M 上下文和极低缓存命中价继续形成成本锚；阿里百炼已把 Qwen3.7、DeepSeek V4、Kimi K2.6、GLM、MiniMax 等聚合到统一模型入口；腾讯混元向 TokenHub 迁移，国内平台化趋势更明显。
3. **对中国 ToB SaaS/CRM，下一步不是“接更多模型”，而是做模型路由、工具白名单和合规审计。** Agent 一旦能跨 CRM、企微、BI、工单、知识库执行动作，数据权限、成本、审计和回滚会成为企业客户采购门槛。

## B. 重点情报（10条）

### 1. [国外] OpenAI：Codex 驱动“自改进税务 Agent”，生产反馈进入 eval → 修复 → PR 闭环
- **厂商/模型/产品**：OpenAI Codex、Tax AI、Thrive Holdings / Crete 税务场景
- **发布时间**：2026-05-27
- **证据链接**：https://openai.com/index/building-self-improving-tax-agents-with-codex/
- **能力变化**：Codex 不只是写代码，而是把真实业务生产痕迹、专家纠错、结构化 eval、代码仓库和技能一起纳入闭环；官方案例称 Tax AI 处理 7,000 份税务申报，节省约 1/3 准备时间，草稿准确率最高 97%，吞吐提升约 50%。
- **企业部署影响**：企业 Agent 的成熟度开始用“能否从生产失败中持续学习并可验证改进”衡量，而不是 demo 问答能力。
- **对 ToB SaaS/CRM/EZR 的机会**：会员标签、导购任务、活动复盘、BUG/需求处理都可沉淀“人工修正 → 结构化错误 → eval → Agent 修复建议”的闭环。
- **风险**：生产数据进入 eval 体系时，必须脱敏、分级、可追溯；否则会把客户私域数据变成训练/评测泄露源。
- **建议动作**：为 AI 导购/AI CRM 设计“业务专家纠错记录表 + eval 样本池”，先从标签解释和导购话术两个场景试点。

- **厂商/模型/产品**：GPT-5.5、GPT-5.4、GPT-5.4 mini、GPT-Realtime-2、GPT-Image-2、Web Search、Containers

- **能力变化**：GPT-5.5 定位 coding/professional work，短上下文价格 $5 input / $0.5 cached / $30 output per 1M tokens；GPT-5.4 mini 为 $0.75 / $0.075 / $4.5；Realtime-2 支持语音/文本/图像输入，Web Search $10/1k calls，Containers 按容器资源计费。
- **企业部署影响**：OpenAI 的优势在工具生态和高复杂任务；成本结构复杂，不能作为所有 CRM 高频任务默认模型。

## C. 对中国 ToB SaaS / CRM 的影响判断

### 增长
- **AI CRM 的卖点应升级为“经营动作闭环 Agent”。** 不只是问答，而是会员洞察 → 标签解释 → 导购任务 → 触达建议 → 活动复盘 → 下一轮策略。
- **企业客户会买“可控 AI”，不是只买“聪明 AI”。** 数据不出域、权限可控、动作可审计、失败可追溯，会成为大客户 AI CRM 采购门槛。
- **国内低成本模型让 AI 能力可嵌入标准功能。** 标签解释、话术、摘要、导购建议、Bug/需求整理可以规模化，不必全部做高价增值。

### 效率
- **研发侧进入“异步 Agent + eval 验证”阶段。** OpenAI 税务 Agent 案例证明：生产纠错、eval、PR 可以形成自改进闭环；技术中心 AI Coding 也应按这个方式推进。
- **模型路由会成为 AI 成本中台。** 高频任务走 DeepSeek/Qwen；多模态走 Kimi/国内平台；复杂推理或跨系统 Agent 走 OpenAI/Claude/Gemini。
- **工具化比页面自动化更重要。** CRM 后台应把会员、标签、活动、导购、优惠券等能力封装成可授权 API/Skill，而不是让 Agent 模拟人工点页面。

### 风险
- **数据合规**：会员资料、订单、导购聊天、企微关系链属于高敏业务数据，跨境模型默认禁止或必须客户授权 + 脱敏。
- **模型路由成本**：长上下文、搜索 grounding、容器、语音、图像、视频都会产生隐形成本，必须做场景级预算。
- **私域数据外流与权限穿透**：Agent 接 CRM/企微/BI 后，越能执行，越需要审批、审计和回滚。
- **内容合规**：AI 生成营销素材、导购海报、会员触达内容应保留生成来源、模型、提示词摘要、审核人、发布时间和 AI 标识。
