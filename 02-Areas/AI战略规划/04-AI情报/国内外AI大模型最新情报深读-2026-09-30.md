# 国内外AI大模型最新情报深读｜2026-09-30

> 范围：近24小时为主，必要时回看近7天；海外优先。仅收录有明确发布日期、官方文档或一手公告支撑的信息；营销软文、无时间戳榜单已过滤。

## A. 今日结论

1. **海外竞争已从“单轮模型能力”转向“持续执行的企业 Agent 操作系统”。** OpenAI 的 Dots、Agents API 与 Anthropic 的 Claude 5.5/Cowork、Salesforce 插件，均把模型、工具、沙箱、权限、长期记忆和组织系统连接作为产品核心。
2. **实时多模态客服进入工程化阶段。** Google Gemini 3.8 Live/Live Avatar 已把低延迟音视频、异步工具调用与 97 语种切换打包到企业产品；国内 Qwen 3.8 Omni/Audio 也推进到实时音视频、远程 MCP 与函数调用，能力差距从“有没有”转为稳定性、生态和数据治理。
3. **国内可作为主力生产路由，海外保留高难任务能力池。** 国内旗舰模型普遍提供 1M 上下文、工具调用与更低 Token 成本；但跨境、复杂自主执行和 SaaS 生态插件方面，OpenAI/Anthropic/Google 的产品化更领先。对 CRM，最优解不是单模型押注，而是“国内数据域优先 + 可切换多模型路由 + 人审/审计闭环”。

1. **[国外｜09-29] OpenAI 发布 Dots：面向持续工作的常驻 Agent。** Dots 由 GPT-6 Astra 驱动，拥有独立云电脑、可跨 ChatGPT/Slack/Teams 工作，并可连接 4,000+ 应用；企业方向将提供带独立身份、凭据与系统集成的 specialist dots。其默认“主动研究”采用只读工具，敏感行为依赖审批、活动视图和自定义规则。
   - 能力：长程任务、浏览器/应用操作、跨渠道上下文、云端执行、权限与审批。

## 国外 vs 国内：能力与部署对照

| 维度 | 国外头部厂商 | 国内头部厂商 | 管理判断 |
|---|---|---|---|
| 核心差异 | OpenAI/Anthropic/Google 已把模型包装成企业 Agent 工作台、插件和托管运行时 | Qwen/DeepSeek/GLM 等快速补齐 1M 上下文、视觉/音视频、MCP、工具调用 | 海外强在产品/生态闭环；国内强在本地可用性、成本和数据域选择 |
| Agent | OpenAI：托管 Agent API、沙箱、子 Agent；Anthropic：Cowork/插件；Google：实时并行工具调用 | Qwen：远程 MCP、Function Calling；决策模型可用于路由和校验；国内长程 Agent 模型供给丰富 | 生产系统需自建任务编排、审批与审计，不能把闭环完全交给供应商 |
| 多模态 | Google 的实时视频数字人与 97 语种切换更产品化；OpenAI 偏常驻执行 | Qwen 实时音视频、语音、视觉模型形成较完整供给 | 客服/导购先在低风险“辅助模式”试点，避免直接自动承诺或改写客户数据 |

## C. 对中国 ToB SaaS / CRM / EZR 的影响判断

### 增长
- **销售 Agent 从“问答助手”进入“工作流竞争”。** Claude 已把 Salesforce 的客户、商机、预测和仪表盘纳入对话型操作；EZR 的机会不是复刻聊天框，而是把品牌经营数据、导购行为、活动、会员、交易及私域触达封装成可授权的经营技能。
- **实时多模态可升级导购与服务。** 国内 Qwen 与 Google 都在把语音、视觉和工具调用融合。短期可落地“门店巡检语音记录—自动结构化—任务派发”“导购训练陪练”“售后图文初判”，而非直接做高成本数字人项目。

### 效率
- **建立分层模型路由即可快速降本。** 国内模型承接中文 RAG、批量摘要、工单分类、质检、报表初稿；复杂代码、跨语种策略研究、长程自主任务可按需调用海外高端模型或在隔离环境中完成。
- **把上下文与工具成本当作 FinOps 管。** 使用缓存、批量、短上下文检索和任务级预算；将“Token、工具调用、重试、人工接管率、任务完成率”纳入统一看板。

### 风险
- **私域数据外流与越权执行。** 常驻 Agent、插件与浏览器操作会放大数据越界风险；联系人、会话、订单、导购绩效等必须最小权限、字段脱敏、按租户隔离，写操作强制审批。
- **模型版本漂移和供应商锁定。** 百度已出现明确退役窗口；任何“latest”模型、平台插件和自动升级都需版本钉扎、回归评测、可回滚的路由层。
- **合规与内容标识。** 语音复刻、数字人、音视频生成需取得授权并留存；生成内容、自动营销触达、跨境数据处理与审计责任不能由模型厂商替代。
