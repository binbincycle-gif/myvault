## A. 今日结论

1. **海外竞争焦点由“模型能力”继续转向“企业级 Agent 分发与治理”。** OpenAI 进入 Google Cloud Model Garden，且 Agents API 将上下文压缩、工具检索、子 Agent 与沙箱做成托管能力；模型路由和运行环境正成为新控制面。
2. **国内的实际生产优势仍是“1M 上下文 + 多模态 + 工具调用 + 更灵活的缓存/批处理价格”。** 阿里云百炼的 Qwen Flash 定价文档已体现长上下文、Batch 半价和缓存折扣；DeepSeek Flash 的版本升级在腾讯云等平台快速跟进。适合先承接中国企业的高频、数据敏感工作流。
3. **ToB Agent 上线的核心风险已从“回答错”升级为“动作越权”。** Anthropic 已针对长时自主工作、健康/金融高风险用例及自主物理动作收紧规则；CRM 场景同样要把工具权限、人工审批、审计回放和可停止性前置。

## C. 对中国 ToB SaaS/CRM/EZR 的影响判断

### 增长
- 将“客户档案 + 导购会话 + 商品素材 + 活动复盘 + 知识库”整合为经营 Copilot，输出必须落到**可执行的下一步建议**、预期收益和依据，而不是泛问答。
- 结合多模型路由推出可配置 AI 能力包：高频轻量任务走低成本国内模型；跨文档策略、复杂代码/分析任务走高能力模型，并向客户透明展示数据范围与执行边界。

### 效率
- 本周可优先用 Batch/缓存改造三个高频任务：工单分流、导购对话摘要、标签补全/知识清洗；以人工接管率和单任务总成本决定扩量。
- 建立统一模型适配层：记录模型、版本、区域、输入输出 token、工具调用、耗时、失败原因与回退路径，避免模型 API 更新造成不可见回归。

### 风险
- **私域数据外流**：会员信息、会话、交易和导购绩效不能无脱敏直传；跨境模型要有单独数据路由与审批。
- **越权与误操作**：模型不得直接导出客户、修改价格/权益、批量发券或外呼；必须通过最小权限工具、人工确认、幂等与可撤销机制。
- **供应商与成本漂移**：同一模型 ID 更新、工具价格调整、区域可用性变化都会改变效果和预算；要有金标集、成本预算、限流与降级。

## D. 今日可执行动作

1. **建 Agent 上线门禁（本周完成 v1）**：数据分级、模型路由、工具白名单、人工审批、停止开关、任务预算、日志回放设为统一准入项；先覆盖“知识问答/摘要/查询”三类低风险任务。
2. **做 100 条脱敏样本的多模型 A/B**：选择 DeepSeek Flash、Qwen Flash 与一个海外模型，测试知识问答、导购建议、工单分流和代码辅助；统一比较准确率、引用完整率、越权率、P95 时延、人工接管率、单任务总成本。
3. **把版本漂移纳入运维**：对所有生产调用记录模型 ID、公告日期和实际输出；每次供应商更新后自动跑回归集，未达阈值即回退到稳定版本/替代路由。
