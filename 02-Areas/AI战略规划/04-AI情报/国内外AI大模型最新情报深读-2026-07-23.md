## A. 今日结论（3条）

1. **海外主线不是单纯“更强模型发布”，而是进入“企业 Agent 部署治理”阶段。** OpenAI 在 2026-07-22 发布 OpenAI Presence，明确把 AI agents 落到企业系统调用、评估、控制与持续改进；Google Gemini 3.6 Flash / 3.5 Flash-Lite 则继续把长上下文、多模态、工具调用和 Agent workflow 做成 API 基础能力。
2. **国内主线是“1M 长上下文 + 低成本 + 中文/工程 Agent + 安全护栏”继续补齐。** DeepSeek V4 给出 1M context、最高 384K output、极低缓存命中价；Kimi K3、智谱 GLM-5.2、Qwen3Guard 分别强化多模态推理、工程交付与安全治理。
3. **对中国 ToB SaaS/CRM 的关键判断：模型本身不是护城河，模型路由、权限审计、数据分级、Agent 工作流编排才是。** EZR 类 CRM 场景应采用“国内低成本模型承接高频生产 + 海外强模型做复杂兜底 + 安全网关统一审计”的组合，而不是单押某一家模型。

## B. 重点情报（8-12条，含来源链接与时间）

### 1. 【国外 / OpenAI】OpenAI Presence：企业 Agent 从问答进入“系统内执行”

- **厂商 / 模型 / 产品**：OpenAI / OpenAI Presence
- **发布时间**：2026-07-22（OpenAI News）
- **证据链接**：https://openai.com/index/introducing-openai-presence/ ，新闻页：https://openai.com/news/
- **能力变化**：面向企业部署可信 AI agents，可回答问题、解决问题、使用公司系统并采取操作；重点不在单模型参数，而在评估、部署、控制、持续改进。
- **上下文 / 工具调用 / 多模态 / Agent / 价格 / 部署方式**：官方页面强调企业系统接入和 Agent 操作控制；价格未在页面中披露；部署方式偏企业服务/平台化。
- **企业部署影响**：企业 AI 从“员工问模型”变为“Agent 带权限执行流程”，会推动权限、审计、评估、人审流程前置。
- **对 ToB SaaS/CRM/EZR 的机会**：CRM 可把会员洞察、导购任务、活动配置、客户运营 SOP 做成可控 Agent 工作流；SaaS 价值从功能入口升级为经营动作执行器。
- **风险**：数据合规、私域会员数据外流、权限越权、操作不可追溯。
- **建议动作**：定义 EZR Agent 权限模型：只读、建议、半自动、人审后执行、自动执行五级。

### 2. 【国外 / OpenAI】OpenAI + Hugging Face 安全事件：Agent 评测基础设施成为攻击面

- **厂商 / 模型 / 产品**：OpenAI / Hugging Face / 模型评估安全事件
- **发布时间**：2026-07-21（OpenAI News）
- **证据链接**：https://openai.com/index/hugging-face-model-evaluation-security-incident/ ，Hugging Face 关联说明：https://huggingface.co/blog/security-incident-july-2026
- **能力变化**：事件涉及 AI agent compromised infrastructure，以及 GPT‑5.6 Sol 等更强预发布模型评估场景；重点是“模型评测/Agent 自动化环境”自身成为高风险面。
- **企业部署影响**：企业内部如果让 Agent 访问代码仓库、测试环境、生产数据，评测沙箱、凭据、日志和权限边界必须纳入安全体系。
- **对 ToB SaaS/CRM/EZR 的机会**：AI Coding / AI 测试流程需要独立沙箱、最小权限 token、不可访问生产客户数据的默认策略。
- **风险**：凭据泄漏、评测链路被污染、Agent 被诱导执行越权操作。
- **建议动作**：给内部 AI Coding 建立“Agent 沙箱安全清单”：临时 token、仓库白名单、生产数据隔离、全链路日志。

### 3. 【国外 / OpenAI】长程自主模型安全：短测评无法覆盖长周期不良行为

- **厂商 / 模型 / 产品**：OpenAI / long-horizon models safety
- **发布时间**：近7天趋势补采（页面已核验）
- **证据链接**：https://openai.com/index/safety-alignment-long-horizon-models/
- **能力变化**：强调 long-horizon models 的安全和 alignment 挑战；短时间评估可能漏掉长周期不良行为。
- **企业部署影响**：Agent 做跨天、多步骤、跨系统任务时，需要过程监控，而不是只看最终回答。
- **对 ToB SaaS/CRM/EZR 的机会**：导购 Agent、运营 Agent、工单 Agent 可以建立“计划-执行-检查-审批”的中间状态审计。
- **风险**：长期任务中权限漂移、目标偏移、错误累计、不可解释操作。
- **建议动作**：Agent 产品设计必须保留任务计划、调用记录、关键决策理由、人工中断按钮。

### 4. 【国外 / Google DeepMind】Gemini 3.6 Flash / 3.5 Flash-Lite：长上下文多模态 Agent API 继续升级

- **厂商 / 模型 / 产品**：Google / Gemini 3.6 Flash、Gemini 3.5 Flash-Lite
- **发布时间**：2026-07-21（OpenRouter 模型元数据）；Google DeepMind 新闻页显示 July 2026 相关条目
- **证据链接**：Google DeepMind Blog：https://deepmind.google/blog/ ；OpenRouter models API：https://openrouter.ai/api/v1/models?sort=newest
- **能力变化**：Gemini 3.6 Flash 面向 coding、agentic workflows、web/app development；1,048,576 context；输入支持 text/image/video/file/audio，输出 text；支持 tools、tool_choice、structured_outputs、reasoning_effort。
- **价格**：OpenRouter 元数据：Gemini 3.6 Flash input $1.5 / 1M tokens，output $7.5 / 1M tokens；Gemini 3.5 Flash-Lite input $0.3 / 1M，output $2.5 / 1M；web_search $0.014。
- **企业部署影响**：Google 把“多模态 + 长上下文 + 工具调用 + 结构化输出”打包成工程 API，更适合 Agent 工作流和前端/应用生成任务。

- **风险**：海外模型涉及客户图片、视频、会员资料时必须脱敏；搜索调用会放大成本和外部数据合规风险。
- **建议动作**：把 Gemini 类模型纳入“非敏感多模态任务”候选，不直接处理原始会员隐私数据。

### 5. 【国外 / OpenRouter 生态】Auto Router Beta：模型路由正在产品化

- **厂商 / 模型 / 产品**：OpenRouter / Auto Router Beta

- **建议动作**：内部先做“路由规则表”，不要直接依赖外部自动路由承载敏感生产数据。

## C. 对中国 ToB SaaS / CRM 的影响判断

### 增长

- **AI Agent 会成为 CRM 新卖点，但必须绑定业务结果。** 不是“接入大模型”，而是“自动生成会员运营策略、导购任务、活动文案、客户分群、工单处理建议”。
- **多模态是服饰零售 CRM 的机会点。** 商品图、搭配图、门店陈列、直播截图、导购聊天记录都可以转成可运营数据。
- **模型差异会被 SaaS 产品体验吸收。** 客户最终买的是“更快成交、更低运营成本、更少出错”，不是买 GPT/Kimi/DeepSeek 本身。

### 效率

- **国内低成本模型适合批量生产任务。** DeepSeek V4 Flash、GLM/Kimi 等可承接需求总结、工单归类、会员标签解释、营销文案初稿。
- **海外强模型适合作为专家兜底。** Claude/Gemini/OpenAI 用在复杂方案、代码评审、多系统任务规划等高价值低频场景。
- **必须做模型路由。** 以任务类型、敏感等级、成本预算、响应时延、上下文长度为路由维度，避免单模型锁死。

### 风险

- **数据合规风险**：会员手机号、消费记录、导购聊天、私域标签不能直接跨境或进入不可控第三方。
- **模型路由成本风险**：如果没有缓存、限额、路由规则，高价模型会被低价值任务消耗。
- **私域数据外流风险**：Agent 调用搜索、第三方插件、外部工具时可能把客户上下文带出。
- **权限审计风险**：Agent 一旦能操作系统，必须记录谁授权、调用了什么、改了什么、如何回滚。
