# 国内外AI大模型最新情报深读（管理层版）

> 覆盖窗口：2026-11-11 至 2026-11-18（海外优先）；仅保留有明确发布日期和可核查来源的内容。营销软文、无日期榜单和未经证实的参数均已过滤或降级标注。

## A. 今日结论

1. **竞争焦点已经从“单模型能力”转到“多模型 Agent 编排 + 企业业务插件”。** Google 以 Carbon/Argon 负责深推理、Hydrogen 负责高频执行，并提供自动编排；OpenAI 则将 CRM、会议、销售外联和报价工具接入 ChatGPT for Sales。模型本身正在退居底层，业务闭环和权限控制成为上层产品的胜负手。
2. **国内模型在“兼容协议、中文/本地云部署、成本”上可成为企业生产主力；但旗舰预览版仍不能直接承担核心线上链路。** Qwen4-Max 预览已具备多模态输入、深度思考、Function Calling、联网/网页抓取/代码解释器及 OpenAI/Anthropic 协议兼容，但窗口、参数、正式按量价格尚未披露，且 11 月 25 日下线预览 ID。
3. **CRM 场景迎来“销售 Agent 产品化”窗口，但数据治理将决定能否规模化。** 机会不在做通用聊天框，而在把客户、商机、通话、行为、知识库和工作流组合为“有边界、可审计、需人工确认”的任务型 Agent；跨境/私域数据、插件越权、模型退役与成本波动必须预置治理能力。

## B. 重点情报

### 1. 【国外｜OpenAI】ChatGPT for Sales 把销售工作流做成插件化 Agent 入口
- **时间：2026-11-17**
- **事实：** OpenAI 发布 ChatGPT for Sales，含 Sales plugin 和 30+ 新增/增强伙伴插件；连接 Salesforce、HubSpot、Close CRM、monday CRM、Gong、Outreach、Salesloft、DocuSign、ServiceNow CPQ 等。其 always-on `dot` 可基于相同插件与客户上下文，持续准备会议简报、跟踪商机变化并提出下一步建议，仍强调人工审核后执行。
- **能力变化：** 从单点 Copilot 转向“账户筛选—会前准备—跟进—管道风险—报价/合同”的跨系统任务链；核心差异是连接器和业务技能，而非单一模型参数。
- **对企业部署影响：** CRM 连接器、对象级权限、动作级审批、数据留存/审计成为采购与落地前置条件。
- **证据：** [OpenAI 官方](https://openai.com/index/introducing-chatgpt-for-sales/)

### 2. 【国外｜Google DeepMind】Gemini 4 Hydrogen：百万上下文、面向高频 Agent 执行
- **时间：2026-11-12 发布；11-16 更新**
- **事实：** Google 发布 Gemini 4 Hydrogen，定位为快速、经济的日常编码和 Agent 工作流模型，进入 Gemini API、AI Studio、Gemini for business、Gemini App、Search 等。价格为 **$1.50/百万输入 Token、$7.50/百万输出 Token**，覆盖整个 **100 万 Token 上下文**；支持不同 thinking 等级。
- **能力变化：** Google 把深推理（Carbon/Argon）与执行（Hydrogen）拆层，而非“一把梭”使用最贵模型。
- **生态动作：** Antigravity Orchestrator 在同一会话动态调度 Carbon/Hydrogen；Google 披露其测试中相对仅用 Carbon，平均少用 24% 配额、完成快 19%。
- **证据：** [Google 官方发布](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-hydrogen/)

### 3. 【国外｜Google DeepMind】Gemini 4 Carbon 的价位给出“高能力模型常态价”信号
- **时间：2026-11-10（官方页面显示；优惠期至 11-30）**
- **事实：** Gemini 4 Carbon 公布在优惠结束后价格为 **$4/百万输入、$20/百万输出 Token**；经 Gemini API 提供。与 Hydrogen 的 $1.5/$7.5 形成“规划/难推理 vs 大规模执行”的明显分层。
- **判断：** 对 SaaS 的最佳实践是按任务难度、价值和风险路由，而不是按用户等级静态分配模型。
- **证据：** [Google 官方](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-carbon-now-available/)

### 5. 【国外｜OpenAI】销售 Agent 的平台化路线比“模型新版本”更影响 CRM
- **时间：2026-11-17**
- **事实：** 同一 ChatGPT for Sales 发布显示 OpenAI 正把插件、客户上下文、web research、会议纪要、CPQ/合同连接到销售操作界面，并让 `dot` 处理跨会话的持续跟进。
- **能力维度：** Agent=任务编排+工具调用+客户上下文+持续状态；并非仅由更长上下文窗口实现。
- **对 EZR 的机会：** 可以把“商机健康度、门店/导购行为、客户沟通摘要、下一步建议、营销触发”封装为受限技能包，与 CRM 权限体系原生绑定。
- **证据：** [OpenAI 官方](https://openai.com/index/introducing-chatgpt-for-sales/)

### 6. 【国内｜阿里/Qwen】Qwen4-Max 预览：多模态、工具调用和双协议兼容，适合做能力验证
- **时间：2026-11-11；预览至 11-25 24:00（UTC+8）**
- **事实：** `qwen4-max-preview`/`qwen4.0-max-preview` 首发 Token Plan；支持文本、图像、视频输入与文本输出，支持深度思考、Function Calling、联网搜索、网页抓取、代码解释器、JSON Object/JSON Schema；兼容 OpenAI 与 Anthropic API 协议。
- **价格/部署：** 当前仅 Token Plan，限时优惠；**官方尚未披露**参数规模、上下文窗口、正式版按量 API 价格、基准成绩、开源计划。预览 ID 到期下线，不宜承载不可中断生产业务。
- **对企业部署影响：** 可快速做协议适配和场景 Benchmark；模型名、Key、计费、回退策略必须配置化，不能硬编码。
- **证据：** [阿里云开发者社区梳理（含未披露项说明）](https://developer.aliyun.com/article/1782128)；[百炼产品页](https://www.aliyun.com/product/bailian)

## C. 对中国 ToB SaaS/CRM 的影响判断

### 增长
- **销售 Agent 可成为 CRM 增购能力。** 将“商机风险预警、会前账户简报、跟进草稿、导购触达建议、营销素材生成、门店问题归因”打包为按角色/场景收费的智能工作台，而非免费聊天入口。
- **差异化来自行业上下文。** OpenAI 的通用销售插件表明底座会快速商品化；EZR 的护城河应是服饰零售的会员、导购、门店、货品、活动和私域运营信号的结构化资产与指标口径。

### 效率
- **采用“强模型规划 + 快模型执行”双层路由。** 高价值任务（复杂分析、策略、异常归因）用强模型；抽取、摘要、标签、批量草稿用快模型。先在 3 个真实工作流测量任务成功率、人工修改率、端到端成本和时延。
- **统一协议降低试错成本。** Qwen4 的 OpenAI/Anthropic 协议兼容提供了接入便利，但必须通过 EZR 自建网关统一模型名、密钥、配额、日志、内容安全和回退策略。

### 风险
- **私域数据外流：** 客户画像、聊天记录、导购行为、合同与会员数据必须最小化出域；输出前做脱敏、租户隔离、字段级授权和跨境路由控制。
- **权限与越权执行：** Agent 对 CRM 的写入、发送、导出、删改应采用“读可自动、写需确认、高风险双人审批”；每一步保存模型版本、上下文摘要、工具参数和操作者。
- **成本和供应连续性：** Qwen4 预览 ID 将下线，xAI 已有模型退役案例；绝不将模型 ID 写死在业务代码。建立版本白名单、灰度、自动 fallback 和月度成本告警。

## 对 EZR 的影响（单独提炼）

1. **产品：** 把“销售/导购 Agent”嵌入现有 CRM：客户 360、商机、任务、营销、门店运营五个对象先做受限技能包；Agent 只建议和生成草稿，首阶段不自动外发。
2. **平台：** 建设 EZR Model Gateway：模型路由、租户额度、敏感字段脱敏、区域策略、工具权限、审计追溯、A/B Benchmark、故障回退为统一能力。
3. **商业：** 面向服饰品牌把“行业动作结果”定价，而不是卖 Token：例如商机复活率、会后跟进覆盖率、导购任务完成率、活动触达转化提升。

## D. 今日可执行动作（3条）

1. **本周完成“销售 Agent POC”任务基准。** 选 20 条脱敏历史商机，跑账户简报、风险识别、会后纪要转任务、跟进草稿四项；对比强模型/快模型/国内模型，记录成功率、人工修改率、单任务成本和时延。
2. **本周建立模型网关最小规范。** 模型 ID 配置化；设默认/高能力/国内合规/降级四类路由；所有工具调用记录租户、用户、权限、模型版本、输入摘要、输出、审批和执行结果。
3. **11 月 25 日前完成 Qwen4-Max 预览验证。** 仅使用脱敏样本测试多模态理解、JSON Schema、Function Calling 与协议兼容；不接入核心生产链路，并在预览结束前形成是否跟进正式版的评估报告。
