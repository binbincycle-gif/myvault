## A. 今日结论（3条）

1. **近24小时没有确认级“新旗舰模型发布”，但近7天趋势很清楚：海外从模型能力竞争转向企业 Agent 治理与工作流入口竞争。** OpenAI 侧强调模型族分层、成功任务成本、Spend Controls、Computer Use / connectors / approved context；Mistral 把 Prompt / Skill 做成可版本化、可审计、可回滚的资产；Google 继续把 Gemini API 文档体系扩展到 Interactions API、Agents、Computer Use、Deep Research、Live API。

2. **国内模型的确定性优势集中在“长上下文 + 中文/工程 Agent + 低价专用模型 + 安全护栏”。** 智谱 GLM-5.2 与 Kimi K3 都进入 1M 上下文和工具调用能力区间；Qwen3Guard 补齐实时安全检测；Qwen-MT 代表低价专用模型路线。对中国 ToB SaaS 来说，国内模型更适合作为“可控、低成本、可本地化”的企业 AI 底座之一。

3. **CRM/私域场景的胜负点不是接入哪个最强模型，而是能否把模型变成可治理的业务能力。** Agent 一旦触达会员资料、优惠券、导购任务、群发消息和订单售后，核心门槛会变成：权限继承、动作审批、审计日志、Prompt/Skill 版本管理、模型路由成本与数据不外流策略。

## C. 对中国 ToB SaaS / CRM 的影响判断

### 增长

1. **AI 产品包装应从“功能点”升级为“行业 Agent 工作流包”。** 推荐优先包装：活动复盘 Agent、会员分层 Agent、导购任务 Agent、客户成功周报 Agent、商品/活动文案 Agent。
2. **垂直数据和行业流程是对抗通用入口的护城河。** Microsoft / Google 会抢企业入口，但不掌握服饰零售会员、导购、私域、活动转化和客户经营细节。
3. **多语言和跨境品牌是可较快验证的新增长场景。** Qwen-MT 等低价专用模型可支持商品文案、导购话术、活动内容、客服知识库多语言化。

### 效率

1. **AI Coding 可进入“项目级上下文”试点。** GLM-5.2 / Kimi K3 适合做 PRD 理解、影响面分析、测试用例生成、回归清单、代码评审。
2. **Prompt/Skill 需要资产化治理。** 借鉴 Mistral：业务专家维护规则，技术侧负责版本、评测、审批、灰度、回滚。
3. **模型路由是降本关键。** 旗舰模型做复杂推理，轻量/专用模型做分类、翻译、摘要、质检，安全模型做护栏。

### 风险

1. **数据合规：** 会员手机号、消费记录、导购跟进、订单售后必须做脱敏、权限继承、供应商边界控制。
2. **模型路由成本：** 长上下文输出价格高，若没有缓存/摘要层/任务验收，会出现 AI 成本失控。
3. **私域数据外流：** Agent 读取网页、邮件、文件、工具返回时，prompt injection 可能诱导泄露客户资料。
4. **权限审计：** 营销券、标签、群发、订单类动作必须默认进入审批，不允许模型直接执行高风险操作。
