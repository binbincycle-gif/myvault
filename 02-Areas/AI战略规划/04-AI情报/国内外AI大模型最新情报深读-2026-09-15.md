# 国内外AI大模型最新情报深读｜管理层版

> **情报窗口**：截至 2026-09-15 08:10（Asia/Shanghai），海外优先。优先采用厂商官网、开发者文档与官方云目录；当官网未清晰展示发布时间时，仅作为“截至抓取仍有效的能力/产品状态”，不包装成当日新品。近24小时未检到足以改变模型选型的、可独立核验的国内重大新品公告，故补充近7天已验证的变化。

## A. 今日结论

1. **海外竞争焦点是可执行 Agent，而非单一文本能力。** Google 将 Gemini 3.8 Flash 定位到 agentic workflow/cyber；Anthropic 通过收购 Vercept 加码 computer use；xAI 把实时语音、推理和工具调用合并。企业要把核心建设放在工作流、权限与审计，而不是绑定单一模型。
2. **国内供给的实际优势仍是：1M 长上下文、接口兼容、低成本和本地合规路径。** DeepSeek-V4.1-Flash、Kimi K3、GLM-5.3 适合高频中文知识与流程任务；复杂跨系统任务再升级到海外强模型或国内高阶模型。
3. **CRM 的关键风险已从“答错”升级为“做错”。** 电脑操作、语音 Agent 和工具调用进入生产化，私域数据外流、越权查询/导出、群发/发券/改价误执行必须以分级授权、审批、留痕与可回滚控制。

## B. 重点情报（海外优先）

### 1. [国外｜Google DeepMind] Gemini 3.8 Flash / Flash Cyber：Agent 与安全能力继续产品化
- **时间**：2026-09-01（Google 模型栏目索引）；本期核验：2026-09-15。
- **证据**：[Google 官方模型栏目](https://blog.google/innovation-and-ai/models-and-research/gemini-models/)
- **能力变化**：Gemini 3.8 Flash 定位为面向 agentic workflows 的高效率模型；Flash Cyber 面向网络安全工作流。官方标题明确指向“next-generation intelligence for agentic workflows and cybersecurity”。
- **企业部署影响**：海外工作流可把其作为高并发 Agent/代码任务候选；涉及企业数据须单独核验地区、账户边界和跨境传输。

### 2. [国外｜Anthropic] 收购 Vercept，强化 Claude 的 computer use 路线
- **时间**：官方公告本期可访问；公告未在正文展示固定日期，按“当前有效战略动作”记录。
- **证据**：[Anthropic 官方公告](https://www.anthropic.com/news/acquires-vercept)
- **能力变化**：Vercept 团队聚焦视觉感知与软件交互，直接服务于 Claude 在真实应用中完成多步骤任务。公告称 Claude Sonnet 4.6 在 OSWorld computer-use 评测达 72.5%，接近处理复杂表格、跨浏览器表单等任务的人类水平。
- **企业部署影响**：无 API 的旧系统也可能被 Agent 操作；但这恰恰要求对浏览器、桌面应用、下载上传与写操作实行最小权限和逐级确认。

### 3. [国外｜xAI] Grok Voice Think Fast 2.0：实时语音 + 推理 + 工具调用趋于一体化
- **时间**：2026-08-05 生效迁移节点；本期核验：2026-09-15。
- **证据**：[xAI 官方公告](https://x.ai/news/grok-voice-think-fast-2)
- **能力变化**：语音到语音模型提升转写、对话、语音推理和工具调用可靠性；官方称首段音频时间 0.70 秒，并称生产环境下工具调用通常可在 Agent 第一句话结束前触发。
- **价格**：$0.08/音频分钟（后端模型/工具调用另计）。
- **企业部署影响**：适合线索初筛、预约、售后回访等有明确转人工边界的场景；上线前需落实录音告知、身份核验、敏感话术拦截和人工接管。

### 4. [国外｜Meta] Muse Spark 1.1：代码、多模态、工具调用走向统一模型接口
- **时间**：官方博客当前页；发布时间需以 Meta 页面的发布日期二次核验。
- **证据**：[Meta 官方公告](https://ai.meta.com/blog/introducing-muse-spark-meta-model-api/)
- **能力变化**：官方将 Muse Spark 1.1 描述为结合 coding、multimodal understanding 与 tool calling 的模型。
- **企业部署影响**：模型能力正在收敛到“理解—推理—调用工具”的统一形态；企业不可把模型接入等同于 Agent 落地，工具合同、权限语义和观测体系才是护城河。

### 5. [国外｜Mistral] 主权 AI / 开放权重仍是企业采购重要变量
- **时间**：本期核验：2026-09-15（具体公告日期以原页为准）。
- **证据**：[Mistral 官方公告](https://mistral.ai/news/mistral-makes-sovereign-open-weight-ai-to-frontier/)
- **能力/部署变化**：强调开放权重、可控基础设施、数据驻留和可审计部署。
- **企业部署影响**：对金融、零售会员和私域数据类场景，模型选型必须同时看能力、数据位置、可替换性、审计及成本预测；中国企业应保留国产云/私有化备选栈。

### 6. [国外｜OpenAI] Agents API / 高权限 Agent：平台化编排方向延续（近7天追踪）
- **时间**：以 [OpenAI Agents API 公告](https://openai.com/index/introducing-the-agents-api/) 页面标注为准；本期未将其误判为 9 月 15 日新品。
- **能力变化**：云端 Agent 编排、上下文压缩、工具检索、MCP/自定义函数、Web Search 与多 Agent 协作成为平台层能力。
- **价格/部署**：按 token 与工具使用计费；托管、自建/隔离环境等部署方式会影响数据边界与总成本。
- **企业部署影响**：可减少自建编排胶水代码，但业务权限模型、操作审计、数据脱敏与异常回滚仍必须由企业承担。

### 7. [国内｜DeepSeek] V4.1-Flash：1M 上下文与低成本，适合高频企业任务
- **时间**：截至 2026-09-15 的官方文档状态。
- **证据**：[DeepSeek API 定价与能力文档](https://api-docs.deepseek.com/quick_start/pricing/)
- **能力变化**：`deepseek-flash` 对应 DeepSeek-V4.1-Flash；支持 1M 上下文、最大输出 384K、思考/非思考、JSON、Tool Calls、视觉与 Anthropic API 兼容。
- **价格**：峰时输入（缓存命中/未命中）$0.006 / $0.30 每百万 token，输出 $1.20；低谷为峰时一半（以官网实时价格为准）。
- **企业部署影响**：适合作为 CRM 知识问答、工单摘要、线索分层、批量内容初稿的默认路由；超长上下文仍应使用检索、摘要、缓存控制成本与幻觉风险。

### 8. [国内｜Kimi] Kimi K3：1M 长上下文、视觉、双主流接口兼容
- **时间**：截至 2026-09-15 的官方文档状态。
- **证据**：[Kimi 开放平台文档](https://platform.kimi.com/docs/intro)
- **能力变化**：Kimi K3 支持 1M token 上下文、视觉理解与 `reasoning_effort`；支持 OpenAI Chat Completions/Responses API 和 Anthropic Messages API 兼容方式。
- **企业部署影响**：降低现有 Agent 与代码工具迁移成本，适合中文长文档、方案生成、知识工作和代码协同；需用真实私有知识样本验证召回、稳定性和极长输入的单位任务成本。

### 9. [国内｜通义/百炼、智谱] 多模型平台与长程 Agent 能力汇聚
- **时间**：截至 2026-09-15 的官方目录/官网状态。
- **证据**：[阿里云百炼模型目录](https://help.aliyun.com/zh/model-studio/models)｜[智谱新闻与产品页](https://www.zhipuai.cn/news)
- **能力变化**：百炼覆盖通义、DeepSeek、Kimi、GLM 等模型，以及图像/视频、语音、Embedding/Rerank 等组件；GLM-5.3 被定位于复杂软件工程与长程 Agent，标注 1M 上下文能力。
- **企业部署影响**：一站式采购可加速 POC，但不应把业务流程锁进某一平台 SDK；需用统一模型网关、标准化工具协议和离线评测保留切换空间。

### 10. [安全/合规｜中国与企业治理] 未发现近24小时可独立核验的重大新增政策，应按既有合规框架持续落地
- **时间**：截至 2026-09-15 08:10；本期未发现具明确时间戳且足以改变企业落地路径的国内重大新规，未用二手解读补量。
- **权威依据**：[《生成式人工智能服务管理暂行办法》中国政府网](https://www.gov.cn/zhengce/202307/content_6891752.htm)
- **影响判断**：面向公众提供服务的生成式 AI 要求与企业处理个人信息、重要数据、跨境传输义务叠加。对 CRM，会员画像、订单、聊天、导购业绩属于高敏经营数据，必须落实数据最小化、目的限定、权限审计与供应商数据条款。

## 国外 vs 国内：API / 价格 / 上下文 / 多模态 / Agent 对照

| 维度 | 国外 | 国内 | 管理判断 |
|---|---|---|---|
| Agent | 强调电脑操作、托管编排、多 Agent、语音实时工具调用 | 强调长上下文、中文工具调用、API 兼容与平台集成 | 自建统一编排、工具与权限层，避免流程被 SDK 锁死 |
| 上下文 | 能力重心偏长程执行与多模态，具体窗口随产品变化 | DeepSeek Flash、Kimi K3、GLM-5.3 可见 1M 级信号 | 1M 不等于应全量塞上下文；检索、摘要、缓存优先 |
| 价格 | 语音、深度推理、电脑操作常引入额外成本 | 高频文本任务通常更具成本优势 | “国产默认 + 高价值任务升档”是当前最稳妥路由 |
| 多模态 | 语音与电脑操作产品化更快 | 视觉、语音、视频与行业云集成密集 | 先做可量化的单场景，不做全能助手 |
| 合规/部署 | 跨境、第三方工具链和数据处理协议是重点 | 国内云/国产模型利于本地交付与合同协同 | 私域数据优先国内合规路径；海外仅处理脱敏低敏任务 |

## C. 对中国 ToB SaaS/CRM（含 EZR）的影响判断

### 增长
- 把 AI 从“聊天入口”升级成“可执行经营助手”：导购跟进建议、客户分层与召回、工单下一步、营销复盘，才能直接关联响应时长、转化率、导购人效和续费率。
- **对 EZR 的机会**：先产品化 3 个有业务闭环的场景包，不以会话次数做 KPI。

### 效率
- DeepSeek/Kimi/GLM 的长上下文、工具调用和成本优势，让工单、会话、活动素材、门店日报等批处理进入规模化可行区间。
- **对 EZR 的机会**：模型路由建议为“低成本国产模型处理标准任务；复杂、高价值、低频任务再升档”，并记录成功率、时延、人工回退率、单任务成本。

### 风险
- **数据合规**：私域聊天、会员画像、订单与导购业绩禁止无边界送入跨境模型或第三方 Agent 平台。
- **模型路由成本**：长上下文、深度推理和并行 Agent 会放大 token 成本，必须设置单任务预算与熔断。
- **权限审计**：查询、导出、群发、发券、改价、删除必须 RBAC + 审批 + 留痕 + 回滚；对外触达和资金/价格类动作不得全自动。

## D. 今日可执行动作（3条）

1. **今天定“CRM Agent 四级权限”**：L0 只读检索、L1 生成建议、L2 人工审批后执行、L3 禁止自动执行；群发、发券、导出客户、改价、删除一律归 L2/L3，并写入审计日志。
2. **本周完成模型路由基准**：用脱敏真实样本对 DeepSeek V4.1-Flash、Kimi K3、GLM-5.3 与 1 个海外强模型测试工单摘要、导购建议、活动复盘、代码审查，输出质量/时延/成本/回退率对比及默认路由表。
3. **两周内做语音 Agent 窄场景 POC**：仅选“售后预约或线索初筛”，接知识库和人工转接，不开放 CRM 写操作；以首响时长、转人工率、一次解决率、单通成本、投诉率验收。
