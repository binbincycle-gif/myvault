## A. 今日结论（3条）

1. **近 24 小时没有看到国外/国内头部厂商新的通用旗舰模型正式发布；本期主要变化是官方价格页、模型列表和 Agent 工具链继续刷新。** 这意味着“模型能力突变”暂时让位于“企业可部署性”：价格、上下文、工具调用、区域路由、安全策略、Agent 环境成为管理层要看的核心指标。
2. **海外模型竞争正在从单模型能力转向“模型 + Agent 平台 + 安全/数据驻留”组合。** OpenAI API pricing 明确 GPT-5.5 长短上下文与工具计费；Anthropic Claude 5/4.8 系列强化缓存、区域/数据驻留价格；Google Gemini 3.5 Flash 把 Computer Use、Interactions API、多模态视频生成纳入平台；xAI Grok 4.3 / 4.20 给出 1M 上下文和低价 API。
3. **国内模型侧，Qwen / Kimi / GLM 已形成“低成本长上下文 + Coding/Agent + 多模态”的可用替代链路。** Qwen3.7 Max/Plus、Kimi K2.6/K2.7 Code、GLM-5.2 都在长上下文、工具调用、结构化输出、MCP/Agent 方向加强；对中国 ToB SaaS/CRM，关键不是选唯一模型，而是建立模型路由、权限审计、成本看板和私域数据分级。

## B. 重点情报（10条）

### 1. 【国外】OpenAI API 价格页显示 GPT-5.5 已进入当前计费体系，长短上下文分层更清晰

- **厂商 / 模型 / 产品**：OpenAI / GPT-5.5、GPT-5.5 Pro、GPT-5.4 系列 / API Pricing
- **发布时间 / 核验时间**：官方价格页当前版本；本次核验 2026-07-04 08:11 CST
- **证据链接**：https://developers.openai.com/api/docs/pricing
- **能力变化**：GPT-5.5 采用短上下文与长上下文两套价格；GPT-5.5 Pro 价格显著更高，适合高价值复杂任务。
- **上下文 / 工具调用 / 多模态 / Agent / 价格 / 部署方式**：GPT-5.5 短上下文 $5 input / $0.5 cached input / $30 output per 1M tokens；长上下文 $10 / $1 / $45；GPT-5.5 Pro 短上下文 $30 input / $180 output，长上下文 $60 / $270。工具计费包括 Web Search $10/1k calls、File Search $2.5/1k calls、Hosted Shell/Code Interpreter 按容器计费。
- **企业部署影响**：企业不能只看模型 token 价，必须把 Web Search、File Search、Code Interpreter、容器、缓存命中率一起纳入单位任务成本。
- **对 ToB SaaS/CRM/EZR 的机会**：适合设计“复杂经营分析/研发改造/高风险决策”上限模型档位，作为模型网关的 premium route。
- **风险**：长上下文和工具调用叠加后成本非线性上升；需强制任务级预算和日志审计。
- **建议动作**：模型网关增加 `context_tier`、`tool_cost_enabled`、`max_task_budget` 三个控制字段。

- **发布时间 / 核验时间**：官方价格页当前版本；本次核验 2026-07-04
- **证据链接**：https://ai.google.dev/gemini-api/docs/pricing
- **能力变化**：Gemini 3.5 Flash 定位“速度 + frontier intelligence + search/grounding”。
- **上下文 / 工具调用 / 多模态 / Agent / 价格 / 部署方式**：Paid tier 标准价格：input $1.50 / output $9.00 per 1M tokens；context caching $0.15 per 1M tokens，storage $1 / 1M tokens/hour；Batch input $0.75 / output $4.50。Google Search / Maps grounding 每月共享 5,000 prompts 免费，之后 $14 / 1,000 search queries。

## C. 国外 vs 国内能力对照：API / 价格 / 上下文 / 多模态 / Agent

| 维度 | 国外头部模型趋势 | 国内头部模型趋势 | 对中国 ToB SaaS/CRM 的判断 |
|---|---|---|---|
| API 与平台 | OpenAI/Anthropic/Google/xAI 都在把模型、工具、容器、搜索、Agent 环境打包；Google 推荐 Interactions API | 阿里百炼、Kimi、智谱均提供 OpenAI 兼容或类 OpenAI API，百炼同时聚合三方模型 | 应建设统一模型网关，避免业务系统直连单厂商 |
| 价格 | OpenAI GPT-5.5 高端价明显；Anthropic Sonnet 5 有临时价；Google/xAI 在部分模型上更低 | Qwen/Kimi/GLM/DeepSeek 价格更适合中文高频生产；阶梯价、缓存价明显 | 高频 CRM 场景优先国内模型，复杂低频任务保留海外上限验证 |
| 上下文 | OpenAI 长短上下文分层；Claude、Gemini、Grok 均进入 1M 级别竞争 | Qwen3.7 Max/Plus 支持 1M 阶梯；GLM-5.2 1M；Kimi 256K | 长上下文要按业务任务拆分，不要把“全量数据塞模型”当方案 |

## D. 对中国 ToB SaaS / CRM / EZR 的影响判断

### 1. 增长机会

- **AI 能力可以包装成“结果型 CRM 能力”，而不是单纯聊天助手。** 例如：会员分群建议、活动复盘、导购任务生成、门店异常提醒、客户经营分析。
- **国产模型成本结构适合规模化嵌入 CRM 高频场景。** Qwen3.7 Plus / Kimi K2.6 / GLM-5.2 等可覆盖大部分中文业务任务，海外模型用于复杂推理或上限评估。
- **多模态会增强导购和零售内容生产。** 商品图理解、海报生成、短视频脚本、导购话术、活动素材审核都有落地机会。

### 2. 效率机会

- **AI Coding 可从“辅助写代码”升级为“长程工程任务协作”。** GLM-5.2 / Kimi K2.7 Code / Claude / GPT-5.5 可纳入统一评测，按任务类型路由。
- **Agent 可先从只读分析、自动核查、测试回归切入。** CRM 后台配置核对、需求影响范围分析、Bug 复现步骤整理，是低风险高收益场景。
- **成本看板会变成 AI 落地的基础设施。** 模型单价、缓存命中率、工具调用次数、搜索/文件/容器费用必须按任务统计。

### 3. 风险判断

- **数据合规风险**：会员、交易、导购、门店、品牌私域数据不能随意送海外模型；需敏感等级和区域路由。
- **模型路由成本风险**：长上下文 + 工具调用 + grounding 可能让单次任务成本失控；必须有预算阈值。
- **私域数据外流风险**：Agent 调用外部搜索、网页、文件上传时可能泄露客户经营信息。
- **权限审计风险**：Computer Use / Browser Agent / CRM Agent 如果自动点击写入，必须记录操作者、模型、工具、动作、参数、审批人和回滚方案。
