## A. 今日结论（3条）

1. **海外近24小时没有高置信新旗舰发布，竞争焦点继续从“模型参数”转到“企业 Agent 治理”。** OpenAI 的 Spend Controls / approved context / permitted actions，Google 的 Gemini API + Agents + Computer Use + Live，多家厂商的 Prompt/Skill/MCP 治理，说明企业 AI 采购正在看“可控执行、可审计、可回滚”，不只是模型榜单。

2. **国内模型的生产可用性继续增强，DeepSeek V4 是今天最值得关注的官方信号。** DeepSeek 官方模型页显示 `deepseek-v4-flash` / `deepseek-v4-pro`：1M context、最高 384K output、Tool Calls、JSON Output、OpenAI/Anthropic 双格式兼容；Flash 价格低至 cache hit $0.0028 / 1M input、cache miss $0.14 / 1M input、output $0.28 / 1M。对高频 CRM 分析、客服摘要、知识库问答有明显成本冲击。

3. **对中国 ToB SaaS/CRM，下一阶段要做“模型组合治理”，不是押注单模型。** 推荐架构是：海外强模型用于复杂推理/多模态/生态入口观察；国内长上下文模型用于中文知识工作和代码/PRD分析；低价专用模型做翻译、分类、摘要；安全模型做实时护栏；路由层统一成本、权限、审计和数据边界。

- 建议动作：建立 CRM Agent Prompt Injection 测试集，覆盖会员、订单、券、标签、导购群发、客户成功报告。

## C. 对中国 ToB SaaS / CRM 的影响判断

### 增长

1. **AI 产品包装要从“功能”升级为“行业 Agent 工作流包”。** 优先包装活动复盘 Agent、会员分层 Agent、导购任务 Agent、客户成功周报 Agent、商品/活动文案 Agent。
2. **国内低成本长上下文模型会让中小品牌也能消费 AI 能力。** DeepSeek V4 / GLM-5.2 / Kimi K3 等让长文档分析、经营复盘、导购建议的成本下降，适合做 SaaS 增值包。
3. **多语言和跨境品牌可做轻量增长试点。** Qwen-MT 等专用模型可支持商品文案、导购话术、活动内容、客服知识库多语言化。

### 效率

1. **AI Coding 可进入“项目级上下文”试点。** GLM-5.2 / Kimi K3 / DeepSeek V4 适合做 PRD 理解、影响面分析、测试用例、回归清单、代码评审。
2. **模型路由是降本关键。** 旗舰模型做复杂推理，低价模型做分类/摘要/客服批处理，专用模型做翻译，安全模型做护栏。
3. **Prompt/Skill 需要资产化治理。** 借鉴 Mistral：业务专家维护规则，技术侧负责版本、评测、审批、灰度、回滚。

### 风险

1. **数据合规：** 会员手机号、消费记录、导购跟进、订单售后必须脱敏、权限继承、供应商边界控制。
2. **模型路由成本：** 长上下文和长输出会吞噬预算；必须做缓存、摘要层、任务验收和成本看板。
3. **私域数据外流：** Agent 读取网页、邮件、文件、工具返回时，prompt injection 可能诱导泄露客户资料。
4. **权限审计：** 营销券、标签、群发、订单类动作默认需审批，禁止模型直接执行高风险操作。
5. **信息源风险：** 国内媒体传闻多，未有官方链接前不进入选型；避免被“参数/榜单/营销稿”带偏。
