# 国内外AI大模型最新情报深读｜2026-09-24

- 核验时间：2026-09-24 09:16（Asia/Shanghai）
- 口径：近24小时优先；无法由一手页面核验的模型名称、价格、性能数据不作为确定事实。

## A. 今日结论
1. **Agent 的竞争重点继续从模型能力转向连接器与工作流入口。** Google 9 月 23 日将 Airtable、Linear、monday.com、PandaDoc、Zoho 等接入 Gemini；企业入口正在从“打开 SaaS”变为“在 Agent 内调用 SaaS”。
2. **ToB SaaS 的第一优先级不是接入模型，而是把可调用能力封装为受控工具。** 纷享销客已经以 MCP + Skills 将 CRM 接入 Workbuddy、千问办公、豆包工作，并把 MCP 单独开通、按工具调用计数。
3. **今天未发现可由 OpenAI、Anthropic 官方近24小时公告独立确认的基础模型重大更新。** 应避免用聚合站的“新模型/降价”信息直接进入管理决策。

## B. 重点情报

### [国外] Google Gemini 新一批 Connected Apps｜2026-09-23
- Google 宣布 Gemini 开始接入 Airtable、Linear、monday.com、PandaDoc、Zoho 等生产力工具；用户可在 Gemini 设置连接，或在对话中 @ 提及工具。
- 能力变化：从模型单点回答升级为跨项目、数据库、文档等外部系统的工作流调用入口。
- 企业部署影响：连接器治理、用户授权、可调用动作边界将成为 Agent 平台采购与落地的基础能力。
- 来源：https://blog.google/innovation-and-ai/products/gemini-app/new-connected-apps-gemini/

### [国外] Gemini 3.8 Live / Extended Thinking｜2026-09-15（近7天有效）
- Google 发布 Gemini 3.8 Live Extended Thinking，定位复杂任务与多步推理。
- 对 SaaS 启示：模型能力持续向多步任务靠拢，但业务系统是否允许其跨工具执行，取决于身份、权限、审批和审计。
- 来源：https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-8-live-gemini-3-8-live-extended-thinking/

### [国外] Anthropic 对齐与安全工具演进｜2026-08-31（近7天仍有效）
- Anthropic 说明其模型安全工具已从少量分类器演进到自动化审查体系。
- 对 SaaS 启示：企业 Agent 上线不应只看模型供应商安全承诺，业务方必须有自己的操作审批、异常熔断、全链路审计。
- 来源：https://www.anthropic.com/news/improving-alignment-security-efforts

### [国内] 纷享销客 CRM 连接器：MCP + Skills｜2026-09-15
- CRM 可在 Workbuddy、千问办公、豆包工作等平台通过连接器访问和操作；企业需开通 MCP 服务，管理员可试用 15 天；按工具调用次数计数。
- 商业化信号：MCP 能力被独立打包，不依赖其 AI 平台；模型成本由外部 Agent 平台承担。
- 对 EZR 启示：应把“可调用 CRM”从概念变成可计价、可授权、可审计的工具目录和套餐。
- 来源：https://help.fxiaoke.com/ee88/a823/6c9c

## C. 对中国 ToB SaaS/CRM 的影响
- **增长：** 先售卖“业务结果型 Agent 工具包”，如续费风险诊断、客户跟进建议、活动复盘，而不是泛聊天入口。
- **效率：** 建立“指标语义 → 证据检索 → 受控工具 → 结果回写”的闭环；对高频任务实行任务级模型路由。
- **风险：** 外部 Agent 连接 CRM 的红线是实时判权、字段脱敏、动作审批、调用计量、审计留痕与熔断；不可将会员明细永久沉淀到 Agent 记忆。

## D. 今日行动
1. 输出 EZR 可调用经营 Skill v0.1：续费风险、会员跟进、活动复盘三项，逐项明确输入/数据范围/审批/回写。
2. 做一张“外部 Agent 接入 CRM”权限模型图：身份、租户、角色、字段、操作、审计六层。
3. 用一个真实客户跑“建议—人工确认—执行—结果回写”闭环，先测人工接管率和结果改善，不先扩模型数量。
