## A. 今日结论（3条）

1. **海外主线：Frontier 模型进入“强能力 + 强管控 + Agent 工作流”阶段。** OpenAI GPT-5.6 Sol 采用有限预览、政府沟通、分层安全栈；Anthropic Fable/Mythos 受美国出口管制影响；Google/Mistral 同步强化 Agent、工具调用与企业连接器。
2. **国内主线：国产模型的优势从“便宜”升级为“长上下文 + 编程/Agent + 开源/低价 API”。** GLM-5.2 的 1M context/MIT 权重、DeepSeek-V4 的 1M context 极低 API 成本、Kimi K2.7 Code 的 256k 多模态编程模型，正在形成企业 LLM 网关的低成本替代层。
3. **对 ToB SaaS/CRM：机会在“模型路由 + 私域数据 Agent + 文档/知识库/导购工作流自动化”，风险在“权限审计、私域数据外流、模型合规路由、跨境模型可用性”。** 不建议押单一模型，应建设可替换的模型网关和审计闭环。

## D. 对中国 ToB SaaS/CRM 的影响判断

### 增长
- **AI 导购/营销内容生产会进一步降本**：Kimi/DeepSeek/Grok 等低价模型让高频文案、标签解释、活动建议可规模化。
- **差异化不在“接入模型”，而在“懂客户上下文 + 能闭环触达”**：CRM 的优势是会员、导购、商品、活动、交易与私域数据，模型只是执行层。
- **企业客户会开始问“能否私有化/国产化/审计”**：GLM-5.2、DeepSeek 等会成为销售侧可讲的国产化备选能力。

### 效率
- **研发效率**：AI Coding 从单点补全进入长程任务，建议按“需求理解 → 代码改动 → 测试生成 → PR Review”设计流程。
- **运营效率**：文档解析/OCR + RAG + Agent 可用于客户资料沉淀、活动复盘、导购 SOP 自动生成。
- **模型路由效率**：高频低风险任务默认低价模型，高风险/高价值任务才上 frontier 模型复核。

### 风险
- **数据合规**：会员资料、导购聊天、交易数据、营销画像不能直接外发到不明确的数据处理环境。
- **模型路由成本**：Agent 循环、搜索、文件检索、中间推理 token 会让账单失控。
- **私域数据外流**：连接器越多，越容易出现跨租户/越权读取。
- **权限审计**：Agent 执行写操作、群发、客户触达必须有审批、日志和回滚。
