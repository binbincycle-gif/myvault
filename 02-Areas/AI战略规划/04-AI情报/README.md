# 04-AI情报

用于沉淀前沿 AI 大模型、Agent、AI 工具链、模型厂商动态等情报。

## 定位

这里不是具体 SaaS 项目方案目录，而是 AI战略规划下的“外部前沿感知库”：

- 记录 OpenAI / Anthropic / Google / DeepSeek / Kimi / 通义等模型与 Agent 动态
- 保留来源、时间、能力变化、趋势判断
- 为后续组织 AI 转型、SaaS 能力释放、产品能力强化提供参考材料

## 入库原则

- 先去重，再入库
- 优先保留高置信、有来源、有时间戳的信息
- 营销软文、榜单、无明确时间戳内容默认不入库
- 如果内容被截断，标记 `status: partial`，后续补全时更新原文件

## 与其他目录关系

- 如果情报本身只是前沿 AI 学习与趋势感知，放这里
- 如果已经形成 EZR / SaaS / CRM 的落地方案，再另行提炼到：
  - `01-组织AI转型思考/`
  - `02-SaaS的AI能力释放思考/`
  - `03-产品能力强化思考/`
