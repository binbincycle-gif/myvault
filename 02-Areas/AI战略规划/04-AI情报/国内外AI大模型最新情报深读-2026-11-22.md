# 国内外AI大模型最新情报深读｜2026-11-22

> **定位**：前沿 AI 学习与感知（海外优先）。采集窗为 2026-11-21 08:10 至 2026-11-22 08:10（Asia/Shanghai），补充近 7 天有明确发布时间的高价值变化。仅收录有官方来源或可追溯产品页、明确时间戳的信息；已过滤榜单、营销软文、无法复核的转述。

## A. 今日结论

1. **海外的最新确定性增量在 Agent 基础设施，而不是又一轮纯参数竞赛。**Google 11 月 19 日将 Tool Retrieval 引入 Gemini API，说明模型调用从“把全量工具定义塞进 prompt”转向“按任务检索工具”；Grok Bot 与 Mistral 企业 Agent 动作进一步验证，企业竞争对象正是可控、可编排的任务单元。
2. **“强模型规划 + 经济模型执行/校验 + 工具检索”已成为主流产品形态。**Google 的 Gemini 4 Carbon/Hydrogen 组合及其 Orchestrator 是清晰样板；国内则以 DeepSeek Flash 的低成本工具化 API、Qwen 的长上下文多模态和云平台聚合承接高频生产任务。模型采购应改成路由策略，不应再押注单一默认模型。
3. **国内在企业接入侧的优势仍是中文、成本、地域与部署选择；差距不在聊天，而在复杂 Agent 的编排、治理与可验证执行。**对中国 ToB SaaS 而言，优先把权限、审计、审批、回滚和成本归因建成底座，才有条件把模型能力变成产品收入而非演示功能。

### 国外 vs 国内：API / 成本 / 上下文 / 多模态 / Agent 对照

| 维度 | 国外头部（本期以 Google / Anthropic / xAI / Mistral 为代表） | 国内头部（DeepSeek / Qwen / 百度等） | 企业落地含义 |
|---|---|---|---|
| 产品形态 | 模型分层+编排器+工具检索；企业 Agent 平台能力更强 | 低价 API、多模态长上下文、云平台工具套件与本地部署选择 | 采用“规划—执行—校验”三层路由，不以单厂商单模型覆盖全部任务 |
| 上下文 | Hydrogen：100 万 token；Tool Retrieval 进一步减少工具 schema 占用 | DeepSeek Flash、Qwen3.8-Max：100 万 token | 长上下文要配合权限裁剪、检索摘要、缓存；不能全量灌入客户数据 |
| 多模态 | 海外侧更强调文件处理、富 UI、专业产物与协作 | Qwen 支持图/文/视频；DeepSeek 的 OCR/ASR/TTS/文件解析工具更易拼装 | 适合把门店图、商品图、录音、合同和报表纳入 CRM 任务，但先做敏感数据治理 |
| Agent/工具 | Tool Retrieval、Orchestrator、多 Bot/工作流，编排成熟 | 搜索、URL/文件读取、安全检查等直接 API 化；国产云集成方便 | 工具应最小权限、只读优先；发券/群发/写 CRM/导出一律审批+幂等+回滚 |
| 价格 | Google Hydrogen $1.50/$7.50（输入/输出每 M token）；各家定价与许可变化快 | DeepSeek Flash $0.30/$1.20（峰值）；Qwen3.8-Max ¥12/¥36，缓存 ¥1.5 | 将每任务成本、缓存率、工具循环次数纳入产品毛利和监控 |
| 部署/合规 | 区域、跨境传输、能力许可与供应商政策需额外治理 | 国内地域与合规链路更顺；也不能忽略备案、标识、内容治理 | 以数据分级决定模型、地域、可用工具与日志留存，禁止默认跨境传输私域数据 |

## C. 对中国 ToB SaaS / CRM / EZR 的影响判断

### 增长
- **机会**：从“问答助手”升级为“受控经营任务 Agent”——按授权读取客户画像、经营报表、商品/门店素材，给出人群策略与触达草稿，生成待审批 CRM 任务，再回收效果数据。
- **最先可验证场景**：销售拜访准备、流失预警解释、会员/导购问答、营销素材多版本、经营复盘。价值不取决于文案生成，而取决于接入真实上下文后能否形成可追踪的行动闭环。
- **模型组合**：国内模型默认承接线上中文与敏感业务；海外强模型仅用于脱敏后的高复杂策略/产品研发，并保留可替换路由。

### 效率
- Tool Retrieval 与 DeepSeek 工具化 API 共同降低 Agent 工程复杂度；但真正的规模收益来自**工具目录治理、标准 CRM 任务接口、知识权限继承和结果校验**。
- 建议架构：`任务分类 → 权限校验/数据脱敏 → 工具检索 → 模型路由 → 工具沙箱 → 规则+模型校验 → 人工审批 → CRM 回写 → 全链路审计`。

### 风险
- **数据合规**：会员画像、交易、私域聊天、合同、员工信息不得以“工具调用”为由默认外发；搜索/URL/附件解析须显式审批和地域控制。
- **执行安全**：Agent 风险已从“答错”变为“越权读取、误触达、错误写回”。高风险写操作必须最小权限、双确认、幂等和可回滚。
- **成本/供应链**：长上下文与多 Agent 会迅速吞噬 token；模型版本、价格、许可与下线周期变化快，需保留模型抽象层与基准评测。

## D. 今日可执行动作

1. **建立 EZR “Agent 工具目录 + 权限矩阵”**：先覆盖查询客户、查经营报表、生成拜访准备、创建待审批任务四类只读/低风险接口；为每个工具定义数据域、租户范围、调用人、审计字段和是否需人工确认。
2. **做一次三模型路由基准 POC**：以“销售拜访准备”固定测试集，对 DeepSeek Flash、Qwen3.8-Max、海外高能力模型（仅脱敏数据）评测质量、时延、单任务成本、工具成功率、人工修改率；形成默认路由阈值。
3. **收紧外部工具接入策略**：本周完成 URL/联网搜索/附件解析的开关、敏感字段掩码、出境拦截与审批规则；所有 CRM 写操作先落“待审批队列”，不要让 Agent 直接修改正式客户数据。
