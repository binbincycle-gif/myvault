- **上下文 / 工具调用 / 多模态 / Agent / 价格 / 部署方式**：GPT-5.6 Sol short context $5 input / $30 output，long context $10 / $45；Terra short $2.5 / $15，long $5 / $22.5；Luna short $1 / $6，long $2 / $9；缓存输入约 90% 折扣，cache write 单独计费。

- **风险**：长上下文 + ultra 多 Agent + 工具调用可能使成本非线性上升；海外模型处理会员/交易/导购数据存在数据出境与审计风险。
- **建议动作**：把 GPT-5.6 放入“低敏高复杂兜底池”，只接公开资料、脱敏需求和研发评测，不接完整客户私域数据。

## C. 对中国 ToB SaaS / CRM 的影响判断（增长 / 效率 / 风险）

### 增长
- **CRM 的新卖点会从“功能模块”转向“经营任务结果”。** ChatGPT Work 和 GPT-5.6 ultra 说明客户未来会期待系统直接产出销售准备、活动方案、导购复盘、经营建议，而不是只给报表。
- **语音/多模态导购场景继续升温。** GPT-Live、Kimi 视频输入、Qwen 视觉、千帆文档解析都指向“文本之外的 CRM 入口”；服饰零售特别适合商品图、搭配图、门店陈列、导购培训视频理解。

### 效率
- **AI Coding 与业务材料生成会同时提速。** GPT-5.6、Grok 4.5、Kimi K2.7 Code 都在强化 coding / agentic tasks；研发提效不只是写代码，还包括需求拆解、影响分析、测试用例、上线风险回放。
- **模型路由成为平台能力，不是工具选择。** DeepSeek/Qwen/Kimi 负责高频低成本和私域合规，OpenAI/Anthropic/xAI 负责低敏复杂兜底，必须统一入口、日志、成本和权限。

### 风险
- **数据合规风险**：会员、交易、导购沟通、语音、图片、视频都可能含个人信息；海外模型默认不能直接接触完整私域数据。
- **模型路由成本风险**：OpenAI 工具、搜索、容器、文件存储、长上下文、ultra 多 Agent 都会叠加计费；需要租户级预算阈值。
- **私域数据外流风险**：ChatGPT Work 类跨应用连接能力很强，但一旦授权过宽，Slack/Drive/GitHub/Figma/CRM 数据可能被混合使用。
- **权限审计风险**：Agent 如果具备写入、发券、外呼、导出、审批等动作，必须有人工确认、回滚、日志和灰度。
