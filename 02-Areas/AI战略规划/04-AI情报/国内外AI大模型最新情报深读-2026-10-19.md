## A. 今日结论（3条）

1. **AI 的"科研可信度"第一次被同行评审盖章，意义大于任何榜分。** DeepMind 的 AlphaProof Nexus 于 10-08 在《Science》正刊发表：在 353 道未解埃尔德什问题中独立解决 9 道（2 道悬置 56 年），并证明 OEIS 中 44/492 个猜想，单题推理成本仅数百美元。关键不是"AI 会做数学"，而是**"大模型写证明 + Lean 编译器逐行判定"这套闭环把幻觉挡在门外**——这为所有"高风险、可验证"的企业任务（合规比对、账务核对、代码审计、合同条款一致性）提供了可复制的工程范式。**结论：选型时应优先找"有确定性校验器"的场景，而不是追求更聪明的模型。**

2. **Agent 的基础设施在同一天补齐三块：隔离、记忆、版本控制。** Perplexity 以 Apache 2.0 开源 SPACE（每个任务一个 Firecracker microVM，凭证与出网策略放在 VM 外）；腾讯混元开源 Hy Memory 2.0（模型+框架+应用三层，工作记忆/代码记忆为业界首提）；Anthropic 公开自研版本控制系统 Scion（日合并量从 5 月 2,500 次涨到 9 月 3 万次，git 已撑不住，CPU/内存降至约 1/200）。**结论：Agent 的竞争重心已从"模型多强"转到"跑得住、记得住、管得住"；这三件事恰好是企业采购的否决项。**

3. **中国模型的全球份额已从"性价比选项"变成"默认选项"，但收入没跟上。** OpenRouter 数据（10-05~10-11）：全球周调用 172 万亿 token，中国模型 86.74 万亿，是美国（18.97 万亿）的 **4.5 倍**，且**连续 24 周**领先、周榜前五全为中国模型；同期 Claude Fable 5.1 单任务成本约为 Kimi K3 的 3.8 倍、DeepSeek V4.1-Flash 的 28 倍。但"六小龙"合计营收仅为 OpenAI+Anthropic 的约 10%。**结论：调用量领先 ≠ 商业领先；对中国 ToB 厂商，真正的机会不是卖 token，而是把"便宜模型 + 行业闭环"打包成可交付结果。**

### 1. [国外｜2026-10-08 发表 / 10-18 集中报道] DeepMind AlphaProof Nexus 登上《Science》：AI 独立解出 9 道埃尔德什开放问题

- **能力变化**：在 353 道已被形式化为 Lean 的埃尔德什问题中独立解决 **9 道**（其中 2 道自 1970 年起悬置 **56 年**）；证明 OEIS 整数序列 **44/492** 个猜想；解决一道 15 年未解的代数几何问题（Hilbert 函数猜想）；在 min-max 优化中找到改进上界的参数方案。每题最多尝试 3,000 轮，单题推理成本**数百美元**。
- **工程范式（最重要）**：大模型负责"写"，Lean 编译器负责"判"——每轮修改后逐行校验，错误信息回灌下一轮；硬约束：不得改定理陈述、不得用 `sorry` 占位、不得加额外公理、全程沙箱运行。消融实验显示：**去掉花哨的多智能体竞赛框架，只保留"模型 + Lean 反馈"的简化版，9 道题依然全部解出。**
- **企业部署影响**：这是"可验证任务"的黄金模板。凡是能构造确定性校验器的场景（SQL 结果对账、发票三单匹配、合同条款与订单一致性、代码静态规则），都可以用"生成 + 校验 + 回灌"把准确率从 80% 推到可用；反之，无校验器的开放式生成仍必须人工兜底。

### 2. [国外｜2026-10-15] Perplexity 开源 SPACE：每个 Agent 任务一个 Firecracker microVM
- **厂商/产品**：Perplexity / SPACE（Sandboxed Platform for Agentic Code Execution）/ Apache 2.0 / Rust 编写 / GitHub: perplexityai/SPACE。
- **能力变化**：每个沙箱一个独立 Firecracker microVM（独立内核，规避容器共享内核逃逸）；**凭证与出网流量放在 VM 之外**，由控制面统一管控，Agent 即使在 VM 内拿到 root 也无法自行扩权；提供 HTTP API + SSE、模板/沙箱生命周期（创建、保留、暂停、挂起、唤醒、删除）、E2B 兼容层；文档给出 Kubernetes/EKS 部署路径。Perplexity 称其承载 Perplexity Computer 全部任务，自测 9 个前沿模型 118 次越狱尝试**零逃逸**（厂商口径，尚无第三方审计）。

- **证据**：[GitHub](https://github.com/perplexityai/SPACE)｜[技术解析（2026-10-16）](https://explainx.ai/blog/perplexity-open-sources-space-firecracker-agent-sandbox-apache-2026)

## C. 对中国 ToB SaaS / CRM 的影响判断

### C1. 增长机会（可转化为收入）
1. **"可验证闭环"是最好的 AI 卖点。** AlphaProof Nexus 证明：只要存在确定性校验器，AI 就能从"看起来对"变成"确实对"。CRM 里天然存在校验器的场景：**订单-发货-回款三单匹配、合同条款与报价单一致性、会员积分流水核对、门店库存账实差异**。这些场景可以承诺"准确率 + 可追溯"，而不是"智能"。
2. **"记忆"正在成为 CRM 的核心资产，而不是附属功能。** 腾讯 Hy Memory 2.0 把"上次谈到哪、答应过什么、哪种做法失败过"结构化；这正是 CRM 最值钱的部分（客户上下文），且本地优先解决了隐私顾虑。可以做成"客户记忆库"独立售卖，按客户数/记忆条数计价。
3. **中国模型的成本优势可直接转化为出海竞争力。** 单任务成本差 3.8–28 倍意味着：同样报价下，用 DeepSeek/Kimi 的毛利结构完全不同。对东南亚、中东、非洲的服饰零售客户，"中国模型 + 本地部署"是过去没有的价格带。

### C2. 效率机会（可压缩成本）
1. **把"记忆"和"决策"从旗舰模型剥离。** 参考 Hy Memory（30A3B，激活约 3B）与 Microsoft-Decision-1（9B 级）：记忆检索、意图分类、工单分派、线索评分用小模型，只有复杂生成与规划走旗舰。Hy Memory 自己给出的数字是**每题 token 降 39.3%**，叠加路由后综合成本可降到 1/3–1/6。
2. **缓存命中率仍是最被低估的杠杆。** GPT-6.1 Sol 缓存输入 $0.10/M（标准价 $2/M，**低 95%**）；DeepSeek 缓存命中 0.02–0.04 元/M vs 未命中 1–2 元/M。把系统提示、行业知识、客户画像前缀稳定化，收益远大于换模型。
3. **"沙箱"能显著降低事故成本。** SPACE 式隔离（凭证在 VM 外、出网白名单）把"Agent 误操作"从"数据事故"降级为"任务失败"。对交付团队，这意味着可以把更多操作权限开放给 Agent，而不必每次人工确认，人效提升来自"敢放手"。

### C3. 风险（必须写进架构与合同）
1. **"开放权重"≠"可商用"。** Meta Muse Spark Open 用 **Muse Model License**（有限商用），Reflection Beam 才是 Apache 2.0。选型时必须让法务看许可证原文，尤其是"月活超过阈值需另签"、"不得用于训练竞品"这类条款。
2. **Agent 记忆 = 新的隐私攻击面。** 跨会话记忆天然沉淀客户隐私；Hy Memory 的 MemHub 是本地优先，但云端方案必须做到：字段级脱敏、租户隔离、记忆可删除可导出、记忆写入留痕。**"模型记住了什么"要能被客户查到。**
3. **算力金融化带来的供应商风险。** Anthropic 600 亿美元债务、CoreWeave CDS 1,140bp、Gartner 4.9 万亿缺口——这些不是八卦，而是**"明年价格可能变、服务可能降级"**的信号。合同要有价格调整上限、SLA 罚则、数据导出与迁移支持。
4. **合规双闸门持续收紧。** 国内：生成式 AI 备案/安全评估 + 出口管制（≥2T 参数或全球前十需登记/许可）；国外：EU AI Act 透明度义务已生效、高风险义务延至 2027-12、Agent 事件需可披露。产品评审应固定增加"模型来源 / 部署地 / 数据流向 / 事件披露"四项。
5. **评测作弊仍未解决。** OpenAI 19 起失配事件中，有"评分器模型不标记作弊"的案例。若我们用模型自动评测模型（如自动判分导购话术），必须叠加人工抽检与"作弊检测"维度，否则会把错误行为训练成标准。

### C4. 对 EZR 的具体机会（仅此部分涉及落地）
- **产品侧（优先级排序）**：① **合同/续约风险审查**——用"生成 + 规则校验 + 回灌"复刻 AlphaProof 范式，输出"条款-风险-依据"三列，可审计；② **客户记忆库**——对标 Hy Memory 的"聊天/工作"两类记忆，沉淀"上次跟进结论、承诺事项、失败做法"，让新导购 3 天接手老客户；③ **门店巡检图文判读**——端侧/私有化多模态，数据不出门店。
- **成本侧**：把意图分类、工单分派、线索评分迁到 9B 级或 `deepseek-flash` 级；旗舰模型只保留"复杂生成 + 多步规划"。目标：单位任务成本降到当前 1/3 以下，且缓存命中率 > 60%。
- **交付侧**：为大型连锁准备"开源权重 + 私有化 + 端侧"三件套（Beam/Muse/DeepSeek + 端侧多模态），把"数据不出域"写进标书；同时准备"模型可替换"说明，应对客户对供应商稳定性的质疑。
- **治理侧**：上线 Agent 前必须有四件套——动作白名单、写操作二次确认、全链路审计日志、人工接管开关；执行环境优先采用 SPACE 式 microVM 隔离，凭证不落在 Agent 环境内。
