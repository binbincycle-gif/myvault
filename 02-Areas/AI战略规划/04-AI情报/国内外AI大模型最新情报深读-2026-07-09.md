### 1. 【国外】OpenAI 发布 GPT-Live：实时语音模型进入 full-duplex + 后台委派架构
- **厂商 / 模型 / 产品**：OpenAI / GPT-Live-1、GPT-Live-1 mini / ChatGPT Voice，API soon。
- **发布时间**：2026-07-08。
- **证据链接**：https://openai.com/index/introducing-gpt-live/
- **能力变化**：full-duplex 连续交互，可边听边说，处理停顿、打断、背景噪音；复杂问题可委派给后端 frontier model，发布时后端使用 GPT-5.5。
- **上下文 / 工具调用 / 多模态 / Agent / 价格 / 部署方式**：先面向 ChatGPT 全球用户滚动；API 即将开放；支持语音对话、视觉响应、搜索/推理/Agent 后台委派。价格页尚未给出 GPT-Live API 独立价格。
- **企业部署影响**：语音 Agent 从 IVR/ASR-TTS 串联转向实时协同；客服、导购、销售陪练、门店培训会出现体验跃迁。
- **对 ToB SaaS / CRM / EZR 的机会**：可设计“导购语音助手 / 督导复盘 / 客户问题实时问答”原型，但会员与交易数据不能直接出境。
- **风险**：语音输入含个人信息；实时工具调用会放大误操作；需记录同意、留痕、脱敏、禁写边界。
- **建议动作**：把“语音导购助手”列入低敏 PoC，仅接入商品知识、活动规则、SOP，不接入会员明细。

## C. 对中国 ToB SaaS / CRM 的影响判断（增长 / 效率 / 风险）

### 增长
- **语音 Agent 会成为 CRM 新入口。** GPT-Live 说明语音不再只是转写/播报，而是可以实时陪导购、陪客服、陪销售做复杂任务；CRM 可从“表单系统”升级成“经营任务协作入口”。
- **导购场景最适合先落地。** 商品知识、活动政策、会员分层策略、话术建议、异议处理都能做低敏 PoC；但不能直接把完整会员画像丢给海外模型。

### 效率
- **AI Coding 评测必须内部化。** OpenAI 对 SWE-Bench Pro 的审计提醒我们：公开榜单不够，EZR 应建立基于真实需求、Bug、迭代、代码库的内部评测。
