## A. 今日结论

1. **海外竞争已从“模型能力发布”推进到“受控 Agent 生产平台”。**Mistral Studio（11月8日）把 Agent、工作流、应用构建与部署打包；OpenAI 的 Images 2.6、Google 的 Gemini 4 Argon，则继续把多模态和复杂任务能力推入 API/企业平台。企业差异化不再只是模型分数，而是运行、权限、审计和回滚。
2. **国内侧的确定性优势是“长上下文 + 低成本 + 本地化交付”，但必须用路由与评测来换取稳定性。**DeepSeek Flash/Pro 均公开 1M 上下文，支持 Tool Calls、Responses API、Anthropic 兼容接口；火山方舟把 DeepSeek、GLM、Kimi、豆包纳入同一 Agent 套餐与工具生态。国产模型可做 CRM 主路由，海外模型仅做脱敏后的高价值补位。
3. **合规门槛正在产品化。**OpenAI 11月20日将生效的新 Usage Policies 要求模型路由/AI gateway 在直接转售其模型前接受审查；国内持续强调备案/登记与显著公示。对 CRM 来说，最现实的风险是私域、会员、交易数据外流，以及 Agent 越权读写，而不只是“是否接了大模型”。

## C. 对中国 ToB SaaS/CRM/EZR 的影响判断

### 增长
- 将“AI 导购/销售助手”从问答升级为**可控任务流**：客户洞察 → 推荐下一步 → 生成触达草稿/素材 → 人工确认 → 回写 CRM。产品卖点应是“少漏跟进、提升转化、可追溯”，不是“接入了某个模型”。
- Images 2.6 一类多模态能力适合营销素材供给，但先以品牌素材库、审核流和 A/B 转化验证为门槛，避免自动化内容带来品牌/版权风险。

### 效率
- 建立三级路由：①国产轻量/缓存模型承接分类、摘要、知识问答；②国产高能力模型承接中文复杂规划、检索与代码；③海外模型仅用于已脱敏的高价值研究、复杂代码或全球化能力补位。
- 以“单任务成功率、人工接管率、时延、Token、缓存命中率、工具失败率”做周度看板。DeepSeek的缓存价差表明，静态知识前缀复用是立即可见的降本抓手。

### 风险
- **数据合规**：会员画像、私域聊天、手机号、订单、交易、导购绩效等不得默认发送到境外模型或跨租户记忆库；落实分类分级、脱敏、目的限制、最小传输、保留期限和删除机制。
- **模型路由成本/稳定性**：模型 SKU 会退役、平台政策会收紧。模型 ID、价格版本、上下文/工具能力、退役日和 fallback 要全部配置化并纳入回归测试。
- **权限与审计**：禁止 Agent 同时拥有“全量客户读取 + 自动对外发送/改价/批量写回”权限；高风险工具必须二次确认、角色授权、幂等、防重和完整审计。

## D. 今日可执行动作（3条）
