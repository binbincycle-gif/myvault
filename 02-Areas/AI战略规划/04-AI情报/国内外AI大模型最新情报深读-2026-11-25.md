# 国内外AI大模型最新情报深读｜2026-11-25

> 定位：前沿 AI 学习与感知。已过滤营销软文、榜单和没有明确发布时间的二手转述；个别厂商近24小时无一手重大更新，明确标注为“未检出”，不以传闻补位。

## A. 今日结论

1. **海外竞争主轴已从“更大模型”转向“可规模化的 Agent 运行时”**：Google 把长上下文、多模态文件切片、工具按需检索做进 API；OpenAI 将专业知识工作、计算机使用和单位任务成本作为 GPT-6.2 Astra/Sol 的核心卖点。企业竞争点正在由单轮问答，转为“文件—工具—执行—审计”的完整链路。
2. **国内进入“旗舰多模态 + 应用工具全家桶 + 本地协作入口”并行阶段**：Qwen4-Max 已进入代码/Agent 工作流；DeepSeek 把搜索、读链、文件与语音/OCR 接口化；Kimi 的百万上下文与视觉旗舰可用。国内方案在中文、本地生态和可控成本上更适合生产落地，但需独立验证复杂工具调用可靠性。
3. **EZR 的优先级不是押注单一模型，而是建设可切换、可审计的 Agent 中间层**：将客户隐私数据、权限、脱敏与工具白名单留在自有系统；以国内模型承接默认业务负载，以海外强模型做非敏感复杂任务/评测，不把任何模型供应商直接接入生产写操作。

## B. 重点情报

1. **[国外｜Google DeepMind｜2026-11-23 更新] Gemini 4 Neon 上线，面向长程 Agent 与企业多模态知识工作。**
   - 能力/部署：1M token 上下文；支持表格、PDF、图表、音视频输入；4 档思考强度；可作为编排器调度子代理。
   - 价格：$3/M 输入、$0.15/M 缓存输入、$15/M 输出。
   - 企业影响：可将大型知识库、客户材料和多文件任务放在同一上下文内，但长上下文不是免费能力，需用缓存、切片和任务拆分控成本。
   - 证据：[Google 官方](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-neon/)

2. **[国外｜Google Gemini API｜2026-11-23] 原生 file slicing：服务端按页/单元格/片段读取文件。**
   - 能力：PDF、Office/ODF、表格、音频、视频可仅传入所需页、工作表/单元格、时间片和内容层；按实际检查部分计 Token。
   - 企业影响：CRM 场景中的合同、巡店视频、经营报表不必全量 OCR/转码，能明显降低多模态 Agent 的上下文与本地沙箱负担。
   - 证据：[Google 官方](https://blog.google/innovation-and-ai/technology/developers-tools/file-slicing-controls/)

3. **[国外｜Google Gemini API｜2026-11-19] Tool Retrieval 预览：大型工具库按需加载 Schema。**
   - 能力/价格：Gemini 3.6+（含全部 Gemini 4）可在 Interactions API 中只保留工具名称与描述，命中时再取完整参数 Schema；无独立服务费，按实际 token 计费；兼容远程 MCP。
   - 企业影响：适合 EZR 把数百个 CRM/BI/审批能力接入 Agent 时，降低固定提示词成本与工具误选；但需在客户端用用户权限过滤可检索工具。
   - 证据：[Google 官方](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-api-tool-retrieval/)

4. **[国外｜OpenAI｜2026-11-17；近7天仍为主线] GPT-6.2 Astra/Sol 以“专业工作流单位成本”分层。**
   - 能力：Astra 主打专业文档、表格、幻灯、代码和计算机使用；Sol 面向日常多步 Agent 工作流。
   - 价格：Astra 为 $8/M 输入、$0.40/M 缓存输入、$40/M 输出，较 GPT-6 Astra 输入/输出价低 20%；Sol 保持 GPT-6.1 Sol 定价。官方强调更少输出 token 完成任务。
   - 企业影响：适合作为高价值、低频、非敏感复杂任务（如复杂方案、交付审查）的质量标杆；不宜作为全量客服/营销默认模型。
   - 证据：[OpenAI 官方](https://openai.com/index/introducing-gpt-6-2-astra-sol/)

5. **[国外｜OpenAI｜2026-11-24] GPT-6 系列披露蛋白设计能力研究。**
   - 判断：这是科研垂直能力信号，直接商业 CRM 价值有限；但它再次说明前沿模型能力更新会快速向高约束专业流程外溢。
   - 企业影响：对 EZR 的启发不是做科学 Agent，而是将“领域模板 + 结构化证据 + 人工复核”作为高价值行业 Agent 的产品形态。
   - 证据：[OpenAI 官方](https://openai.com/index/gpt-6-models-demonstrate-intrinsic-protein-design-capabilities/)

6. **[国外｜Anthropic｜2026-09-23 GA，近24h未检出新旗舰发布] Claude Cloud Sessions 已正式可用。**
   - 能力/部署：浏览器连接 GitHub 后，多任务并行运行；每个任务隔离沙箱、可实时 steering、自动创建 PR；可配置网络域名白名单。
   - 企业影响：将“云端并发执行 + 隔离环境 + PR 审阅”确立为 Agent 开发平台的基线能力。对有代码资产的企业，必须将仓库权限、密钥与出网控制前置。
   - 证据：[Anthropic 官方](https://claude.com/resources/articles/claude-code-on-the-web)

## C. 对中国 ToB SaaS / CRM / EZR 的影响判断

### 增长
- **机会：从“AI 问答”升级为“可交付结果的经营 Agent”。** 可围绕导购跟进、活动复盘、商机推进、巡店材料解析、经营周报，做“证据引用—建议—人工确认—写回 CRM”的闭环。
- **优先产品形态：多模态经营档案。** 利用文件切片/结构化解析，让 Agent 只读取指定合同页、表格单元、视频片段，生成带原始证据链接的任务与洞察。

### 效率
- **模型路由是确定性降本项。** 低风险中文总结/分类走国内成本层；复杂跨文件、代码或非敏感国际资料使用海外质量层；先做 30 个真实任务集评测，不按宣传指标选型。
- **工具库必须权限感知。** 按组织、角色、数据域检索工具，仅向模型暴露被授权的最小工具集；写操作强制二次确认、幂等键、可撤回与全链路审计。

### 风险
- **私域数据外流**：客户画像、聊天记录、会员信息、合同和经营数据不得默认送往境外模型；实现租户隔离、字段脱敏、地域路由与供应商留存约束。
- **Agent 误操作与成本失控**：工具自动选择、长上下文和多轮搜索会放大误调用及 token 费用；设置工具配额、预算阈值、速率限制、异常熔断和人工审批。
- **模型退役风险**：Kimi K2.x 已进入退役窗口，任何生产依赖都需要版本锁定、回归集与可替代模型。

## D. 今日可执行动作

1. **本周完成“EZR Agent 路由底座”设计评审**：统一 Provider Adapter、模型注册、任务级路由、token/工具成本记账、降级策略；目标是不改业务代码即可替换模型。
2. **选 3 个可量化场景做对照 POC**：①合同/经营报表按页取证与摘要；②导购/商机建议但不自动写库；③研发 PR/测试失败定位。使用同一真实脱敏样本，评估准确率、人工修订率、单任务成本、耗时与越权率。
3. **立刻补齐 Agent 安全基线**：数据分级与脱敏、工具最小权限/白名单、写操作人审+回滚、提示词/工具调用/数据访问日志、模型版本与退役台账；Kimi K2.x 依赖先完成清单和迁移回归。
