# 国内外AI大模型最新情报深读（管理层版）

> 覆盖窗口：近24小时（截至 2026-11-15 08:10，Asia/Shanghai），必要处补近7天。海外优先；仅保留有明确发布日期、官方公告/文档或可复核一手证据的内容。已过滤营销软文、无时间戳榜单与未获官方证实的型号传闻。

## A. 今日结论

1. **海外前沿已把竞争重点从“单模型分数”推进到“分层多智能体运行面”。** Google 同时给出 Carbon（深推理/协调）与 Hydrogen（低成本执行）的组合，并在 Antigravity 预览 `/swarm`；Anthropic 亦让高阶模型担任 Advisor/Orchestrator。企业应按任务分层，而非押注单一旗舰。
2. **国内在快速补齐“应用 API 全家桶 + 超长上下文 + 多模型兼容”。** Qwen4-Max-Preview、DeepSeek 应用 API、Kimi K3.1 Pro 都把视觉、检索、文件、工具调用或 1M 上下文作为企业入口；国内成本优势显著，但平台锁定、版本替换与审计要求随之上升。
3. **合规约束开始直接决定模型路由设计。** OpenAI 自 11月20日起要求模型路由/网关提供其模型前先获审核；Anthropic 自11月12日起强化高风险人工监督与地域/控制权限制。EZR 的优先级应是可审计的 Agent Gateway，而非“先接最强模型”。

## B. 重点情报

1. **[国外｜11月13日] Google 发布 Gemini 4 Hydrogen：Agent 执行层模型。**
   - 能力/价格：1M 输入上下文、最高 1M 输出；四档思考强度（含 xhigh）；API 定价 $1.5/百万输入、$7.5/百万输出 token。支持原生多模态知识工作、工具调用和长任务执行。
   - 企业影响：适合做代码执行、资料整理、验证等 Worker/Verifier；与 Carbon/Argon 配对而非替代。Google 声称 Antigravity Orchestrator 的多模型编排可在近 Carbon 成功率下少 24% 配额、快 19%。
   - 证据：[Google Blog](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-hydrogen/)。

2. **[国外｜11月10日] Gemini 4 Carbon 向付费开发者与企业开放，预览 Agent swarm。**
   - 能力/价格：定位深度推理、长程 Agent、复杂知识工作/软件工程/科学任务；API 在 AI Studio 和 Gemini for business 开放。当前介绍价 $2/百万输入、$10/百万输出 token（11月30日后将调整为 $4/$20）。
   - 平台动作：Antigravity 的 `/swarm` 将一个提示拆成可跟踪的协调、Worker、验证 Agent，并隔离工作区。
   - 证据：[Google Blog](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-carbon-now-available/)。

3. **[国外｜11月9日] Anthropic 发布 Claude Fable 5.2 / Mythos 5.2，走“高阶受控 Agent”路线。**
   - 能力/价格：编码、推理、视觉提升；常规价 $8/百万输入、$40/百万输出 token，Fast mode $16/$80，输出速度最高提升 2.5 倍。Fable 面向全量用户并加固生物/网络安全保护；Mythos 的高危网络与生命科学能力需要验证计划准入。
   - Agent：Fable 可作为 Advisor 或 Orchestrator 向较小模型委派任务；说明高端模型从“直接作答”转向“受控协调”。
   - 证据：[Anthropic 发布页](https://www.anthropic.com/claude-fable-and-mythos-5-2)。

4. **[国外｜11月10日] OpenAI 推出 Businesses in ChatGPT beta：从搜索入口进入商业 Agent 分发。**
   - 产品：Business Hub 支持企业认领资料、维护产品 feed（价格/库存）与查看聚合互动洞察；美国符合条件的电商及在线服务企业可发布 Business Agent，并可作为 ChatGPT Ads 落地页。
   - 对 CRM：AI 搜索/问答入口会成为新的线索与转化前台，但不可把用户原始对话数据当作可获得资产；OpenAI 明确企业只获得满足阈值后的聚合洞察。
   - 证据：[OpenAI](https://openai.com/index/introducing-businesses-chatgpt/)。

5. **[国外｜生效11月12日 / 20日] Anthropic 与 OpenAI 同步收紧高风险、路由和地域治理。**
   - Anthropic：高风险健康、金融、法律权利等场景要求有权干预的人工复核并告知受影响者 AI 已参与；对自主物理动作要求可观察、可停止、安全态；进一步明确不支持地区、控制权限制。
   - OpenAI：11月20日生效的新政策要求直接提供其模型的 router/AI gateway 先获审核；并推进 SafetyIDs，使滥用调查能定位终端用户而不获取其真实身份。
   - 证据：[Anthropic Usage Policy](https://www.anthropic.com/news/2026-usage-policy-update)；[OpenAI 政策说明](https://openai.com/index/broad-access-through-consistent-standards/)。

6. **[国内｜11月11日] Qwen4-Max-Preview 上线：国内旗舰多模态 + 兼容层信号。**
   - 能力：默认深度思考（low/medium/xhigh 可调）、图像与视频理解、Function Calling、联网搜索、JSON/JSON Schema；1M 上下文、393,216 最大输出；兼容 OpenAI Chat Completions/Responses 与 Anthropic Messages API。
   - 部署/成本：仅通过 Token Plan，预览期 11月11日10:00—11月25日24:00，非按量计费；思考 token 与最终输出共用上限，迁移时需重算预算，避免截断。
   - 证据：[阿里云百炼文档](https://help.aliyun.com/zh/model-studio/qwen4-max-preview)。

7. **[国内｜11月13日] DeepSeek 开放“应用 API 全家桶”，从模型 API 进化为托管工具层。**
   - 能力：在 `deepseek-flash` 的 Messages、Responses、Chat Completions 中开放联网/深度搜索、文件输入、URL 阅读和安全校验；Search、Fetch、OCR、ASR、TTS 也可独立调用。服务端负责编排工具调用和上下文拼接。
   - 价格：Flash/V4-Pro 均为 1M 上下文、最大 384K 输出；Flash 高峰价输入缓存未命中 2元、输出8元/百万 token，闲时减半；搜索/抓取 5元/千次，文件解析/OCR 1.5元/千页。
   - 证据：[发布公告](https://api-docs.deepseek.com/zh-cn/news/news261113/)；[价格与规格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)。

8. **[国内｜当前能力/迁移窗口] Kimi K3.1 Pro 维持超长上下文与高速变体；旧模型下线应列为供应商风险。**
   - 能力：K3.1 Pro 为 3 万亿级参数、原生视觉、1M token 上下文，面向代码、3D、金融研究及复杂 Agent；提供约 2—3 倍速度的 Highspeed 版本。

## C. 对中国 ToB SaaS/CRM 的影响判断

### 增长
- ChatGPT Business Agent 表明“AI 内的发现—咨询—转化”开始形成新入口。EZR 可为品牌建立可控的商品/知识/服务 Agent，但核心竞争力应是连接 CRM 的实时库存、会员、导购、交易与权益，而不是通用聊天。
- 可优先商品化：商机复盘、导购跟进建议、会员流失解释、工单归因、活动策略草稿；以可量化的转化率、跟进时效、人工节省做价值证明。

### 效率
- 建议“高能力协调 + 低成本执行/验证”的多模型路径：复杂策略/跨文档分析走高阶模型，摘要、分类、信息抽取、质检走 DeepSeek Flash 等低成本模型；多模态模型处理聊天截图、商品图、录音、工单附件。
- 指标从 token 单价改为：**任务成功率、单成功任务总成本、时延、人工回退率、工具调用失败率**。

### 风险
- **数据与私域：** 会员画像、交易、导购对话、合同不可默认出域；需字段级脱敏、租户隔离、检索权限继承、数据驻留策略。
- **权限与审计：** Agent 的读取、生成、写回、触达需区分权限；营销、删改、外发动作必须二次确认、可回放、可回滚。
- **供应商连续性/成本：** 模型 ID 下线、套餐价格、平台点数及供应商政策随时变化；保留原始模型版本、token、缓存、工具费、质量结果和故障原因。

## 对 EZR 的影响（单独提炼）

1. 建设 **EZR Agent Gateway**：模型注册与版本锁定、任务路由、权限注入、字段脱敏、工具白名单、预算控制、调用审计、评测回归、熔断降级一体化。
2. 将企业 AI 场景划为三级：L1（只读摘要/标签）可自动；L2（方案/话术/建议）须人工确认后使用；L3（客户触达、改价、工单/营销写回）必须审批、留痕和可撤销。
3. 商业化采用“基础 AI 能力包 + 透明用量包 + 结果型 Agent 包”，把每类任务的成本和效果可视化，避免把不可解释的平台点数直接转嫁给客户。

## D. 今日可执行动作（3条）

1. **完成一套多模型路由 PoC（两周）：** 选 6 类 CRM 任务各 30 条脱敏样本；比较 Qwen4-Max、DeepSeek Flash、Kimi K3.1 与一个海外模型的质量、时延、总成本和人工回退率。
2. **建立供应商变更监控（本周）：** 对模型 ID、价格、上下文、工具价格、区域可用性和弃用公告设置变更告警；Kimi 旧模型在 12 月下线前完成调用清单与替代回归。
3. **把安全控制前置为发布门槛（立即）：** 上线字段级脱敏、RBAC、租户隔离、工具白名单、L3 动作审批、模型/提示词/工具调用审计以及一键熔断；海外模型只允许进入脱敏、非生产测试链路。
