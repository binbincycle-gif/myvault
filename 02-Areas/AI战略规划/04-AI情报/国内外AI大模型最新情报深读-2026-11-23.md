## A. 今日结论

1. **能力竞争已从“单模型问答”转为“长程 Agent + 多模型协同”。** OpenAI、Google 的最新主线均把复杂工作流、工具调用/电脑操作、代码验证和成本效率绑定在一起；国内 Qwen、混元、文心则正以 **1M 长上下文、MoE 低激活参数和更低单价**快速追赶。
2. **中国企业模型路线应是“双轨路由”，而非单一模型押注。** 海外强模型适合高价值复杂推理、国际化内容和深度代码任务；国内模型/私有化部署适合中文业务、客户数据、成本可控与监管边界场景。核心不是模型榜单，而是路由、权限和审计能力。
3. **安全从“内容合规”升级为“Agent 行动合规”。** Anthropic 已把自主物理行动、高风险健康/金融、监控和欺骗活动写入使用规则；纽约 RAISE Act 要求头部实验室公开安全框架、72 小时上报关键事故。面向 CRM 的 Agent 必须默认最小权限、可撤销和全链路留痕。

## D. 对中国 ToB SaaS/CRM / EZR 的影响

### 增长机会
- **从“问答助手”升级为“经营工作流 Agent”**：围绕线索评分、会员分层、导购跟进建议、活动复盘和商机风险预警，采用“检索—分析—生成建议—人工确认—写回 CRM”的闭环。
- **多模态客户经营入口**：把门店图文、语音回访、活动物料、培训视频、Excel/合同等转成结构化经营信号；先选择可量化的单点，如“导购回访录音质检+待跟进清单”。
- **模型路由成为产品能力**：高价值复杂任务走高能力模型，日常摘要/分类/抽取走国内低成本模型；这将直接决定单位客户毛利和可规模化交付能力。

### 效率机会
- 1M 上下文可减少大客户资料的切片拼接，但仍需用 RAG 权限过滤和证据引用，避免“一次塞全量数据”。
- DeepSeek 工具 API 的成本变化，使情报搜集、竞品监测、网页/附件资料处理更适合产品化；必须对外部内容做注入隔离。

### 风险
- **数据合规**：私域聊天、会员画像、订单/交易与员工行为数据不得无边界外发；建立数据分级、脱敏、出境评估与供应商数据处理台账。
- **Agent 越权**：自动发券、改客户标签、外呼、发私域消息、修改商机等属于高影响动作；默认只生成草稿，必须审批后执行。
- **成本和可用性**：介绍价、预览模型和工具免费策略都可能变化；需要模型版本固定、预算熔断、限流、缓存、回退及观测。
- **审计不足**：每次模型请求必须可追溯到用户、租户、数据源、模型版本、提示模板、工具调用、审批人与最终写回结果。

## E. 今日可执行动作（3条）

1. **本周建立模型路由基准集**：选 50 条 CRM 真实但脱敏的任务（线索总结、门店复盘、会员洞察、工单分类、合同/附件抽取、营销文案），对 Qwen4-Max、文心5.5 Flash、混元 Hy4 Flash、DeepSeek 与一个海外强模型评估质量、时延、单位任务成本和幻觉率。
2. **把 Agent 的“可做/不可做”写成权限矩阵**：读取/建议/草稿可自动；发送消息、发券、改标签、写回商机、外呼、导出数据必须按租户、角色和审批分级，且全量审计。
3. **做一条安全架构红线**：外部网页和检索内容只可进入隔离上下文；客户私域与 PII 先脱敏、最小化传输；为所有模型调用补上版本锁定、成本阈值、回退与人工兜底。
