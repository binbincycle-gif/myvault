## A. 今日结论（3条）

1. **海外主线从“模型能力发布”转向“高能力模型的受控释放 + Agent 生产力平台化”。** OpenAI GPT-5.6 采取 trusted partners 预览、政府沟通、分层安全栈与后续 GA；Anthropic 文档显示 Claude Fable 5 / Mythos 5 被美国出口控制暂停访问；Google、Mistral 则把 Agent 开发平台、文档智能和本地模型作为企业落地抓手。
2. **国内主线是“低成本长上下文 + 开源/可私有化 + 安全护栏”继续补齐。** DeepSeek V4 给出 1M context、最高 384K output、极低缓存命中价；Kimi K2.6/K2.7 Code 强化长程 coding 与 Agent 任务；Qwen3Guard 补齐实时流式安全检测；智谱 GLM-5.2 / GLM-5V-Turbo 继续强调 1M 上下文、多模态 coding 与开源 SOTA。
3. **对中国 ToB SaaS/CRM，下一阶段不是“接入哪个最强模型”，而是建设模型路由、数据分级、Agent 权限审批和审计系统。** 高频文本/摘要/分类可走国内低成本模型，复杂代码、架构、深度分析用海外旗舰或国内高端模型兜底；但私域客户数据、导购行为、会员资产必须通过网关、缓存、脱敏和审计来管控。

## B. 重点情报（10条）

### 1. 【国外】OpenAI GPT-5.6 Sol / Terra / Luna：旗舰模型进入受控预览，Agent 与安全栈同步升级

- **厂商 / 模型 / 产品**：OpenAI / GPT-5.6 Sol、Terra、Luna / API、Codex、ChatGPT 后续可用
- **发布时间**：官方页面当前抓取于 2026-06-27；页面为 GPT-5.6 preview 发布文
- **证据链接**：https://openai.com/index/previewing-gpt-5-6-sol/ ；系统卡：https://deploymentsafety.openai.com/gpt-5-6-preview
- **能力变化**：Sol 为旗舰，Terra 为平衡型，Luna 为快速低成本型；强化 coding、biology、cybersecurity 长程任务；新增 max reasoning effort；ultra mode 使用 subagents 加速复杂工作。
- **上下文 / 工具调用 / 多模态 / Agent / 价格 / 部署方式**：官方披露价格为 Sol $5 input / $30 output、Terra $2.5 / $15、Luna $1 / $6 per 1M tokens；支持更可预测 prompt caching，cache write 1.25x uncached input，cache read 90% discount；预览期先通过 API 与 Codex 面向 trusted partners。
- **企业部署影响**：高价值 Agent 任务将更适合按“任务价值”计费，而不是按 token 粗算；但受控预览说明未来前沿模型的可用性会受安全、政府沟通、客户资质影响。
- **对 ToB SaaS/CRM/EZR 的机会**：可借鉴其 Sol/Terra/Luna 分层，把 EZR 内部 AI 能力拆成“复杂决策 / 日常办公 / 高频低成本”三档。
- **风险**：高能力模型的 cyber/biology 风险导致访问收紧；企业内部 Agent 必须做权限边界、审批、人机确认与日志。
- **建议动作**：内部模型网关预留“能力 tier + 任务风险 tier”两维路由字段。

### 2. 【国外】OpenAI Agent 生产力研究：Codex 从 coding 工具演变为跨部门长程任务工具

- **厂商 / 模型 / 产品**：OpenAI / Codex / Agentic work
- **发布时间**：官方文章抓取于 2026-06-27；数据覆盖至 2026-06
- **证据链接**：https://openai.com/index/how-agents-are-transforming-work/
- **能力变化**：OpenAI 称 Agentic AI 把知识工作的单位从单次交互变为可委派的长程任务；到 2026-05，80.6% sampled individual users 至少发起过一次估计超过 30 分钟人类工作量的 Codex 请求，70.2% 超过 1 小时，25.6% 超过 8 小时。
- **企业部署影响**：Agent 的组织价值不止研发提效，而是让 Legal、Finance、Recruiting 等非技术岗位承接原本需要技术协助的自动化与结构化分析。
- **对 ToB SaaS/CRM/EZR 的机会**：可以把 OpenClaw / AI Coding 从研发试点扩展到产品、测试、交付、客服、运营，形成跨部门任务委派机制。
- **风险**：Agent 工作时间越长，越需要任务边界、验收物、权限、回滚和责任归属。
- **建议动作**：用“任务说明 → Agent 执行 → 产物验收 → 人工确认”的流程替代纯聊天式使用。

### 3. 【国外】Anthropic：Claude Fable 5 / Mythos 5 高端模型能力强，但出现出口控制约束

- **厂商 / 模型 / 产品**：Anthropic / Claude Fable 5、Claude Mythos 5、Claude Opus 4.8、Sonnet 4.6、Haiku 4.5
- **发布时间**：Anthropic News 显示 2026-06-12 出口控制公告；模型文档抓取于 2026-06-27
- **证据链接**：https://www.anthropic.com/news ；https://docs.anthropic.com/en/docs/about-claude/models/overview
- **能力变化**：Claude Fable 5 为最强广泛发布模型，Mythos 5 通过 Project Glasswing limited availability；Fable/Mythos context 1M、max output 128K、$10/$50 per MTok；Opus 4.8 $5/$25，context 1M，max output 128K；Sonnet 4.6 $3/$15，context 1M。
- **企业部署影响**：Claude 在长上下文、agentic coding、多云部署（API、AWS、Bedrock、Google Cloud、Microsoft Foundry）上适合企业级复杂任务，但出口控制说明中国企业要准备可替代模型路径。
- **对 ToB SaaS/CRM/EZR 的机会**：复杂 PRD、架构评审、代码迁移、长文档分析可把 Claude 作为上限参照。
- **风险**：出口管制、区域路由、数据 residency 与云平台差异会影响可用性；不可将关键能力单押海外模型。
- **建议动作**：海外模型仅做上限验证和复杂兜底，生产默认保留国内模型 fallback。

### 4. 【国外】Google：Gemma 4 12B + AI Edge，把本地多模态 Agent 带到普通笔记本

- **厂商 / 模型 / 产品**：Google DeepMind / Gemma 4 12B / Google AI Edge Gallery、Eloquent、LiteRT-LM
- **发布时间**：2026-06-03
- **证据链接**：https://developers.googleblog.com/en/bringing-gemma-4-12b-to-your-laptop-unlocking-local-agentic-workflows-with-google-ai-edge/
- **能力变化**：Gemma 4 12B 面向本地 agentic、multimodal 工作流；可在 macOS 上用 AI Edge Gallery 做本地数据分析、Python 代码生成与执行；Eloquent 支持本地语音听写与 voice edit；LiteRT-LM CLI 新增 OpenAI-compatible local endpoint。
- **部署方式**：本地运行，数据留在设备侧；LiteRT-LM 可通过本地 server 接入 OpenClaw、Continue、Aider 等工具。
- **企业部署影响**：低敏/高隐私的本地 Agent 具备可行性，特别适合文档草稿、个人效率、轻量数据处理。
- **对 ToB SaaS/CRM/EZR 的机会**：可探索“本地小模型 + 云端强模型”混合架构：本地处理脱敏、摘要、草稿，云端做复杂推理。
- **风险**：本地模型能力与一致性不如云端旗舰；设备性能和版本管理会带来运维复杂度。
- **建议动作**：选择一类低风险场景试点本地模型，例如个人日报整理、会议纪要初稿、低敏文档改写。

### 6. 【国外】Mistral OCR 4：文档智能从 OCR 走向结构化 RAG / Agent ingestion

- **厂商 / 模型 / 产品**：Mistral / OCR 4 / Search Toolkit、Document AI
- **发布时间**：页面元信息检索到 June 23, 2026
- **证据链接**：https://mistral.ai/news/ocr-4/
- **能力变化**：OCR 4 返回 bounding boxes、block classification、inline confidence scores；支持 170 languages across 10 language groups；可作为 enterprise search、RAG、domain-specific retrieval pipelines 的 ingestion 组件。
- **价格 / 部署方式**：API $4 / 1,000 pages，Batch API 50% discount 后 $2 / 1,000 pages；Document AI $5 / 1,000 pages；企业客户可 self-hosted，单容器部署。
- **企业部署影响**：企业文档进入 Agent 工作流前需要结构化、定位、置信度和可回溯 citation；这比纯 OCR 更接近知识库治理。
- **对 ToB SaaS/CRM/EZR 的机会**：合同、门店 SOP、活动方案、品牌资料、会员规则可先结构化入库，再供 Agent 检索与执行。
- **风险**：OCR 结果仍需人工抽检；合同/会员等敏感文档要优先选择 self-hosted 或私有化方案。
- **建议动作**：知识库建设时加入“结构化抽取 + 引用定位 + 置信度 + 人工复核”字段。

## D. 对中国 ToB SaaS/CRM 的影响判断

### 1. 增长机会

- **AI 能力可以从“功能卖点”升级为“经营结果交付”。** 长上下文 + Agent 让系统能跨会员、导购、商品、营销、订单、售后数据完成更完整的业务动作，例如客户分群、活动策略、导购跟进建议、异常复盘。
- **国内低成本模型让 CRM 高频场景具备规模化经济性。** 会员标签解释、活动文案、工单摘要、门店复盘、客户需求聚类都可用国内模型先跑起来。
- **文档智能与多模态能力让历史资料变成可调用资产。** 合同、品牌方案、SOP、培训资料、活动复盘可结构化入库，变成 Agent 可检索、可引用、可执行的业务上下文。

### 2. 效率提升

- **研发效率**：Kimi / DeepSeek / Claude / GPT 等可分层支持需求拆解、代码阅读、测试用例、前端原型、故障定位。
- **交付效率**：Agent 可基于客户资料、需求、PRD、上线记录自动生成交付准备清单与风险提示。
- **管理效率**：模型可辅助做周报、质量复盘、资源预警、需求优先级归因，但必须保留口径定义和人工确认。

### 3. 风险与治理

- **数据合规**：会员、导购、交易、企业微信、品牌经营数据不能直接外发海外模型；需数据分级、脱敏、地域路由。
- **模型路由成本**：长上下文会迅速放大 token 成本；要把 cache hit、平均输入、平均输出、失败重试纳入成本看板。
- **私域数据外流**：Agent 工具调用可能把客户数据带入第三方搜索、浏览器、日志或插件，需要默认最小权限。
- **权限审计**：Agent 能执行工具后，必须记录谁发起、调用什么工具、读取/写入什么数据、产物由谁确认。

### 对 EZR 的影响（单独提炼）

- **近期优先方向**：建设 EZR 内部模型网关，按任务类型路由：高频文本任务走 DeepSeek/Kimi/Qwen，复杂架构/代码/深度分析保留海外旗舰或国内高端模型 fallback。
- **AI Coding 方向**：把 Kimi K2.6/K2.7 Code、DeepSeek V4、Claude/GPT 作为统一评测对象，按 EZR 真实代码库任务评测，而非只看榜单。
- **CRM 产品方向**：先做“安全可控的经营助理”：不直接自动下发营销动作，先给出客户洞察、活动建议、风险解释和导购跟进建议，由人确认。

## E. 今日可执行动作（3条）

1. **建立模型路由 MVP 表**：字段包括任务类型、数据敏感级、推荐模型、fallback 模型、最大 token、是否允许工具调用、是否需要人工确认、日志保留策略。
2. **启动 20 个真实任务评测集**：从 EZR 代码库、需求、Bug、CRM 业务文档中抽样，评测 GPT/Claude/Kimi/DeepSeek/Qwen/GLM 的准确率、成本、耗时、可控性。
3. **设计 Agent 安全闸口**：先落地“工具白名单 + 敏感数据脱敏 + 输出前安全检测 + 人工确认 + 审计日志”，再扩大 Agent 自动执行范围。
