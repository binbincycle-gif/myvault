## TOP5

### 1. xAI 发布 Grok Voice 3.0：语音到语音登顶独立榜单，单价不变
- **来源账号/来源链接**：@xai、@SpaceXAI（白名单）；官网 [x.ai/news/grok-voice-3](https://x.ai/news/grok-voice-3)｜第三方核验 [eesel](https://www.eesel.ai/blog/grok-voice-3)｜发布说明解读 [dev.to](https://dev.to/gabrielanhaia/grok-voice-30-took-over-grok-voice-latest-on-october-14-pin-your-voice-agents-model-435)
- **发布时间/核验时间**：2026-10-14 发布；2026-10-16 08:12 核验。
- **事件**：xAI 发布 Grok Voice 3.0 语音对话模型，称在 Artificial Analysis 语音指数得分 86.9 居首，单价维持 $0.08/分钟；`grok-voice-latest` 别名已指向 3.0。
- **为什么重要（业务视角）**：语音 Agent 的"效果—成本"拐点已到，导购/客服的外呼与接听不再必须自建 ASR+TTS 拼接链路。
- **对 ToB SaaS / CRM / EZR 的影响**：可评估把"AI 外呼/接听"从自研语音链路切换为一体化语音模型；同时 `-latest` 别名漂移是隐患，必须固定版本号。
- **建议动作**：评估一条导购语音跟进的最小可用方案（建议先从内部回访场景试），并确认是否固定模型版本。
- **置信度**：**高**（官网 + 多来源交叉；原帖互动量不可核验）。

### 2. NVIDIA 开源 Nemotron 3.5 Super VL（120B MoE / 12B 激活），主打"始终在线 Agent"
- **来源账号/来源链接**：@nvidia、@NVIDIAAI（白名单）；[NVIDIA 官方博客](https://blogs.nvidia.com/blog/nemotron-3-5-super-vl/)｜[Hugging Face 权重](https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Super-VL-120B-A12B-BF16)｜[Artificial Analysis 评测](https://artificialanalysis.ai/articles/nemotron-3-5-super-and-bolt)
- **发布时间/核验时间**：2026-10-15 发布；2026-10-16 08:12 核验。
- **事件**：NVIDIA 发布 Nemotron 3.5 Super VL 开源权重多模态模型（120B MoE、每 token 激活 12B、最高 1M 上下文），并同时推出 Nemotron 3.5 Bolt；独立评测称其为当前领先的美国开源权重模型（智能指数 26）。
- **为什么重要（业务视角）**：强多模态 + 可自托管 = 大客户"数据不出域"谈判有了新选项，也是成本与供应风险的缓冲。
- **对 ToB SaaS / CRM / EZR 的影响**：私有化/专有云交付场景可把"图片/小票/票据识别 + 长文档理解"放到自托管开源模型，降低对单一公有云的绑定与成本暴露。
- **建议动作**：让架构侧做一次自托管可行性小测（显存/吞吐/准确率），只作备选路线，不立即切换主力模型。
- **置信度**：**高**（官方博客 + HF + 独立评测）。

### 3. FTC 向 OpenAI、Anthropic 发出民事传票：监管从"能不能用"转向"谁负责"
- **来源账号/来源链接**：Reuters/Axios/Ars Technica；[Reuters](https://www.reuters.com/business/us-ftc-subpoenas-openai-anthropic-over-consumer-harms-axios-reports-2026-10-15/)｜[Axios](https://www.axios.com/2026/10/15/ftc-openai-anthropic-ai-safety-investigation)｜[Ars Technica](https://arstechnica.com/tech-policy/2026/10/ftc-probes-if-openai-anthropic-security-incidents-harmed-americans-report-says/)
- **发布时间/核验时间**：2026-10-15；2026-10-16 08:12 核验。
- **事件**：美国 FTC 就消费者保护/安全事故风险，向 OpenAI 与 Anthropic 发出民事传票，并要求相关第三方提供材料。
- **为什么重要（业务视角）**：模型供应商的合规性将成为企业采购尽调项；下游使用方也可能被追溯。
- **对 ToB SaaS / CRM / EZR 的影响**：面向品牌的 Agent 一旦涉及自动触达、权益发放、数据导出，需要可证明的审批与留痕；大客户合同将加入"AI 事故响应"条款。
- **建议动作**：把《CRM Agent 权限与审计最小规范》从建议升级为本月交付物（身份 / 数据域 / 动作白名单 / 阈值审批 / 日志回放 / 一键停用）。
- **置信度**：**高**（多家权威媒体 + 监管事实）。

- **为什么重要（业务视角）**：再次证明"模型 ID 写死"会直接打断研发流水线，工具链必须具备切换能力。

- **置信度**：**高**（官方 changelog）。
