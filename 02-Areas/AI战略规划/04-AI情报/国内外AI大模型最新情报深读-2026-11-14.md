# 国内外AI大模型最新情报深读（管理层版）

> 覆盖窗口：2026-11-13 至 2026-11-14（必要处补近 7 天）。海外优先。仅保留有明确发布日期、厂商公告或可复核一手/主流媒体证据的项目；已过滤无时间戳营销软文与榜单类内容。

## A. 今日结论

1. **Agent 正从“模型能力”进入“企业运行面”竞争。** Google 推出面向可靠 Agent 工作流的 Gemini 4 Hydrogen；Anthropic 强调在企业安全边界内运行托管 Agent；国内则以豆包工作接入多厂商模型为代表，焦点转向“任务—模型—成本”的路由治理。
2. **模型选择权正在从模型厂商移到平台层。** 国内办公 Agent 已把 Kimi、GLM、DeepSeek 等纳入统一入口，企业无需逐家采购；但计费倍率、数据流向、调用审计若不透明，会直接形成采购与合规风险。
3. **对 EZR 的第一优先级不是追逐单一旗舰模型，而是建设可审计的多模型路由与权限边界。** 高价值复杂任务接高能力 Agent 模型；结构化抽取、摘要、标签、质检走低成本模型；客户私域数据默认最小化出域。

## B. 重点情报

### 1. [国外｜11月13日] Google 发布 Gemini 4 Hydrogen，明确定位 Agent 工作流
- **事件/能力：** Google 官方称 Gemini 4 Hydrogen 是面向“可靠 Agentic workflows 与日常任务”的快速、成本效率型模型。
- **意义：** 海外一线竞争进一步从“通用模型分数”转为 Agent 稳定性、速度与单位任务成本；适合被作为工具调用、流程编排的常用执行层，而非只做对话。
- **证据：** [Google Blog：Introducing Gemini 4 Hydrogen for Agentic Workflows](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-hydrogen/)（检索时间：2026-11-14；页面标注 1 day ago）。

### 2. [国外｜11月12日] Anthropic 强化“安全边界内的托管 Agent”叙事
- **事件/能力：** Anthropic 最新企业内容指向“在企业安全边界内运行 Claude Managed Agents”。其企业方案强调 SSO、RBAC、审计日志与 SCIM；历史企业方案材料还列出 500K 上下文、原生 GitHub 集成及“不以企业会话/内容训练 Claude”的承诺。
- **部署影响：** 企业采购从模型本身走向“可控身份、权限、审计、知识接入”的完整套件；CRM 场景必须把工具授权与数据域隔离纳入产品能力。
- **证据：** [Anthropic：Claude for Enterprise](https://www.anthropic.com/news/claude-for-enterprise)（检索到 2026-11-12 相关更新）；[Claude Enterprise 方案页](https://claude.com/solutions/enterprise)。

### 3. [国外｜11月3日] Mistral Voxtral 3 将语音与主权部署绑定
- **事件/能力：** Mistral 发布 Voxtral 3，覆盖语音转文本、TTS 与语音 Agent；强调可通过欧盟托管 API 或主权部署方式使用。
- **部署影响：** 多模态竞争已由“看图/读文档”扩展至实时语音 Agent；同时，“地域托管/私有部署”正成为跨境、金融、政企的明确选型条件。
- **证据：** [Mistral：Voxtral 3](https://mistral.ai/news/voxtral-3/)（2026-11-03）。

### 4. [国外｜11月2日] xAI 发布 Grok Bot 1.0，强调团队型主动执行
- **事件/能力：** Grok Bot 1.0 主打团队协作、主动接手工作；xAI 已形成模型、Bot、API、控制台的产品栈。
- **判断：** “无需每次显式触发”的主动型 Agent 会提高自动化价值，也会提高误操作风险；企业需要事件触发白名单、人工确认阈值与可回放执行记录。
- **证据：** [xAI：Introducing Grok Bot 1.0](https://x.ai/news/grok-bot-1-0)（2026-11-02）。

### 5. [国外｜持续变化] OpenAI 继续把模型能力产品化为 Agents API + 托管沙箱
- **事件/能力：** OpenAI 的 Agents API 已上线；API 更新说明显示可为符合条件的项目配置自动审核（`auto_review`）来批准或拒绝受支持的工具调用。定价页提示 GPT-5.6 Sol 的促销价至 11 月30日，快通道更名为 Fast mode。
- **部署影响：** 海外闭源平台的差异不只是模型，而是托管工具、沙箱和审核链路；成本评估应从“token 单价”升级为“单任务完成成本 + 执行风险”。
- **证据：** [OpenAI Agents API](https://openai.com/index/introducing-the-agents-api/)（2026-09-10）；[OpenAI API Changelog](https://developers.openai.com/api/docs/changelog)；[OpenAI API Pricing](https://developers.openai.com/api/docs/pricing)。

### 6. [国外｜近7天] Meta 与开源生态本周期未见同等量级官方新品公告
- **观察：** Meta 官方近期可复核的主线仍是 Llama 4 原生多模态开放权重与超长上下文方向，近24小时没有检索到同级别的新模型公告；开源侧继续是企业私有化、微调与成本可控的关键备选。
- **含义：** 不能把“无新品”误读为能力停滞；对中国 ToB 而言，开源模型更适合充当敏感数据域、离线批处理和可控推理的技术底座。
- **证据：** [Meta：Llama 4](https://ai.meta.com/blog/llama-4-multimodal-intelligence/)（背景基线，2025-04-05）。

### 7. [国内｜10月29日上线，11月5日披露] 豆包工作接入第三方模型，平台层多模型路由成标配
- **事件/能力：** 豆包工作向团队/企业订阅用户开放 Kimi K3.1 Pro、GLM 5.3、DeepSeek V4.1 Flash；管理员可按成员、部门、群组或全员配置模型和调用场景。企业无需分别向模型厂商采购，按 AI 点数扣费。
- **价格/成本：** 报道披露的输出价格（每百万 Token）为：Kimi K3.1 Pro 68 元、GLM 5.3 28 元、DeepSeek V4.1 Flash 闲时 4 元/高峰 8 元；豆包未公开各模型的 AI 点数倍率。
- **部署影响：** 功能上降低了多模型试用门槛，但不透明的点数换算会妨碍成本核算；企业应保留原始模型、版本、输入输出量、价格倍率和任务成功率的账本。
- **证据：** [澎湃：豆包工作首次接入第三方模型](https://www.thepaper.cn/newsDetail_forward_34413540)（2026-11-05，披露 10月29日上线）。

### 8. [国内｜10月29日公告] 扣子企业版下线，字节企业 Agent 服务走向产品整合
- **事件：** 扣子企业标准版/旗舰版于 2026-11-30 停止接受新客户；部分旧版服务于 2026-12-31 全面下线，公告将原因表述为企业级服务整合升级。
- **部署影响：** 依赖单一 Agent PaaS 的企业要准备迁移、资产导出、权限与工作流重构预案；平台产品迭代/下线风险已是 Agent 选型的常规维度。
- **证据：** [澎湃同篇报道](https://www.thepaper.cn/newsDetail_forward_34413540)（2026-11-05）。

### 9. [国内｜近期产品基线] 豆包 Seed 1.8 深度思考强化多模态与企业 Agent 能力
- **能力变化：** Coze 官方模型更新将 Doubao Seed 1.8 描述为多模态深度思考模型，强化工具调用、指令遵循、视觉理解并降低幻觉；提供 minimal/low/medium/high 四档思考强度。
- **部署影响：** “可调推理深度”可直接映射 CRM 的分级路由：高风险洞察/复杂方案用高档，摘要、分类、抽取用低档，以控制时延和成本。
- **证据：** [扣子编程：模型发布动态](https://docs.coze.cn/guides_model_release_note)（2026-01-13 记录，作为当前能力基线）。

### 10. [国内｜近7天] 国内 Token 商业化进入“统一入口 + 用量运营”阶段
- **事件：** 天猫 Token 充值中心已接入 DeepSeek、阿里云、智谱、Kimi 等；多模型办公入口正在普及。报道同时显示企业客户对预算内可用 Token 的关注度上升。
- **判断：** 国内供给侧正快速商品化，模型差异会被平台路由吸收。对 SaaS 厂商而言，核心壁垒将转向行业工作流、私域数据治理、评测集与交付结果，而不是“接了哪个模型”。
- **证据：** [人民网：2026年双11，AI走向前台](http://finance.people.com.cn/n1/2026/1111/c1004-40832084.html)（2026-11-11）；[澎湃报道](https://www.thepaper.cn/newsDetail_forward_34413540)。

### 11. [安全、合规｜近7天趋势] 企业 Agent 的合规重心转向“可追溯执行”
- **趋势：** 中国 2026 年 AI 合规执法/指引持续强化，生成内容标识、数据与算法治理仍是重点；欧盟 AI Act 进入实施与执法准备阶段。全球企业产品需同时考虑个人信息、跨境数据、输出标识与高风险场景的人类监督。
- **对产品要求：** 必须有数据分类分级、脱敏/最小化传输、工具调用审批、审计日志、模型版本与提示词版本留存、异常回滚。
- **证据：** [China Briefing：中国 AI 监管 2026](https://www.china-briefing.com/news/china-ai-regulation-2026-enforcement-guidance-compliance/)（2026-10-26）；[欧盟 AI Act 概览](https://digital-strategy.ec.europa.eu/en/policies/regulatory-framework-ai)。

## 国外 vs 国内：产品与部署差异（管理视角）

| 维度 | 国外头部平台 | 国内头部平台/开源生态 | 对 EZR 的含义 |
|---|---|---|---|
| 竞争核心 | 模型 + 托管 Agent + 沙箱/工具治理 + 企业身份体系 | 多模型聚合、价格路由、办公/低代码入口、私有化与开源供给 | 不能只做“模型接口”；需做任务分级、路由和审计 |
| 上下文 | 长上下文与企业知识接入强绑定，如 Claude 企业方案 500K | 128K/256K 常见，长上下文与性价比并行 | 客户档案/互动记录须按权限切片检索，不能整库裸投 |
| 多模态 | 语音、视觉、代码与 Agent 工具链加速整合 | 图文视频、GUI Agent 与办公自动化落地更快 | 优先落地导购聊天、商品素材、门店巡检、工单附件理解 |
| Agent | 强调托管执行、沙箱、自动审核、企业连接器 | 强调模型可选、工作流/低代码与成本控制 | 默认“建议/草稿”模式，高影响动作需审批 |
| 价格 | token 外还叠加推理/沙箱/托管工具成本 | 价格差显著，平台点数可能掩盖真实模型成本 | 建立按任务核算的 FinOps，而非只比 token 单价 |
| 部署 | 区域云、企业数据控制与跨境限制成为前提 | 国内云、专有云/私有化、开源模型更具落地性 | 国内客户数据默认国内闭环；跨境模型只进脱敏/非生产路径 |

## C. 对中国 ToB SaaS/CRM 的影响判断

### 增长
- **机会：** 从“AI 功能”升级为按结果付费的业务 Agent：商机复盘、导购跟进建议、活动策略草稿、会员流失预警解释、销售知识问答。
- **关键条件：** 连接 CRM 内的客户、交易、互动、权限与流程上下文；没有业务闭环的通用聊天入口容易被平台替代。

### 效率
- **机会：** 用多模型路由分层处理：低成本模型承担标签、抽取、纪要、分类；高能力模型处理复杂分析、方案生成、工具编排；多模态模型处理聊天截图、商品图、语音及门店巡检资料。
- **建议口径：** 评估“每成功完成一个业务任务的总成本/时延/人工回退率”，而不是仅比较 token 单价或榜单。

### 风险
- **私域数据外流：** 会员画像、交易、导购沟通记录、合同与品牌经营数据不得默认外发；需字段级脱敏、检索权限继承与出域策略。
- **模型路由成本：** 聚合平台 AI 点数/倍率不透明会导致预算失控；必须记录原模型、版本、token、缓存命中、任务结果。
- **权限与审计：** Agent 访问客户资料、生成触达内容、修改工单或执行营销动作，必须具备 RBAC、审批、日志、可回放与回滚。
- **供应商连续性：** 产品下线、模型改版、区域可用性变化将持续发生；需 API 抽象层、替换预案和回归评测集。

## 对 EZR 的影响（单独提炼）

1. **产品：** 建设“EZR Agent Gateway”而非绑定单一模型：统一接入、任务路由、权限注入、脱敏、成本计量、调用审计、评测与降级。
2. **场景优先级：** 先做低风险高频的“会话/工单/客户档案摘要 + 标签抽取 + 跟进建议”；再进入需审批的营销文案、活动编排与客户触达。
3. **商业化：** 采用“基础包 + AI 用量包 + 高价值 Agent 结果包”，并向客户展示模型/任务成本透明账单；避免把不透明点数直接转嫁为不可解释的价格。

## D. 今日可执行动作（3条）

1. **本周建立 6 类 CRM 任务评测集：** 客户摘要、线索分级、工单归因、活动策略、导购话术、图片/语音资料抽取；每类至少 30 条脱敏样本，统一比较质量、时延、成本、人工回退率。
2. **两周内完成多模型路由 PoC：** 至少接入“国内低成本模型 + 国内高能力 Agent 模型 + 1 个海外高能力模型（仅脱敏/非生产数据）”；强制记录模型版本、token、缓存、工具调用、失败原因。
3. **上线前补齐 AI 控制面：** 字段级脱敏、租户隔离、RBAC、工具白名单、营销/写回类动作二次确认、审计日志与一键停用开关；以此作为任何 CRM Agent 功能的发布门槛。
