# 国内外AI大模型最新情报深读（管理层版）

> 口径：优先收录厂商官方公告、官方文档和可追溯定价/使用数据页；搜索窗口为北京时间 2026-11-06 08:10 至 2026-11-07 08:10，必要处补近7天。今日未发现多家厂商的官方新旗舰通用模型/API调价；营销软文、榜单、无明确时间戳及无法核验的“泄露”已过滤，不作为决策依据。

## A. 今日结论

1. **海外前沿的主线已进入“高能力 Agent + 强约束安全”的同步升级。** OpenAI 于11月5日发布 GPT-6 Cyber，Google 于10月28日发布 Gemini 4 Carbon；两者都把长程工程/安全任务与范围约束、沙箱、监督、提示注入防护一起产品化。对企业而言，Agent 的竞争门槛已不是“能否调用工具”，而是“能否在授权边界内稳定执行并留痕”。
2. **国内供给的主线是高性价比、长上下文、多模型聚合与快速生命周期切换。** Kimi K3.1 Pro 提供原生视觉和 1M 上下文；腾讯云在 DeepSeek V4.1 Flash 上用峰谷与缓存进一步拉开单位成本；华为云 openPangu 2.0 Flash/Pro 已停售、11月30日下线，凸显生产环境必须把模型替换视为常规运维能力。
3. **EZR 不应押注单一模型，而应优先完成可审计 AI Gateway。** 客户、交易、私域对话、录音等数据默认走国内合规路径；海外模型只接收脱敏后的复杂规划/代码/安全复核任务。模型路由、版本固定、权限审批、成本预算、执行日志和回退必须先于大规模 Agent 上线。

## B. 重点情报

1. **[国外｜2026-11-05｜官方] OpenAI 发布 GPT-6 Cyber，面向经授权的网络安全研究与防御。**
   - **能力变化：** ExploitGym 48.5%，高于 GPT-5.6 Cyber 的32.1%；支持漏洞发现、验证与补丁候选生成。它被定位为“Critical”级网络安全能力，而非通用 CRM 模型。
   - **安全/部署：** Daybreak Red 默认 IP allowlist；强调沙箱、动作复核与人工监督。零数据留存 API 客户仍需接受 Private Safety Processing 的加密记录审查机制。
   - **企业影响：** 安全代码评审与漏洞治理的 Agent 化速度将提高，但任何具备外部执行权的 Agent 都须具备任务范围、授权证明、人工止损和完整审计。

## C. 对中国 ToB SaaS / CRM 的影响判断

### 增长
- 最值得产品化的是“带证据、可确认的经营闭环”：拜访/录音纪要 → 商机、客户风险与待办建议 → 销售确认 → 写回 CRM；而非泛聊天机器人。
- 长上下文与多模态可支撑跨会议、商品图、工单、合同、行为记录的综合判断，但必须只抽取本任务必要的脱敏字段和可追溯证据。

### 效率
- 建议采用 **国内默认路由 + 海外脱敏增强路由**：国内模型处理客户数据、高频批量、知识检索与结构化生成；海外强模型用于脱敏后的复杂规划、代码评审、安全复核和多语种质量抽检。
- 对模型建“供应商—区域—模型ID—版本—能力—价格—替代—下线日期—回归集”的配置台账，生产禁用 `latest`/preview 类无固定版本别名。

### 风险
- **数据合规：** 客户画像、交易、私域对话、录音及员工信息须做字段级脱敏、地域路由、最小留存与处理台账；涉及出境需走专项评估与授权。
- **成本/可用性：** 峰谷、缓存失效、长上下文、工具/搜索调用和重试会显著拉高真实成本；设单任务上限、总预算熔断与异常告警。
- **权限/责任：** CRM 查询、创建、修改、外发要分级；写回、发消息、执行外部动作均要求人工确认、可撤回/补偿和完整执行审计。

## 对 EZR 的影响（单独提炼）

1. **AI Gateway MVP：** 租户模型白名单、字段级脱敏、国内/海外路由、固定模型版本、调用审计、预算阈值、故障降级与回退。
2. **首个闭环：** 销售录音/拜访纪要 → 提取证据和建议商机/待办 → 销售确认 → 写回 CRM；默认禁止无确认的写回及外发。
3. **评测卡：** 以50条脱敏真实任务，横评 DeepSeek/GLM/Kimi/Qwen 与一款海外模型：事实准确率、引用证据覆盖率、工具成功率、P95、单任务总成本、人工采纳率、越权拦截率。

## D. 今日可执行动作

1. **完成模型生命周期盘点（今天）：** 扫描所有生产/候选调用，标出 openPangu 2.0、Kimi K2.x、`latest`、preview；为每项写明替代模型、下线日期、回归集、灰度与回退开关。
2. **启动任务成本与质量双看板（本周）：** 先覆盖“拜访纪要→CRM建议”，归集输入/输出、缓存、峰谷、工具、重试与人工复核；同时采集事实准确率、写回前人工采纳率和拦截率。
3. **收紧 Agent 执行边界（今天）：** CRM 写操作和外部消息统一接入工具白名单、最小权限、二次确认、作用域/时效限制和审计日志；明确禁止客户数据未经脱敏进入海外模型。
