## C. 国外 vs 国内能力对照（管理层摘要）

- **模型上限**：国外 OpenAI / Anthropic / Google / xAI / Mistral 更强在复杂推理、长程 Agent、生态连接、企业云治理；国内 Qwen / DeepSeek / Kimi 更强在中文场景、低成本、OpenAI-compatible API、本土部署与规模化试错。
- **上下文窗口**：国外 Claude / Grok / OpenAI / Gemini 已普遍进入 1M 级别；国内 Qwen 与 DeepSeek 也进入 1M，Kimi K2.6 为 256K，已覆盖多数中文企业文档场景。
- **API / 价格**：国外旗舰模型适合关键任务和上限验证；国内 DeepSeek、Qwen、Kimi 更适合高频 CRM 任务。建议 EZR 不做单模型绑定，统一模型网关 + 路由策略。
- **多模态**：国外在实时语音、图像、视频、工具链整合更成熟；国内 Kimi、Qwen、豆包/火山方舟、千帆也在补齐图片/视频/语音/全模态能力。
- **Agent 能力**：海外 Mistral Vibe、OpenAI Agents SDK、Claude 长程编码、Google Workspace/Vertex 生态更像企业 Agent 操作系统；国内更适合把 SaaS 原子能力开放成 Skill，再接入企业 Agent。
- **部署与合规**：国外强调区域端点、数据驻留、云平台治理；国内更强调生成式 AI 服务合规、个人信息保护、算法/内容责任。本质都要求产品内建审计和权限。

## D. 对中国 ToB SaaS / CRM 的影响判断（增长 / 效率 / 风险）

### 增长

1. **AI 能力销售话术要从“模型很强”升级为“业务闭环能跑”。** 客户真正买的是导购转化、会员复购、活动归因、经营建议，不是聊天框。
2. **Agent-ready SaaS 会形成新竞争壁垒。** 谁先把会员洞察、商品推荐、活动创建、导购任务、客户分群做成可调用 Skill，谁就更容易被企业 Agent 生态集成。
3. **合规可控会成为大客户采购加分项。** 对服饰零售品牌，会员数据、私域聊天、交易记录非常敏感，EZR 可把“AI 安全与审计”包装成企业级能力。

### 效率

1. **高频任务优先国内模型规模化。** 工单摘要、需求拆解、测试用例、知识库检索、导购话术初稿，可用 DeepSeek / Qwen / Kimi 做成本友好验证。
2. **复杂任务保留海外模型上限验证。** 架构评审、长程 Coding、战略分析、复杂客户需求归因，可少量调用 OpenAI / Claude / Mistral。
3. **RAG 要进入可评估阶段。** 知识库不再只看“能回答”，要看召回率、引用准确率、错误率、回答是否可追溯。

### 风险

1. **模型路由成本失控**：1M 上下文和多模态工具会让成本从 token 扩展到搜索、容器、语音、图像、视频、连接器。
2. **私域数据外流**：会员画像、私域聊天、交易明细不能直接丢给海外模型；需要脱敏、授权、模型白名单和数据出域审批。
3. **权限审计不足**：Agent 一旦能调用 CRM 操作，必须区分“读数据、写数据、发消息、建任务、改配置”的权限等级。
