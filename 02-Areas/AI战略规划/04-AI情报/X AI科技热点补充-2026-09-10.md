## 管理摘要

**今天的核心不是新增模型数量，而是“电脑操作型 Agent”已成为企业产品能力：能跨旧系统完成工作，同时必须把权限、确认、审计做成标配。**

对 EZR 的含义很直接：第一，Agent 首版继续以“读数据—给建议—生成草稿”为主；第二，任何写 CRM、客户触达、发券、改价、导出动作必须经过人审和审计；第三，模型不能直绑业务代码，统一经 Agent Gateway 路由与灰度。

## TOP5

### 1. OpenAI：GPT-6 Astra 把 computer use 推入 ChatGPT Work、Codex 与 API

- **事件：**OpenAI 于 2026-09-09 发布/扩大 GPT-6 Astra，强调其可在既有业务软件中执行工作，即使没有 API；覆盖专业工作、浏览、软件工程与 computer use。
- **为什么重要（业务视角）：**Agent 能力从“回答”进入“跨系统完成任务”。企业竞争焦点将从模型效果转向：谁能安全授权、稳定执行、完整追溯。
- **对 ToB SaaS/CRM/EZR 的影响：**EZR 可将旧系统操作纳入受控 Agent，但首期只能处理低风险、可回放任务；写操作必须预览、审批、幂等与可撤销。
- **来源账号/来源链接：**@OpenAI（X 置顶贴文可见，2026-09-04，称 Astra 可完成电脑上的任务）：https://x.com/OpenAI 。官方发布页：https://openai.com/index/gpt-6-astra-next-generation-work/
- **发布时间/核验时间：**官方发布 2026-09-09；X 页面核验 2026-09-10 08:14。
- **置信度：**高。

### 2. OpenAI：把高风险 Agent 的网站、桌面应用与数据流纳入管理员控制

- **事件：**Astra 的企业控制覆盖允许访问的网站和桌面应用、上传下载、浏览历史、重大操作确认，以及对潜在越权工具调用的审查。
- **为什么重要（业务视角）：**Agent 采购门槛正在从“好不好用”升级为“能不能管住”。安全控制不是交付附加项，而是企业客户的产品准入能力。
- **对 ToB SaaS/CRM/EZR 的影响：**EZR 应产品化四层控制：租户/角色/字段级数据权限、工具动作白名单、关键操作二次确认、全链路审计与熔断。
- **来源账号/来源链接：**@OpenAI；官方说明：https://openai.com/index/gpt-6-astra-next-generation-work/
- **发布时间/核验时间：**2026-09-09 / 2026-09-10 08:14。
- **置信度：**高。

### 3. Anthropic：1M 上下文与长程 Agent 成为企业模型主力配置

- **事件：**Anthropic 当前模型文档显示，Fable 5.1、Opus 5、Sonnet 5 支持 1M token 上下文、视觉与工具调用；Fable 5.1 面向长程 Agent。
- **为什么重要（业务视角）：**超长客户资料、工单记录、商品资料与会议/私域纪要可以联合研判；但全量喂数会放大成本、时延和敏感数据风险。
- **对 ToB SaaS/CRM/EZR 的影响：**CRM 应采用“检索—摘要—结构化上下文”分层，不把 1M 上下文当作全量数据直灌的理由；复杂任务再路由至高能力模型。
- **来源账号/来源链接：**@AnthropicAI（白名单监测）；官方模型文档：https://platform.claude.com/docs/en/models/overview
- **发布时间/核验时间：**当前文档状态核验于 2026-09-10 08:14，非当日首次发布声明。
- **置信度：**高（产品当前状态）；中（是否为近24小时传播热点）。

### 4. Kimi K3：1M 上下文、视觉、结构化输出与工具调用，并兼容海外协议

- **事件：**Kimi K3 官方文档列示 1M token 上下文、视觉理解、严格 JSON Schema、函数工具调用、动态加载工具，并兼容 OpenAI Responses / Chat Completions 与 Anthropic Messages API。
- **为什么重要（业务视角）：**国内模型在接口迁移、本地化数据接入与成本可控方面具备生产候选价值；模型切换成本降低，有利于避免供应商锁定。
- **对 ToB SaaS/CRM/EZR 的影响：**统一 Agent Gateway 应按任务复杂度、数据等级、时延与成本路由国产/海外模型。联网搜索工具暂不进入生产主链路，企业知识检索应保持受控。
- **来源账号/来源链接：**非 X 原始发布；官方文档：https://platform.kimi.com/docs/guide/kimi-k3-quickstart 、https://platform.kimi.com/docs/get-api-key.md
- **发布时间/核验时间：**2026-09-10 08:14 核验，非当日首次发布声明。
- **置信度：**高（能力/接口当前状态）；中（X 热度）。

### 5. NVIDIA / Hugging Face：模型分发、评测与部署入口成为 AI 基础设施竞争点

- **事件：**NVIDIA 此前宣布拟收购 Hugging Face，并强调保持平台开放性、中立性与选择权；该信号仍具管理价值。
- **为什么重要（业务视角）：**AI 基础设施竞争正在从芯片延展至模型分发、推理框架、评测与企业部署入口。企业不能把业务能力绑定到单一模型、单一云或单一 SDK。
- **对 ToB SaaS/CRM/EZR 的影响：**持续建设模型—版本白名单、统一评测集、成本/效果监控和可替换路由；业务代码不得直连单一厂商模型。
- **来源账号/来源链接：**@nvidia：https://x.com/nvidia/status/2095518531693806017 。官方博客：https://blogs.nvidia.com/blog/nvidia-to-acquire-hugging-face/
- **发布时间/核验时间：**2026-09-03 发布；2026-09-10 08:14 核验。非近24小时新发生，作为延续性基础设施信号保留。
- **置信度：**中高（以正式公告及后续监管进展为准）。

## 今日建议动作（<=3条）

1. **本周发布《CRM Agent 权限与审计最小规范》：**读/建议/执行三层权限；触达、发券、改价、导出、写 CRM 默认二次确认，保留用户意图—模型建议—工具参数—执行结果审计链。
2. **启动一个两周 POC：**选“商机跟进助手”或“活动复盘助手”，沉淀 30 条脱敏真实任务，并评测准确率、时延、单任务成本、越权率与人工接管率。
3. **把模型路由收敛进 Agent Gateway：**业务只声明任务能力和数据等级；网关承担模型选择、脱敏、预算、缓存、重试、灰度、降级与观测。
