## A. 今日结论（3条）

1. **海外主线从“模型发布”转向“Agent 工作方式 + 企业治理 + 算力全栈”。** OpenAI 近24小时重点不是单一新模型，而是用 Codex 数据证明 Agent 正在从工程团队扩散到法务、招聘、财务等非技术岗位；同时 Broadcom 推 LLM 推理芯片，说明头部厂商在把模型能力、Agent 产品和推理成本控制做成闭环。
2. **Agent 产品进入企业级竞争：可长程执行、接企业工具、可审计、可控成本会成为采购关键。** OpenAI Codex、Mistral Vibe、百度千帆、智谱 BigModel 都在向“Agent 平台”靠拢；单纯聊天能力的差异正在让位给工具调用、权限控制、连接器、审计和预算管理。
3. **中国 ToB SaaS/CRM 最现实路线：国内模型承接高频/敏感/低成本任务，海外强模型承接复杂推理与研发提效，统一通过模型路由、数据分级、审计台账治理。** 机会在 AI 导购、客户运营、商品文案、知识库问答、研发测试自动化；风险在私域数据外流、模型调用成本失控、Agent 越权和合规留痕不足。

### 1. 【国外】OpenAI：Agent 正从“单轮问答”转向“长程委派工作”

- **厂商 / 模型 / 产品**：OpenAI / Codex / ChatGPT Enterprise
- **发布时间**：2026-06-25（官方 News）
- **证据链接**：https://openai.com/index/how-agents-are-transforming-work/
- **能力变化**：OpenAI 披露 Codex 使用趋势：Agent 可独立运行数分钟到数小时，编排工具调用、与环境交互并迭代完成任务；截至 2026-05，80.6% 的个人用户曾发起超过 30 分钟人类工作量的 Codex 请求，70.2% 超过 1 小时，25.6% 超过 8 小时；OpenAI 内部非技术岗位（Legal、Finance、Recruiting）也转向 Codex。
- **上下文 / 工具调用 / 多模态 / Agent / 价格 / 部署方式**：重点是 Agent 长程执行与并行任务，不是新增上下文窗口；依托 ChatGPT/Codex 企业工作区。

## C. 对中国 ToB SaaS / CRM 的影响判断

### 增长

1. **AI 导购和客户运营可以从“辅助写文案”升级为“可执行运营 Agent”。** Agent 能自动读客户画像、生成触达策略、生成话术、提醒导购执行、复盘转化；这比单点 AI 文案更接近客户愿意付费的结果。
2. **面向品牌的卖点应从“接入某个大模型”转成“把品牌经营流程 AI 化”。** 客户不关心模型名，关心复购、唤醒、导购效率、活动转化和会员服务质量。
3. **国内模型低价会打开高频场景毛利空间。** 批量商品文案、会员分群解释、活动复盘、导购任务生成，可以优先用国内低成本模型承接。

### 效率

1. **研发效率提升进入 Agent 阶段。** 需求拆解、代码改动点分析、测试用例、Bug 归因、上线检查可串成一条 Agent 工作流。
2. **知识库质量决定 Agent 上限。** Mistral OCR 4 这类文档结构化能力提醒我们：企业 RAG 不是“把文档丢进去”，而是要保留结构、来源、置信度和权限。
3. **模型路由是中台能力，不应散落在业务系统。** 价格、上下文、合规、延迟、供应商可用性都在变化，必须用 Model Gateway 统一调度。

### 风险

1. **数据合规风险**：会员、订单、导购聊天、私域运营数据不能直接发给海外模型；需脱敏、最小化上下文和客户授权边界。
2. **模型路由成本风险**：长上下文和 Agent 循环调用会快速放大 token 成本；要有预算、熔断、缓存、低价模型降级策略。
3. **私域数据外流风险**：CRM 数据、标签、营销策略是品牌资产，Agent 工具调用必须限制导出、分享、外发。
4. **权限审计风险**：Agent 一旦具备“读 + 写 + 发消息 + 改配置”能力，必须具备操作日志、审批人、回滚机制和异常告警。
