# 国内外AI大模型最新情报深读（管理层版）

> 口径：优先收录厂商官方公告、官方文档及可追溯平台变更。近24小时的明确重磅基础模型发布有限，重点转向 Agent 产品化、协议/计费变化和国内长上下文供给。营销软文、榜单、无明确时间戳材料已过滤。

## A. 今日结论

1. **海外从模型竞赛进入“常驻 Agent + 专属运行环境 + 审批治理”阶段。** OpenAI 11 月 3 日把 GPT-6.1 Terra 扩入 dots；dots 以独立云电脑、跨 4,000+ 应用插件、只读主动研究与敏感动作审批为核心，企业试点已指向采购、发票、客服、合同等系统记录场景。
2. **国内的现实竞争点是兼容协议、长上下文、模型聚合和成本控制。** 阿里云百炼 11 月 2 日调整 Qwen 新模型的 `max_tokens` 语义以对齐 OpenAI；腾讯 TokenHub 于 11 月 3 日更新 DeepSeek 文档，覆盖 OpenAI/Anthropic 双协议、1M 上下文、384K 输出、思考开关与函数调用，但联网搜索开始单独计费。
3. **对 EZR 的优先级是治理底座而不是再接一个聊天模型。** 生产必须实现模型路由、版本固定、字段级脱敏、工具最小权限、审批写回、调用审计与任务级成本核算；海外强 Agent 只在脱敏/审批后的增强层使用。

## B. 重点情报

1. **[国外｜2026-11-03] OpenAI 将 GPT-6.1 Terra 扩展至 dots 的模型家族。** dots 可按任务调用不同模型；Terra 延续 GPT-6 系列对齐改进，并使用 GPT-6 Astra 的安全防护。  
   - **能力/产品：** 常驻 Agent、独立云电脑、跨应用插件；支持 ChatGPT、Slack、Teams，面向企业有具备独立身份、凭据和系统记录深度集成的 specialist dots 预览。  
   - **安全/部署：** 主动研究阶段仅限已连接应用的只读工具；高风险或分享信息的动作走自动审查/人工批准；Business、Enterprise、Edu 默认不用于训练。  
   - 来源：[OpenAI — Introducing dots](https://openai.com/index/introducing-dots/)

2. **[国外｜2026-11-03 核验] OpenAI 的 Agent 产品设计把“可见进度、可控权限、隔离执行环境”做成产品标准。** 用户可查看 Agent 云电脑；保存的密码不暴露给模型；敏感操作（例如改密码）仍由人完成。  
   - **对企业意义：** CRM Agent 不应直接获得全量账户权限，应采用“建议—审批—执行—审计”闭环。  
   - 来源：[OpenAI — dots 安全与产品说明](https://openai.com/index/introducing-dots/)

3. **[国外｜2026-11-03 核验] Anthropic 新闻页显示当日有新动态索引，但检索器未能提取具体公告正文；本期不把不可复核条目作为结论。** 持续有效的企业 Agent 能力仍包括代码执行、MCP Server、文件存储与长缓存；其 2026 Usage Policy 将于 11 月 12 日生效。  
   - **风险：** MCP/工具连接需要最小权限、来源白名单与完整执行日志。  
   - 来源：[Anthropic Newsroom](https://www.anthropic.com/news)；[2026 Usage Policy update](https://www.anthropic.com/news/2026-usage-policy-update)

4. **[国外｜2026-10-27，近7天趋势] Meta 将个人 Agent Muse 推进到新加坡，并连接 Gmail、Google Calendar、Instagram 及 Shopee、Grab、航旅和电商平台。**  
   - **能力/部署：** Muse 运行在 Secure VM；连接器扩展到实际消费与服务平台；邮件发送、购买等敏感动作需要用户确认；基础功能免费，更多能力按订阅提供。  
   - **启示：** Agent 商业化正在以“连接器覆盖 + 可信执行环境 + 审批”而非单纯模型 API 展开。  
   - 来源：[Meta — Muse Singapore](https://about.fb.com/news/2026/10/muse-is-now-available-in-singapore-the-worlds-first-personal-ai-agent-built-for-everyone/)

5. **[国外｜2026-10-21，近7天趋势] Mistral 与 NVIDIA 推进面向工业工程的 AI 基础设施，并称其算力路线图目标为 1GW。**  
   - **判断：** 海外竞争仍在向企业/工业场景和推理基础设施纵深推进；本窗口未见可核验的新 Mistral 旗舰模型/定价更新，不应凭二手资讯调整选型。  
   - 来源：[Mistral — AI for Industrial Engineering](https://mistral.ai/news/mistral-nvidia-ai-for-industrial-engineering/)

6. **[国外｜近24小时核验] Google DeepMind、xAI 未检索到可由官方页面确认的新旗舰基础模型或 API 定价发布；Meta/Mistral 的本窗口新增也以平台扩展为主。**  
   - **持续对比基线：** Google Gemini 4 Argon（10 月 13 日）代表复杂任务方向；xAI Grok Voice 3.0（10 月 14 日）代表实时语音 Agent 方向。  
   - 来源：[Google — Gemini 4 Argon](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-argon/)；[xAI — Grok Voice 3.0](https://x.ai/news/grok-voice-3)

7. **[国内｜2026-11-02] 阿里云百炼调整 API 兼容性：从下一个 Qwen 新模型开始，`max_tokens` 等效 `max_completion_tokens`，思考内容与最终回答共用输出预算。**  
   - **API/成本影响：** 旧模型不变；新模型开启思考后会挤占最终输出额度。若 EZR 按历史 `max_tokens` 经验配置，可能出现答案被截断、成本/延迟预估偏差。  
   - **建议：** SDK 统一将新旧模型参数行为纳入版本配置与回归测试。  
   - 来源：[阿里云百炼 — API 兼容性升级公告](https://help.aliyun.com/zh/model-studio/api-compatibility-upgrade-notice)

8. **[国内｜2026-11-03] 腾讯云 TokenHub 更新 DeepSeek 调用指南：支持 OpenAI Chat Completions 与 Anthropic 两类协议。**  
   - **能力：** DeepSeek V4 Flash/Pro、V4.1 Flash 等列为 1M 上下文、最高 384K 输出；思考可通过 `thinking.type` 开关，模型支持 Function Calling；Vision 实验模型列入多模态理解供给。  
   - **部署差异：** 原厂直供服务不由 TokenHub 提供 SLA，且需接受 DeepSeek 原厂条款；生产部署要把 SLA、故障回退、数据条款作为独立验收项。  
   - 来源：[腾讯云 TokenHub — DeepSeek 调用指南](https://cloud.tencent.com/document/product/1823/132248)

9. **[国内｜2026-11-01 生效/11-18 生效] DeepSeek 原厂联网搜索工具在腾讯 TokenHub 开始单独收费。** 后付费 API 自 11 月 1 日生效；TokenPlan 个人/企业版自 11 月 18 日生效。  
   - **成本影响：** Agent 的真实成本不能只以输入/输出 token 预算；搜索、网页抓取、重试、缓存未命中都需进入任务级成本账。  
   - 来源：[腾讯云 TokenHub — DeepSeek 调用指南](https://cloud.tencent.com/document/product/1823/132248)

10. **[国内｜2026-11-03] 腾讯 TokenHub 存在 DeepSeek 模型的静默升级路径。** 指南显示部分调用保持 model 参数不变即可使用新版本，平台自动完成升级。  
   - **风险：** 模型行为可在未改代码时漂移；必须保留关键任务基准集、输出评测、灰度发布和可回退的版本别名策略。  
   - 来源：[腾讯云 TokenHub — DeepSeek 调用指南](https://cloud.tencent.com/document/product/1823/132248)

11. **[国内｜2026-10-21 / 11-17 即将生效] 腾讯云 Token Plan 公告提示 MiniMax-M2.7 将于 11 月 17 日下线。**  
   - **生态影响：** 国内模型聚合平台的模型生命周期变化频繁；任何生产调用均需保存“模型 ID—版本—替代模型—回归结果”清单。  
   - 来源：[腾讯云 Token Plan 企业版专业套餐](https://cloud.tencent.com/document/product/1823/130659)

12. **[安全/合规｜2026-11-04] 跨境数据、隐私和 Agent 授权风险仍是中国 ToB 的首要约束。** OpenAI/Meta 的产品都强调隔离执行环境、连接器权限和敏感动作确认；中国客户场景还需叠加数据分级、地域路由、个人信息处理告知、访问控制和审计留存。  
   - **判断：** “先接 Agent 后补权限”会造成私域数据外流与越权执行风险；合规能力应成为大客户产品卖点。  
   - 来源：[OpenAI dots](https://openai.com/index/introducing-dots/)；[Meta Muse](https://about.fb.com/news/2026/10/muse-is-now-available-in-singapore-the-worlds-first-personal-ai-agent-built-for-everyone/)

## API / 能力对照（国外 vs 国内）

| 维度 | 国外头部供给 | 国内头部供给 | 企业部署结论 |
|---|---|---|---|
| Agent | OpenAI/Meta 已把云电脑、连接器、身份、审批、进度可见性推进为成品 | 国内重心在模型聚合、工具调用、云 Agent 平台与生态兼容，运行时成熟度需逐案压测 | 不绑定单一 Agent SDK；统一任务状态、工具协议、审批与审计 |
| 上下文/推理 | 长上下文普及，强项在复杂规划/跨工具执行 | DeepSeek 在 TokenHub 标注 1M 上下文、384K 输出，思考按参数开关 | 长窗口不是权限过滤/RAG 的替代品；先按租户和字段裁剪数据 |
| 多模态 | 实时语音、浏览器/电脑操作、跨应用连接是主线 | DeepSeek Vision、国内语音/多模态模型可选，接入更贴近中国云生态 | 录音、图像、语音数据须明示授权、保存期限与脱敏 |
| 协议/API | 原厂 SDK 与 Agent 平台快速演化 | OpenAI/Anthropic 协议兼容降低迁移门槛；百炼主动对齐 OpenAI 参数语义 | 建立兼容层和契约测试，不能假设参数语义永久一致 |
| 价格/成本 | 需综合 token、执行环境、连接器、检索和任务额度 | 国内更易做模型聚合与性价比，但工具搜索已出现独立收费 | 用“单任务总成本”决策，不只比每百万 token |
| 部署/合规 | 强 Agent 能力领先，但跨境与数据主权约束高 | 中国区域云、国产模型和本地服务条款更适合客户数据默认路径 | 客户/私域数据默认国内闭环；海外模型只进脱敏增强层 |

## C. 对中国 ToB SaaS / CRM 的影响判断

### 增长
- 增长机会不在通用对话，而在“下一步经营动作”：拜访纪要转待办、商机阶段诊断、客户分层、活动复盘、导购回访建议、知识库带证据问答。
- 海外 Agent 的产品形态可用于学习“连接器 + 任务进度 + 审批”；落地必须以 CRM 的客户/组织/权限上下文为中心，不能让通用 Agent 直接越权操作。

### 效率
- 采用“强模型规划/复核 + 国内模型批处理/长上下文”的路由策略；低风险摘要、分类、结构化抽取可先进入国产模型候选池。
- 新模型/API 行为变更、静默升级和模型下线要求建立自动回归集，避免 CRM 工作流随供应商更新而退化。

### 风险
- **数据合规：** 客户画像、交易、私域对话、员工绩效默认禁止未经审批跨境；实行租户隔离、字段脱敏、地域路由与数据处理清单。
- **成本/可用性：** 搜索、抓取、工具执行和失败重试会拉高成本；第三方直供模型 SLA/条款可能不同于聚合平台。
- **权限/责任：** CRM 读取、创建、修改、发送应分层授权；自动触达和写回必须支持人工确认、撤回和全链路审计。

## 对 EZR 的影响（单独提炼）

1. **AI Gateway 最小版本：** 租户级模型白名单、字段级脱敏、调用审计、预算阈值、模型版本固定、可观测指标和降级路由。
2. **首批闭环：** 销售拜访纪要 → 结构化待办/商机字段建议 → 销售确认 → 写回 CRM；禁止无确认自动写回。
3. **评测卡：** 用脱敏的 50 条真实任务，对 Qwen/DeepSeek/一款海外强模型测事实准确率、工具成功率、P95 延迟、单任务成本、越权率和版本漂移。

## D. 今日可执行动作

1. **完成模型/API 变更清单。** 本周登记所有生产/候选模型的 model ID、别名、上下文/输出上限、思考参数、工具收费、SLA、替代模型与下线日期；对百炼 `max_tokens` 变更加回归用例。
2. **启动 AI Gateway 治理 MVP。** 先实现租户白名单、字段脱敏、写操作审批、任务日志、预算阈值、版本锁定与失败回退；任何 CRM 写回/外发都不得绕过审批。
3. **做两周销售纪要试点。** 选 1 个内部团队、100 条脱敏样本，评估采纳率、字段准确率、单任务成本、人工修订率与越权拦截率；达到阈值后再扩面。
