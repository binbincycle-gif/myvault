# 国内外AI大模型最新情报深读（管理层版）

> 口径：优先收录厂商官方公告、官方文档与一手平台更新；无明确日期的营销稿、榜单已过滤。近24小时没有检索到海外头部厂商新的旗舰基础模型正式发布，以下以过去7天可核验的产品/平台变化和近30天的能力趋势为主。

## A. 今日结论

1. **海外竞争已从“单模型能力”转向“可运行的 Agent 平台”。** OpenAI 将 Decisions API 推至 GA、Anthropic 把代码执行/MCP/文件存储/长缓存纳入 API，重点是把模型接入企业系统后的决策、执行与评估闭环。
2. **国内的现实优势是长上下文、低成本、多模型供给与本地合规承载；短板是 Agent 运行时、跨工具可靠性、可观测和安全评测的一致性。** Qwen Plus 提供 1M 上下文与强化的多轮工具调用；DeepSeek V4.1 Flash-1017 继续向项目级编码和执行效率优化。
3. **EZR 不应押注单一模型，而应建设“模型路由 + 权限审计 + 场景评测”底座。** 客户摘要、知识问答、内容生成优先国内/私有化路径；复杂规划、跨文档推理、代码/Agent 工作流采用国外强模型的可替换增强层，严禁无脱敏地传输私域客户数据。

## C. 对中国 ToB SaaS / CRM 的影响判断

### 增长
- 最高价值不在通用聊天，而在“销售/导购下一步动作”：客户分层、商机诊断、回访建议、营销素材草稿、会议纪要转任务。海外 Agent 的任务编排能力可用于产品体验标杆，国内模型负责可规模化交付。
- 1M 级上下文适合品牌季报、活动复盘、连锁门店经营资料的跨文档分析；但必须由 CRM 权限模型先过滤可见数据，再向模型提供最小必要上下文。

### 效率
- 代码、测试、文档和运营分析应采用“强模型规划/复核 + 国产性价比模型批处理”的路由策略。DeepSeek Flash 类模型可进入低风险批处理候选池；对数字口径、客户承诺、自动写回 CRM 保持人工或规则复核。
- 多模态语音能缩短一线录入链路，但录音转写、复刻声音、自动外呼均不可绕过授权和日志。

### 风险
- **数据合规：** 客户画像、交易、私域聊天、员工绩效等数据禁止默认出境；建立字段级脱敏、租户隔离、地域路由和供应商数据处理清单。
- **成本与可用性：** 上下文、缓存、工具执行、检索和重试会让真实成本远高于 token 标价；模型退役/静默升级会造成行为漂移。
- **权限与责任：** Agent 对 CRM 的读取、创建、修改、发送必须分权；高风险动作采用“建议—确认—执行”三段式并保留完整审计。

## 对 EZR 的影响（单独提炼）

1. 建设统一 **AI Gateway**：模型路由、租户/场景白名单、成本账单、缓存命中率、质量评测、敏感字段脱敏、失败回退统一治理。
2. 优先做三个可量化场景：**销售拜访纪要→待办/商机更新（人工确认）**、**品牌活动复盘→经营洞察**、**知识库问答→带引用答案**。每个场景都用“采纳率、节省时长、事实错误率、单任务成本”验收。
3. 产品层保留“模型/数据来源说明、引用证据、人工修订、撤回/纠错、权限与审计记录”，把合规能力做成大客户卖点。

## D. 今日可执行动作

1. **本周完成一套模型评测卡。** 对 Qwen Plus、DeepSeek Flash、一个海外强模型，用 EZR 脱敏的 50 条真实任务评测：事实准确率、工具调用成功率、单任务成本、P95 延迟、越权率；不得以公开 benchmark 替代。
2. **立项 AI Gateway 最小版本。** 先落地：租户级模型白名单、字段脱敏、调用审计、预算阈值、版本固定与降级路由；把任何“自动写 CRM/自动触达”放在显式确认之后。
3. **做一个销售纪要闭环试点。** 语音/文本输入 → 摘要 → 商机字段建议 → 销售确认 → 写回 CRM；先选 1 个内部团队、2 周、100 条样本，产出采纳率和错误类型，再决定是否扩面。
