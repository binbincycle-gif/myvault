## 管理摘要

1. **海外主线从“单模型能力”转向“企业级可控 Agent 平台”**：Anthropic 发布 Claude Opus 5，1M 上下文、128k 输出、默认 thinking；OpenAI 增加组织/项目硬预算；Google Gemini Managed Agents 强化后台执行、远程 MCP、凭证刷新。对企业来说，模型能力竞争已进入“长上下文 + 工具调用 + 沙箱执行 + 成本/权限治理”的组合战。
2. **国内主线是“多模态 Agent 化 + 成本快速下探”**：阿里百炼 7 月 25 日上架 qwen3.7-flash，明确强化多模态理解、Search Agent、CI Agent、端到端任务执行；同时 Qwen3.7 Max/Plus 形成 1M 上下文与限时折扣。国内模型在成本、中文场景、多模态生产力上更适合高频业务流程试点。
3. **EZR 应优先做“模型路由与权限审计底座”**：不要押单一模型。建议按任务类型分层：海外模型用于高复杂推理/长上下文设计评审，国内模型用于 CRM 营销文案、导购知识库、客服/运营高频任务，所有 Agent 接入必须纳入预算上限、私域数据脱敏、工具权限和审计日志。

## A. 今日结论（3条）

### 1. 海外模型竞争焦点：长上下文 + Agent 执行 + 企业治理
- Anthropic Claude Opus 5 把旗舰模型推到 **1M token context + 128k max output**，并以 effort 控制推理强度。
- Google Gemini Managed Agents 把后台任务、远程 MCP、凭证刷新做成平台能力。
- OpenAI 新增组织/项目 hard spend limits，说明大模型 API 已从“技术试用”进入“企业成本治理”阶段。

### 2. 国内模型竞争焦点：多模态 Agent 与低成本规模化
- 阿里百炼 2026-07-25 上架 **qwen3.7-flash**，强调多模态理解、Search Agent、CI Agent、端到端任务稳定性。
- qwen3.7-max / plus 已覆盖 1M 上下文，并在华北、海外地域提供不同价格/折扣。
- Kimi K3、DeepSeek V4、智谱 GLM 等已被云平台聚合，国内企业更容易走“多模型供应 + 本地合规 + 低成本调用”。

### 3. 对 ToB SaaS/CRM：机会在“能力嵌入业务流”，风险在“权限和数据外流”
- 增长机会：导购助手、会员运营、营销活动生成、客户洞察、销售话术，可以先从人机协同升级到半自动 Agent。
- 效率机会：研发 CI Agent、需求/测试/客服知识库 Agent、经营分析 Agent 会变成内部提效抓手。
- 风险重点：私域会员数据、企业微信会话、营销素材、客户经营策略一旦进入外部模型/工具链，必须有脱敏、路由、审计、预算上限。

### 1. 【国外】Anthropic 发布 Claude Opus 5：1M 上下文、128k 输出、默认 thinking
- **时间**：2026-07-24
- **厂商/模型**：Anthropic / Claude Opus 5 (`claude-opus-5`)
- **来源**：https://platform.claude.com/docs/en/release-notes/overview
- **能力变化**：1M token context window；128k max output；thinking 默认开启；effort 支持 low/medium/high/xhigh/max；API、Amazon Bedrock、Google Cloud Vertex AI、Microsoft Foundry 同步可用。
- **企业部署影响**：适合长文档、复杂研发评审、合同/需求/知识库深度分析；但默认 thinking 与新 tokenizer/行为变化会影响成本和输出稳定性，需要单独做迁移测试。

## C. 对中国 ToB SaaS/CRM 的影响判断（增长/效率/风险）

### 增长
1. **CRM 从“记录客户”升级为“执行客户经营动作”**：Agent 可围绕会员分层、导购任务、营销活动、客户召回生成下一步动作建议。
2. **多模态内容生产降低品牌运营门槛**：Qwen Image/Audio/Video 类能力可支撑海报、短视频脚本、直播话术、导购培训素材自动化。
3. **AI 能力可成为 SaaS 增值包**：按场景包装“导购助手、营销助手、经营分析助手、客服质检助手”，比单纯卖模型调用更有商业价值。

### 效率
1. **研发提效进入 CI Agent 阶段**：qwen3.7-flash 明确提到 CI Agent，多模态 Coding 和端到端任务执行，适合接入测试失败定位、代码改动影响分析。
2. **知识库/RAG 从问答转向业务流程节点**：阿里百炼知识检索、知识问答、数据连接、Agent 托管形成组合，适合搭建内部交付/客服/实施知识助手。
3. **长上下文降低人工拼材料成本**：1M 上下文适合一次性输入需求、合同、历史工单、代码片段，但要配合摘要缓存和分层路由降低成本。

### 风险
1. **私域数据外流风险**：会员画像、企微会话、交易偏好、品牌策略不能直接进入未审计外部模型。
2. **模型路由成本风险**：Agent 循环调用、长上下文滥用、默认 thinking 都可能造成成本失控。
3. **权限审计风险**：Agent 接入数据库、CRM 操作、营销触达后，必须有工具白名单、最小权限、操作留痕、人工确认节点。
4. **模型生命周期风险**：云平台老旧模型下线、别名更新、价格活动变化会影响稳定性，生产模型必须锁版本。
