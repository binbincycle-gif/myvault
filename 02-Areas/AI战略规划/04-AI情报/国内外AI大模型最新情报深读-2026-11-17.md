# 国内外AI大模型最新情报深读（管理层版）

> 覆盖窗口：2026-11-16 至 2026-11-17（必要处补近 7 天）。海外优先；只保留具备厂商公告、官方文档或可复核日期的信号。已过滤无明确时间戳的营销软文、榜单与未经核实型号传闻。

## A. 今日结论

1. **海外竞争从“最强模型”走到“分层 Agent 集群”。** Google 用 Gemini 4 Hydrogen 占据高速执行层，并让 Carbon/Argon 做高阶协调；Anthropic 以 Fable/Mythos 5.2 继续推高长程技术 Agent 能力。企业选型应从单模型改为“协调模型 + 执行模型 + 低成本批处理模型”。
2. **国内今日最实质的新增是 DeepSeek 把 App 能力打包为 API。** 搜索、读链接、文件理解、OCR/ASR/TTS 与安全校验进入 V4.1-Flash 的统一 API，降低了构建复杂助手的工程门槛，但工具调用费、联网数据出域与内容合规必须纳入成本/审计。
3. **模型能力不再是上线门槛，权限、审批、日志和路由才是。** OpenAI/Anthropic 均在强化高风险人工监督与 Agent 行为边界；EZR 应把“模型网关 + 权限注入 + 脱敏 + 可回放执行”作为 CRM Agent 的基础设施，而非应用后补。

## B. 重点情报（海外优先）

### 1. [国外｜11月16日更新] Google Gemini 4 Hydrogen：1M 上下文的高效 Agent 执行层
- **厂商/产品：** Google DeepMind / Gemini 4 Hydrogen。
- **能力与价格：** 100 万 token 上下文，输入 $1.50/百万 token、输出 $7.50/百万 token；提供 low/medium/high/xhigh 四档思考；原生处理 PDF、表格、图表、音频、视频，并强化工具调用与失败恢复。
- **Agent/平台动作：** Google Antigravity 的 Orchestrator 可在 Carbon 与 Hydrogen 之间动态切换；官方称在其评测中，接近 Carbon 成功率下配额低 24%、完成更快 19%。
- **企业部署影响：** 代表“高能力协调 + 低成本执行/校验”的多模型编排已产品化；1M 上下文不等于可直接投放整库数据，仍需权限切片检索。
- **证据：** [Google Blog](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-hydrogen/)（2026-11-12 发布，11-16 更新）；[Model Card](https://deepmind.google/models/model-cards/gemini-4-hydrogen/)（2026-11-12）。

### 2. [国外｜近7天] Anthropic 发布 Claude Fable 5.2 / Mythos 5.2：高风险能力与多 Agent 编排分层
- **厂商/产品：** Anthropic / Claude Fable 5.2、Mythos 5.2（11月9日）。
- **能力与价格：** 编程、推理、视觉、Computer Use 与长程技术任务升级；标准价输入 $8/百万、输出 $40/百万 token，Fast mode 输入 $16、输出 $80；官方称比 5.1 输出快最高 30%。
- **Agent 机制：** Fable 可作为 Advisor 或 Orchestrator，把较简单任务委派给小模型；Mythos 的网络/生物能力限定在验证计划中，形成“通用可用模型—受控高风险能力”的双层产品。
- **企业部署影响：** 高阶模型不适合全量跑日常任务，应只给复杂规划、跨系统判断和审核；高风险能力必须以合格人员授权、可追溯任务边界使用。
- **证据：** [Anthropic 公告](https://www.anthropic.com/claude-fable-and-mythos-5-2)（2026-11-09）；[System Card](https://www.anthropic.com/document/claude-fable-5-2-mythos-5-2-system-card)。

### 3. [国外｜11月16日] OpenAI：Computer-use Agent 走向“审批 + 审计 + 单任务成本”运营
- **厂商/产品：** OpenAI / GPT-6 Astra、GPT-6 Luna 与 Computer Use。
- **能力变化：** 官方在医疗行政工作流中披露：Astra 在 HealthAdminBench 取得 94.3% rubric 分数；Luna 为 91.8%，单任务成本 8.5 美分（官方实验条件）。能力已通过 API、ChatGPT for Healthcare/Clinicians 提供。
- **治理：** 支持配置审批与 Agent 访问范围、角色权限、审计日志；案例强调操作截图、动作记录与人工复核。
- **企业部署影响：** 对 CRM 的启示是：真正价值在跨旧系统执行，而非聊天；但写回客户资料、触达、营销动作必须留在“人审后提交”而非全自动。
- **证据：** [OpenAI](https://openai.com/index/advancing-computer-use-for-healthcare-teams/)（2026-11-16）。

### 4. [国外｜11月12日生效] Anthropic 更新 Usage Policy：高风险业务必须可干预、须告知 AI 使用
- **变化：** 健康、金融、法律权利、就业/生计和基本服务等高风险场景，需要有权修改建议的合格人员参与，并告知受影响人使用了 AI；对自主物理行动还要求操作者可观察、可停止及安全停机。
- **企业部署影响：** 营销推荐、信用/权益、客户服务自动决策等，均要落地“人工确认、对客户告知、审计证据”。
- **证据：** [Anthropic Policy Update](https://www.anthropic.com/news/2026-usage-policy-update)（2026-10-08 发布，2026-11-12 生效）。

### 5. [国外｜近7天] Mistral 聚焦企业 Agent、模型/数据/基础设施控制权
- **平台动作：** Mistral 11月5日公开的企业 Agent/工作流主张，继续将“控制模型、数据与基础设施”作为卖点。
- **判断：** 在跨境、政企、欧洲客户场景，主权部署与数据驻留已成为与性能并列的采购指标；对中国 SaaS 出海客户需准备区域部署与模型替代方案。
- **证据：** [Mistral News](https://mistral.ai/news/)（2026-11-05）。

### 6. [国外｜近7天] xAI API 完成图像模型迁移，供应商版本治理是常态
- **变化：** `grok-imagine-image-quality` 已于 11月2日退役，迁向 `grok-imagine-image-2.0`；官方文档 11月13日仍提示该迁移。
- **企业部署影响：** 不要在业务逻辑硬编码模型名；统一模型别名、版本回归测试、灰度/降级和供应商迁移预案，应成为网关的标配能力。
- **证据：** [xAI Migration Guide](https://docs.x.ai/developers/migration/imagine-image-quality-nov-2)；[xAI Release Notes](https://docs.x.ai/developers/release-notes)。

### 7. [国外｜趋势基线] OpenAI 将 Agent 自主性与“人类意图/副作用控制”绑定
- **变化：** 更新后的 Model Spec 以人类意图忠实性、伤害最小化、诚实透明、人类自主性、关怀五项价值重构，并新增对上下文、监督、行动副作用的更明确要求。
- **企业部署影响：** 未来 Agent 采购/验收应加入：是否越权、是否能解释、失败时是否停下、是否能让人接管，而不只测回答正确率。
- **证据：** [OpenAI Model Spec Update](https://openai.com/index/updated-model-spec/)（2026-10-29）。

### 8. [国内｜11月13日] DeepSeek 发布“全家桶应用 API”，V4.1-Flash 获得托管工具链
- **厂商/产品：** DeepSeek / V4.1-Flash（`deepseek-flash`）。
- **能力变化：** 在 Messages、Responses、Chat Completions 中集成联网/深度思考搜索、文件输入、读链接；开放 Search、Fetch、OCR、ASR、TTS 独立接口。服务端处理工具调用和上下文拼接；可开启输入输出安全校验。
- **价格/部署：** 除 token 外收取工具调用费；官方明确，对外服务方仍需承担内容安全审核、模型登记、AI 标识等义务。
- **对 CRM/EZR 的机会：** 可快速构建带资料理解、语音质检、知识问答和检索溯源的客服/导购助手；但应控制外部联网、附件上传、链接抓取的数据范围。
- **证据：** [DeepSeek 官方公告](https://api-docs.deepseek.com/zh-cn/news/news261113/)（2026-11-13）；[更新日志](https://api-docs.deepseek.com/zh-cn/updates/)。

## C. 对中国 ToB SaaS/CRM 的影响判断

### 增长
- **机会：** 客户经营 Agent 的壁垒将从“能否对话”转成“是否能调用客户、商品、交易、导购互动和流程权限，并交付可验证结果”。
- **优先场景：** 客户档案自动摘要、线索分级与下一步建议、导购跟进话术、工单归因、活动复盘、门店语音质检、图片/附件理解。
- **商业化：** 可采用“基础 AI 助手 + 用量包 + 高价值结果型 Agent 包”，但要提供任务级账单与客户可见的权限边界。

### 效率
- **建议架构：** 低风险高频任务（摘要、分类、抽取）走国内 Flash/轻量模型；复杂诊断、策略和多工具编排走高能力模型；复杂跨系统操作只在审批链路下执行。
- **度量标准：** 每类任务同时衡量完成率、正确率、时延、token/工具费、人工回退率、投诉/误操作率；只比较 token 单价会误导决策。

### 风险
- **私域数据外流：** 会员画像、交易、导购聊天、合同、品牌经营数据采用字段级脱敏、最小化传输、租户隔离与检索权限继承；附件/链接/联网工具需单独开关。
- **模型路由成本：** 新“App 能力 API”会把工具费叠加到 token 费；必须记录模型版本、缓存命中、工具调用、单任务总成本和失败重试。
- **权限与审计：** 对营销触达、客户写回、工单变更、优惠/权益推荐实行 RBAC、双重确认、审批、审计、回滚和一键停用。
- **供应商连续性：** 模型退役与区域/政策限制已成常态；建设 API 抽象层、模型别名、黄金评测集和降级预案。

## 对 EZR 的影响（单独提炼）

1. **建设 EZR Agent Gateway：** 统一供应商适配、任务分级路由、租户/字段脱敏、权限注入、工具白名单、成本台账、评测和审计回放；模型调用不得直接散落在业务服务中。
2. **启动“附件/语音资料智能化”试点：** 选一个客户成功或销售支持团队，以脱敏录音、工单附件、商品资料为输入，验证 ASR/OCR/文件理解对人均处理时长、质检覆盖率和建议采纳率的提升。
3. **建立 CRM 高影响动作控制线：** 营销发送、客户资料写回、权益建议、跨系统操作，统一默认草稿/建议模式；仅在规则满足、人工审批和全量日志开启后提交。

## D. 今日可执行动作（3条）

1. **48 小时内完成模型网关账本字段定义：** 模型/版本、租户、任务类型、输入输出 token、缓存、工具调用、响应时延、成功/人工回退、总成本、审批人、执行轨迹；作为所有新 Agent 接入硬门槛。
2. **本周跑一个“DeepSeek App API vs Qwen 多模态”脱敏 PoC：** 用 30 条真实结构的 CRM 附件/语音/网页知识样本，比对资料抽取准确率、引用可核验性、单任务总成本、失败处理与数据出域；禁止接生产客户数据。
3. **两周内冻结 CRM Agent 高风险动作清单：** 写回客户、营销发送、权益/折扣、跨系统操作一律审批；同步补齐工具白名单、字段脱敏、租户隔离、审计回放和供应商替换演练。
