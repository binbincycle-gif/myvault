# 国内外AI大模型最新情报深读（管理层版）

> 核验口径：优先厂商官方公告、产品/价格/生命周期文档；截至 2026-11-06 08:10（Asia/Shanghai）。本窗口海外“新旗舰文字模型”发布有限，重点变化转向多模态、平台治理和 Agent 基础设施。营销软文、榜单、无发布日期或无法交叉核验的二手信息已过滤，不作为选型依据。

## A. 今日结论

1. **海外竞争的焦点继续从单一模型分数迁至“受治理的 Agent 执行能力”。** OpenAI 对模型路由/AI Gateway 提出审批与一致安全标准；Anthropic 把长程自主工作、物理执行、高风险行业和反欺诈纳入更细政策；Google 当日出现 Gemini Omni 1.2 Flash 模型卡。企业价值不再只是“会回答”，而是能否在受控的工具、身份、数据与沙箱内执行。
2. **国内能力正以“百万上下文 + 多模态实时交互 + 开源/低成本工程 Agent”快速商品化。** Kimi K3.1 Pro、DeepSeek V4.1 Flash、阿里 Qwen-Audio 3.1 Realtime 已分别覆盖 1M 上下文/工具调用、开源视觉工程任务、实时音频+搜索+函数调用；国内模型可作为客户数据默认路径，但必须面对频繁换代、下线和计费变化。
3. **对 EZR 的决策：先做 AI Gateway 和任务评测，再扩大模型使用。** 客户、交易、私域会话、录音默认国内闭环；海外能力仅进入脱敏的研发、复杂规划或质量复核层。所有读写 CRM、外发和外部检索必须有模型版本锁定、权限边界、审批、预算与审计。

## C. 对中国 ToB SaaS / CRM 的影响判断

### 增长
- 应把 AI 交付为经营闭环：**销售拜访/导购对话 → 结构化商机和待办 → 人工确认 → 写回 CRM → 复盘**，而不是新增聊天入口。
- 语音/视觉实时能力可用于导购质检、商品/陈列辅助理解、回访建议和知识检索；首批应选择可量化业务指标的单点场景。

### 效率
- 默认路由：国内模型处理客户数据、批量处理、长文档和知识问答；海外模型只处理脱敏后的复杂研发、规划和独立质量复核。
- 用统一 AI Gateway 管住版本、上下文/输出限额、工具调用、缓存与搜索计费，避免模型下线、静默升级或无限 Agent 循环影响生产。

### 风险
- **数据合规：** 客户画像、交易、私域对话、员工绩效、录音默认不得未经审批出境；实施字段级脱敏、地域路由、租户隔离和处理台账。
- **模型路由成本：** 搜索、抓取、沙箱、长上下文和重试会显著抬升真实成本；每条业务链路都要有预算阈值和熔断。
- **私域与权限审计：** 读取、创建、修改、外发必须分层授权；高影响写操作与外发必须人工确认、支持撤回并保留完整执行证据。

## 对 EZR 的影响（单独提炼）

1. **AI Gateway MVP：** 租户级模型白名单、字段级脱敏、国内/海外路由、模型版本固定、工具凭据隔离、调用审计、预算熔断、降级和回退。
2. **首批业务闭环：** 销售录音/拜访纪要 → 结构化机会与待办建议 → 销售确认 → 写回 CRM；默认禁止无确认写回、无确认外发和无审计的外部检索。
3. **评测卡：** 用 50 条脱敏真实任务，对比 Kimi/DeepSeek/Qwen 与一款海外模型的事实准确率、字段抽取正确率、工具成功率、P95 延迟、单任务总成本、人工采纳率与越权拦截率。

## D. 今日可执行动作

1. **完成模型生命周期盘点。** 本周清查所有 `latest`、preview、Kimi K2.x 与无固定版本模型调用；为每项填入替代模型、下线日期、回归集、灰度计划和一键回退。
2. **建设任务级成本看板。** 从“销售纪要→CRM 建议”链路开始，汇总输入/输出、缓存、峰谷、搜索/工具、重试、人工复核，指标只看单任务成功成本和质量。
3. **启动 AI Gateway 治理 MVP。** 先落地租户/模型白名单、PII 脱敏、地域路由、写操作审批、工具凭据隔离、审计日志和预算熔断；海外模型仅接收脱敏后的必要字段。
