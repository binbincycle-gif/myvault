# SaaS 的 AI 能力释放思考

关注 EZR SaaS / CRM 如何从传统软件能力，升级为可被 AI Agent 调用、组合、闭环的能力体系。

## 重点问题

- 哪些 CRM 能力应被封装成 Skill / API / Agent 能力
- AI 如何提升续费、增长、交付效率和客户成功
- EZR 如何避免成为被集成层，而是成为能力提供方 / 上下文枢纽
- 数据资产、交易嵌入、导购关系如何形成 AI 时代护城河
- SaaS 功能如何从「人点页面」转向「Agent 调能力」

## 适合归档的内容

- EZR AI 能力地图
- SaaS + Skills 架构设计
- CRM 数据资产与 Agent 场景分析
- 客户成功 / 增长 / 续费 AI 方案
- AI 导购、会员洞察、营销自动化相关材料
