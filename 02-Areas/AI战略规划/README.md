## 目录说明

- `00-每日三块思考总结/`：每日围绕三条主线的复盘与带题沉淀。
- `01-组织AI转型思考/`：组织机制、AI Coding 协作、超级个体、OPD、人才评价、管理动作。
- `02-SaaS的AI能力释放思考/`：EZR SaaS / CRM 能力 Skill 化、Agent 可调用能力、Context、权限、安全、商业化。
- `03-产品能力强化思考/`：智能导购、小龙虾、智能助手、明镜台、产品项目组合、竞品产品情报。
- `04-AI情报/`：前沿 AI 大模型、Agent、工具链、海外/国内厂商动态；作为 AI战略规划的外部前沿感知库，不默认归入 SaaS。
- `PAI系统/`：PAI 日同步与周复盘运行日志归档；高价值内容应二次提炼到上面四个主题目录。
- `assets/`：架构图、流程图等图形资产。

## 使用规则

- 战略判断先放对应主题目录，不要堆在根目录。
- 前沿 AI 情报放 `04-AI情报/`，后续如形成 EZR / SaaS / CRM 落地判断，再提炼到对应主题。
- 竞品情报放 `03-产品能力强化思考/竞品情报/`。
- PAI 日同步只作为运行日志；有价值结论要二次提炼。
- 知识库治理类报告暂放根目录，后续可迁入 `07-Meta/知识库治理/`。
