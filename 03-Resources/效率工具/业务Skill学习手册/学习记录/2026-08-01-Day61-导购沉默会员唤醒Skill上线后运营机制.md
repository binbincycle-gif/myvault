## 今日抓到的核心判断

Day60 解决的是：导购沉默会员唤醒 Skill 上线前，如何判断它是否从 Demo 可用变成业务可交付。

Day61 要继续补上线后的核心问题：**Skill 上线不是结束，而是开始进入运营期；如果没有持续监控、复盘和迭代机制，Skill 很快会从“能力资产”退化成“又一个没人维护的功能”。**

> 导购沉默会员唤醒 Skill 上线后，真正要盯的不是“有没有人点”，而是：是否被正确场景调用、是否推动导购真实触达、是否产生会员响应、是否回写 CRM、是否能基于失败原因继续优化策略。

如果上线后缺少运营机制，会出现四类问题：

1. **使用假繁荣**：打开次数高，但导购没有采纳、没有触达、没有回写。
2. **效果黑盒**：生成了名单和话术，但不知道哪些有效、哪些无效。
3. **策略老化**：沉默会员规则、权益推荐、话术模板长期不更新，效果持续下降。
4. **责任悬空**：产品、运营、实施、技术都能看到问题，但没人负责持续改。

## 导购沉默会员唤醒 Skill｜上线后运营机制 v0.1

| 模块 | 上线后必须运营什么 |
|---|---|
| 调用监控 | 每日调用次数、调用入口、触发场景、调用失败原因 |
| 使用转化 | 名单查看率、建议采纳率、话术编辑率、实际触达率 |
| 业务结果 | 客户响应率、复购/唤醒率、客单贡献、权益使用率 |
| 失败沉淀 | 未采纳原因、触达失败原因、客户无响应原因、权限/数据异常原因 |
| 策略迭代 | 沉默周期规则、会员优先级模型、权益推荐规则、话术模板优化 |
| 角色复盘 | 导购看任务完成，店长看过程质量，总部看策略效果，产品看能力迭代 |
| 风险监控 | 越权拦截、免打扰拦截、权益冲突、批量触达审批、异常投诉 |
| Owner 节奏 | 日看异常、周看效果、月看策略，不允许上线后无人维护 |

## 上线后建议建立的 3 张看板

```text
1. 使用看板：判断有没有被真实使用
- DAU / WAU
- 调用次数
- 名单查看率
- 话术采纳率
- 实际触达率

2. 效果看板：判断有没有带来经营结果
- 客户响应率
- 复购/唤醒率
- 成交金额
- 权益核销率
- 不同门店/导购效果对比

3. 异常看板：判断是否可控、可修
- 权限不足次数
- 数据不足次数
- 免打扰拦截次数
- 权益冲突次数
- 未采纳/失败原因 Top5
```

## 管理提醒

1. **上线后先盯漏斗，不要只盯调用量。** 调用量只能证明有人打开，不能证明产生经营动作。
2. **失败原因比成功案例更有价值。** 未采纳、无响应、触达失败，是下一轮策略优化的入口。
3. **Skill 的复利来自回写。** 没有 CRM 回写，就没有后续学习、评估和策略迭代。
4. **运营机制要轻，但不能没有。** 第一版可以只做日异常、周复盘、月优化，不要一开始做重。
5. **Owner 要从上线前延续到上线后。** 产品负责能力迭代，业务负责策略有效，技术负责稳定和安全。

## 晚上复盘问题

1. 今天是否定义清楚“调用成功”和“业务成功”的区别？
2. 导购从看到建议到完成触达，中间哪一步流失最大？
3. 未采纳、无响应、失败原因是否已经结构化回写？
4. 哪一个策略最需要下周优先优化：会员筛选、推荐理由、权益策略，还是话术模板？
5. 如果这个 Skill 扩到 10 个品牌，当前运营机制是否还能撑住？
