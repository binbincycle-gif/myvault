## 今日抓到的核心判断

Day21 的重点是：业务 Skill 不是从“我要做一个 AI 功能”开始，而是从真实客户/员工场景开始，反推出角色、目标、输入、判断、动作、反馈和风险。

导购沉默会员唤醒 Skill 已经走过 v0.3 的异常复盘、灰度扩围和下线归档，今天需要重新回到蓝图层做一次 v0.4 重审：

1. 这个 Skill 服务的真实场景是否仍然成立。
2. 角色、输入、动作、反馈是否已经从单点建议升级为经营闭环。
3. 哪些能力应该继续作为独立 Skill，哪些应该并入新版导购工作流。

> Skill 蓝图不是一次性设计稿，而是每轮试点、扩围、异常和归档之后，都要回头校准的能力施工图。

## v0.4 重审重点：从“单一唤醒 Skill”升级为“导购经营工作流蓝图”

v0.3 主要围绕沉默会员唤醒单点能力治理。v0.4 要判断：它是否应该继续单独存在，还是作为智能导购 / 导购小龙虾的一段标准工作流。

### 1. 客户场景重审

| 蓝图元素 | v0.4 要回答的问题 | 当前判断 |
|---|---|---|
| 角色 | 谁真正使用，谁为结果负责 | 导购使用，店长/运营看结果，产品/技术维护能力 |
| 目标 | 最终改善什么业务结果 | 沉默会员重新触达、响应、到店、复购或成交 |
| 输入 | AI 必须拿到哪些上下文 | 会员归属、沉默周期、消费偏好、互动记录、权益/活动、库存或商品信息 |
| 判断 | AI 要做什么决策辅助 | 是否值得唤醒、为什么唤醒、适合什么权益/商品/话术 |
| 动作 | 输出什么可执行建议 | 推荐名单、推荐理由、触达话术、触达优先级、下一步任务 |
| 反馈 | 结果如何回流 | 是否采纳、是否触达、客户反馈、成交/未成交、跳过原因 |
| 风险 | 哪些必须受控 | 权限越界、权益误承诺、重复触达、会员归属口径、导购不信任 |

### 2. 能力链路重拆

```text
业务闭环：提升导购沉默会员唤醒转化
  ↓
关键动作：识别机会 → 判断价值 → 推荐动作 → 生成话术 → 人工确认 → 触达回写 → 效果复盘
  ↓
Skill 单元：会员机会识别 / 偏好洞察 / 商品权益推荐 / 话术生成 / 反馈记录 / 转化归因
  ↓
Agent 工作流：导购小龙虾按场景编排多个 Skill
  ↓
CRM 回流：沉淀动作、结果、异常和版本证据
```

### 3. v0.4 蓝图卡片

```text
Skill / 工作流名称：导购沉默会员唤醒工作流 v0.4
业务目标：帮助导购优先跟进有唤醒价值的沉默会员，并把触达结果回写 CRM
使用角色：导购；管理查看：店长/运营；能力维护：产品/技术/数据
最小闭环：名单识别 → 推荐理由 → 话术建议 → 导购确认 → 触达结果回写
输入上下文：会员归属、沉默周期、消费记录、偏好标签、活动权益、库存/商品、历史互动
输出内容：推荐名单、唤醒理由、建议话术、权益/商品建议、风险提醒
动作权限：默认只建议，不自动触达；涉及权益承诺必须人工确认
反馈字段：是否采纳、是否触达、客户反馈、成交结果、跳过原因、异常标记
验收指标：使用率、采纳率、触达率、客户响应、成交/复购、异常率、导购修正率
暂停条件：P0/P1 异常、权限争议、权益口径变化、重复触达升高、数据链路不稳
归档策略：被新版智能导购工作流覆盖后，旧 Skill 标记废弃并保留历史留痕
```

## 6 个 Skill 单元的最小验收

| Skill 单元 | 最小验收问题 |
|---|---|
| 会员机会识别 | 能否说清“这个会员为什么今天值得唤醒”？ |
| 会员偏好洞察 | 能否给出可解释的偏好、禁忌和历史依据？ |
| 商品/权益推荐 | 能否推荐具体商品/权益，并校验适用规则？ |
| 导购话术生成 | 话术是否符合品牌、会员状态和人工确认边界？ |
| 触达反馈记录 | 导购动作和客户反馈是否能结构化回写？ |
| 转化归因 | 能否把本次唤醒动作和后续成交/复购建立可复盘关联？ |

## 管理提醒

1. 不要把“沉默会员唤醒”只做成话术生成器，它的价值在识别、触达、回写和复盘闭环。
2. Skill 单元可以分开验收，但产品上要让导购感知为一条自然工作流。
3. 权限、权益和触达频控必须前置设计，不能等扩围后再补。
4. v0.4 的目标不是做大，而是把“最小可验证经营闭环”做稳。
5. 如果旧 Skill 与新版智能导购工作流并存，必须明确入口优先级和替代节奏。

## 晚上复盘问题

1. 今天是否把导购沉默会员唤醒从“单点 Skill”重审为“工作流蓝图”？
2. 6 个 Skill 单元里，哪一个已经可以独立验收，哪一个还缺数据/接口/规则？
3. 最小闭环是否真的包含结果回写，而不是只停留在生成名单和话术？
4. 如果导购不采纳推荐，是否能记录跳过原因并反哺下一版？
5. v0.4 应该继续独立运营，还是并入智能导购 / 导购小龙虾主工作流？

## 一句话沉淀

导购沉默会员唤醒 Skill v0.4 的关键，不是再多写一个 AI 能力，而是把“识别机会、推荐动作、人工确认、触达回写、效果复盘”串成一条可验收、可治理、可持续进化的导购经营工作流。
