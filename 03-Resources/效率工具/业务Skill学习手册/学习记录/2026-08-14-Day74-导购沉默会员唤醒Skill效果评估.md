## 导购沉默会员唤醒 Skill｜效果评估 v0.1

### 1. 三层指标框架

| 层级 | 核心问题 | 建议指标 |
|---|---|---|
| 调用层 | 有没有被目标用户用起来 | 调用次数、活跃导购数、活跃门店数、成功率、平均耗时 |
| 过程层 | 有没有改变导购跟进流程 | 名单查看率、建议采纳率、话术修改率、触达完成率、未采纳原因 |
| 结果层 | 有没有改善会员经营结果 | 客户回复率、沉默会员唤醒率、复购率、成交金额、投诉/反感率 |

管理上不要只看调用量。调用量高但采纳低，说明建议不准；采纳高但触达低，说明导购执行卡住；触达高但转化低，说明人群或权益策略不对。

### 2. 建议核心指标口径

| 指标 | 口径 | 用途 |
|---|---|---|
| 名单查看率 | 已查看名单导购数 / 被推送导购数 | 判断导购是否愿意打开 |
| 建议采纳率 | 被采纳建议数 / 生成建议数 | 判断 AI 推荐是否有用 |
| 话术修改率 | 人工修改话术数 / 生成话术数 | 判断话术是否贴近品牌和导购风格 |
| 触达完成率 | 实际触达会员数 / 计划触达会员数 | 判断导购执行是否跑通 |
| 客户回复率 | 有回复会员数 / 已触达会员数 | 判断触达是否有效 |
| 唤醒成功率 | 触达后到店/消费会员数 / 已触达沉默会员数 | 判断业务结果 |
| 投诉/反感率 | 负反馈会员数 / 已触达会员数 | 判断风险是否可控 |

### 3. 分阶段评估建议

#### v0.1 内部验证
- 重点看：名单生成成功率、推荐理由准确性、权限边界是否正确。
- 不急着看成交结果。

#### v0.2 小范围灰度
- 重点看：导购采纳率、话术修改率、触达完成率、负反馈。
- 判断导购是否真的愿意用。

#### v0.3 试点门店
- 重点看：客户回复率、沉默会员唤醒率、复购率、门店执行复盘。
- 判断是否值得扩围。

#### v1.0 标准交付
- 重点看：跨门店稳定性、ROI、审计完整率、异常率、客户可汇报指标。
- 判断是否可包装成标准产品能力。

## 今天可落地动作

如果继续推进智能导购 / 导购小龙虾，建议补一张《导购沉默会员唤醒 Skill 效果评估表》：

1. 先确定本轮只看 5 个核心指标：名单查看率、建议采纳率、触达完成率、客户回复率、唤醒成功率；
2. 每个指标明确数据来源：CRM、导购任务、触达记录、成交记录、客户反馈；
3. 明确最小观察周期：至少 7 天，不用单日波动拍板；
4. 补一个风险指标：投诉/反感率必须纳入扩围门槛；
5. 周会只问：扩、改、停、还是继续灰度。

管理上只问一句：**这个 Skill 今天有没有让导购更容易做出正确动作，而不是只生成了更多内容？**

## 管理提醒

1. **不要只看调用次数。** 高频调用不等于高价值。
2. **不要只看 AI 指标。** 准确率是底线，业务结果才决定继续投入。
3. **不要过早承诺销售提升。** 先证明流程变短、动作更准，再看转化。
4. **不要忽略负反馈。** 沉默会员触达如果打扰过度，会伤害客户关系。
5. **不要让指标太多。** 试点期抓 3-5 个关键指标即可。

5. 这项 Skill 下一步应该扩围、修改、暂停，还是继续观察？
