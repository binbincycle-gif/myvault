## 导购沉默会员唤醒 Skill｜目录发布与生命周期运营 v0.1

### 1. Skill 目录登记卡

| 字段 | 建议内容 |
|---|---|
| Skill 名称 | 导购沉默会员唤醒建议 Skill |
| 适用场景 | 沉默会员唤醒、老客复购、导购跟进名单、会员激活、门店经营复盘 |
| 目标用户 | 导购、店长、区域运营、总部运营、智能导购 Agent |
| 输入要求 | 品牌/门店/导购范围、沉默周期、会员权限范围、当前活动/权益、输出用途 |
| 核心输出 | 唤醒名单、分组理由、跟进优先级、导购话术、风险提示、CRM 回写字段、复盘指标 |
| 权限边界 | 导购只看自己会员池；店长看本店；运营看授权区域/品牌；Agent 不自动触达/发券/批量写回 |
| 负责人 | 产品负责人 + 技术负责人 + 运营/客户成功负责人 |
| 当前状态 | Draft / Beta / GA / Maintain / Deprecated 选择其一 |
| 核心指标 | 名单查看率、建议采纳率、触达完成率、客户回复率、唤醒成功率、投诉/反感率 |
| 审计要求 | 记录操作者、角色、数据范围、动作类型、审批状态、输出摘要、回写字段、风险标记 |

### 2. 发布流程

```text
Draft 草稿定义 → Beta 内部/小范围灰度 → GA 正式发布 → Maintain 持续运营 → Deprecated 下线归档
```

| 阶段 | 通过标准 | 不允许跳过的检查 |
|---|---|---|
| Draft | 场景、输入、输出、权限边界说清楚 | 不能只有 prompt，没有业务闭环 |
| Beta | 单品牌/单门店能跑通，导购有真实反馈 | 权限、审批、审计、异常降级必须可用 |
| GA | 指标证明值得复制，风险可控 | 版本号、回滚方案、客户可见说明必须齐备 |
| Maintain | 按周/月看指标，持续优化 | 不能只新增能力，不看效果 |
| Deprecated | 有替代方案、下线时间、历史数据处理方式 | 不能静默下线影响客户流程 |

### 3. 生命周期运营规则

#### 扩围条件
- 名单查看率、建议采纳率、触达完成率达到试点门槛；
- 投诉/反感率低于风险红线；
- 权限、审批、审计没有高风险缺口；
- 试点门店/导购能说清楚实际价值。

#### 优化条件
- 导购打开但不采纳：优化推荐理由和话术；
- 采纳但不触达：优化任务节奏、提醒机制、店长督导；
- 触达但没结果：优化人群口径、权益策略、触达时机；
- 负反馈上升：收窄触达范围，增加人工确认。

#### 暂停/下线条件
- 权限或审计不完整；
- 投诉/反感率超过红线；
- 关键指标连续两个周期无改善；
- 业务流程已被新 Skill 替代；
- 客户场景变化导致原 Skill 不再适用。

## 今天可落地动作

如果今天继续推进智能导购 / 导购小龙虾，建议做一件很具体的事：

**把导购沉默会员唤醒 Skill 正式登记进“智能导购 Skill 目录 v0.1”。**

目录里先放 4 个能力：
1. 今日重点会员推荐；
2. 沉默会员唤醒分析；
3. 会员触达话术生成；
4. 导购执行复盘。

每个能力都标注：负责人、状态、输入、输出、权限、指标、下一次评审时间。

管理上只问一句：**这个 Skill 现在是个人会用，还是组织能找得到、用得起、管得住、可复盘？**

## 管理提醒

1. **不要让 Skill 藏在个人电脑或项目群里。** 找不到，就不是组织资产。
2. **不要把能跑当正式发布。** 正式发布必须有权限、审计、指标、负责人和回滚。
3. **不要只上架不下架。** 没效果、风险高、无人负责的 Skill 要停掉。
4. **不要让目录变成静态清单。** 每周至少更新状态和指标一次。
5. **不要忽略客户可见口径。** ToB Skill 发布必须能让交付、客服、客户成功讲清楚边界。
