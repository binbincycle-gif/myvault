## 今日抓到的核心判断

Day67 已经把导购沉默会员唤醒 Skill 从蓝图压缩成 MVP：

```text
AI 推荐会员 → 导购理解理由 → 导购确认触达 → 触达结果回写 → 晚上能复盘
```

Day68 要继续往前走一步：**MVP 不是跑完就算完成，必须用复盘判断它值不值得放大。**

复盘不能只看 AI 推荐得准不准，也不能只看导购说好不好用，而要看四层证据：

1. 有没有真实调用
2. 有没有真实触达动作
3. 有没有业务结果变化
4. 有没有沉淀出可复用经验

一句话：**导购沉默会员唤醒 Skill 的复盘，不是验收一个功能，而是判断一条会员经营动作链是否值得复制。**

## Day68 复盘口径：四层证据

| 层级 | 要回答的问题 | 导购沉默会员唤醒 Skill 的证据 |
|---|---|---|
| 调用证据 | 导购有没有真的用 | 使用导购数、连续使用天数、每日调用次数 |
| 动作证据 | 用完有没有触达 | 推荐采纳率、触达率、话术改写率、反馈记录率 |
| 结果证据 | 触达有没有价值 | 客户回复率、到店/加购/成交线索、负反馈率 |
| 沉淀证据 | 是否能变成组织资产 | 有效推荐理由、可复用话术、未采纳原因、风险边界 |

如果只有调用，没有触达，说明 Skill 只是“看起来有用”。

如果有触达，没有反馈字段，说明无法复盘，后续只能靠感觉判断。

如果有结果，但没有沉淀规则和话术，说明还停留在个人经验，没有变成组织能力。

## 三类决策标准

### A. 值得放大

满足条件：

```text
试点导购连续 5 天使用
推荐采纳率 ≥50%
触达反馈记录率 ≥70%
客户负反馈可控
至少沉淀 10 条有效推荐理由或话术样本
```

下一步：进入灰度发布，扩大到更多门店 / 导购，但仍保持人工确认和反馈回写。

### B. 继续小范围迭代

典型情况：

```text
导购愿意用，但推荐理由不够稳
触达发生了，但反馈字段填写不完整
有客户回复，但成交或复购趋势还不明显
风险可控，但场景边界需要再收窄
```

下一步：不要急着扩围，先优化输入数据、推荐理由、话术结构和反馈字段。

### C. 暂停 / 回到蓝图

典型情况：

```text
导购不使用
使用后不触达
触达后不回写
客户反感明显
需要大量人工兜底才能运行
权限或触达风险不可控
```

下一步：暂停扩围，重新判断场景是否选错、输入是否不足、导购动作是否不成立。

## 今天可落地动作

今天如果继续推进智能导购 / 导购小龙虾，不建议继续加功能，建议补一页《导购沉默会员唤醒 Skill MVP 复盘卡》。重点补齐：

| 模块 | 必填内容 |
|---|---|
| 调用 | 谁用了、用了几次、是否连续用 |
| 动作 | 是否采纳、是否触达、是否改写话术 |
| 结果 | 是否回复、是否到店/加购/成交、是否反感 |
| 沉淀 | 有效理由、有效话术、未采纳原因、风险边界 |
| 决策 | 放大、迭代、暂停三选一 |

管理上只问一句：**这个 MVP 跑 5 天后，我们能不能基于数据拍板，而不是基于感觉拍板？**

## 管理提醒

1. **不要把复盘会开成功能评审会。** 功能问题可以记录，但复盘核心是“是否值得放大”。
2. **不要只看生成质量。** 导购有没有触达、有没有回写，比话术漂不漂亮更重要。
3. **不要事后补数据。** MVP 开跑前就要把调用、采纳、触达、结果、异常字段埋好。
4. **不要盲目扩围。** 没有连续使用、动作证据和风险边界，就不能进入规模化。
5. **复盘后必须沉淀资产。** 至少沉淀规则、话术、字段、边界或暂停原因之一。

## 晚上复盘问题

1. 今天是否补齐了导购沉默会员唤醒 Skill 的 MVP 复盘卡？
2. 当前试点数据能否支撑“放大 / 迭代 / 暂停”的判断？
3. 导购使用后是否产生了真实触达，而不是只看了 AI 推荐？
4. 反馈字段是否足够支撑每天晚上复盘：采纳、触达、回复、成交、反感、未采纳原因？
5. 本轮试点如果结束，能沉淀出哪些组织资产：推荐规则、话术模板、字段口径、风险边界？

## 今日一句话

> 导购沉默会员唤醒 Skill 的 MVP 复盘，不是证明 AI 推荐很聪明，而是证明这条“AI 建议—导购触达—客户反馈—CRM 回写”的业务动作链，是否值得被组织复制。
