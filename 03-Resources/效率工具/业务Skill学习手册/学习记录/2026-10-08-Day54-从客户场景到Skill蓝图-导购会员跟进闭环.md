# Day54｜从客户场景到 Skill 蓝图：导购会员跟进闭环

## 今天学什么

前 20 天把 Skill 的认知、编写、发布、运营、评审、下线走完了一遍。Day54 回到起点：**怎么从一个真实客户场景，反推出一组可落地的 Skill 蓝图。**

核心原则：**Skill 不从“我想做个 AI 功能”开始，而从“客户/员工在真实场景里要完成什么结果”开始。**

## 当前业务场景

### 业务目标
导购每天优先跟进最值得行动的会员，提升成交/复购机会。

### 角色与目标
- 使用者：导购；管理者：店长/运营；受益对象：品牌会员。
- 目标：从“凭经验找人”升级为“基于 CRM 数据识别机会并执行动作”。

### 输入上下文
会员基础信息、最近消费记录、偏好品类/尺码/风格、最近互动记录、优惠券/活动/库存、品牌会员运营规则。

## Skill 蓝图（7 元素拆解）

| 元素 | 本场景回答 |
|---|---|
| 角色 | 导购（用）/ 店长·运营（管）/ 会员（受益） |
| 目标 | 提升会员跟进转化与复购 |
| 输入 | 画像、消费、偏好、互动、权益、运营规则 |
| 判断 | 是否值得跟进、适合什么商品、风险点是什么 |
| 动作 | 推荐名单、推荐理由、沟通话术、下一步任务 |
| 反馈 | 是否触达、是否成交、是否复购 |
| 风险 | 权限、口径、误推荐、客户敏感信息 |

## 三层结构

```text
业务闭环层：提升导购会员跟进与成交转化
  ↓
能力动作层：识别机会 → 生成推荐 → 生成话术 → 记录反馈 → 复盘效果
  ↓
Skill 单元层：会员洞察 / 商品推荐 / 话术生成 / 反馈归因 Skill
```

## Skill 单元与最小验收

| Skill 单元 | 最小验收问题 |
|---|---|
| 会员机会识别 | 能否说清“这个会员为什么值得跟进”？ |
| 会员偏好洞察 | 能否给出偏好、风险、历史购买特征？ |
| 商品/权益推荐 | 能否给出“推荐什么 + 为什么 + 风险提醒”？ |
| 导购话术生成 | 话术是否符合品牌、场景与客户状态？ |
| 触达反馈记录 | 能否记录是否触达、会员反应、下一步？ |
| 转化归因 | 能否把导购动作与成交/复购关联？ |

**最小闭环先定为**：会员机会识别 → 推荐理由 → 导购话术 → 触达反馈。跑通这条链，就已经不是单点 AI 功能，而是导购智能体雏形。

## 今日可执行动作

1. 把当前 CRM Agent 立项卡里的能力，按上表拆成**可独立验收的 Skill 单元**，标出哪一个是第一个可验收单元（建议“会员机会识别”）。
2. 为每个单元写一句**最小验收口径**（问题式），作为 Demo 的验收标准。
3. 确认最小闭环的**反馈回流点**：触达结果与转化结果分别回写到 CRM 的哪张表、哪个字段。

## 晚间复盘

1. 今天我能否选出一个真实场景，而不是泛泛说“做 AI 能力”？
2. 这个场景是否已拆成“识别、判断、推荐、执行、反馈”几个动作？
3. 哪一个动作最适合作为第一个可验收 Skill？结果能否回流 CRM 形成复盘？

## 一句话结论

**业务 Skill 蓝图的价值，不是把功能拆小，而是把一个真实业务结果拆成 Agent 可调用、可验证、可复盘的能力链路。**
