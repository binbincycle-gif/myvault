## 今日抓到的核心判断

Day52 已经明确：导购沉默会员唤醒 Skill 不能只生成话术，必须记录导购采纳、客户反馈、转化结果和风险事件。

Day53 往前推进一步：**这些数据不能只躺在日志里，而要进入一张运营看板，持续触发“扩、改、停、沉淀”的管理动作。**

今天阅读 Day17 后，最重要的判断是：

> Skill 上线不是结束，而是进入运营。导购沉默会员唤醒 Skill 是否值得扩大，不看生成多少建议，而看采纳率、触达完成率、客户响应、转化观察和风险是否可控。

如果没有运营看板，试点结果会变成零散反馈；如果有看板，才能把一次试点变成可复用的经营能力产品。

## 导购沉默会员唤醒 Skill｜运营看板 v0.1

| 看板模块 | 核心指标 | 管理判断 | 触发动作 |
|---|---|---|---|
| 使用指标 | 活跃导购数、门店覆盖数、推荐任务查看率、Skill 调用次数 | 是否真的被一线看到和使用 | 低使用：检查入口、任务推送、导购培训 |
| 质量指标 | 推荐成功率、推荐理由完整率、话术采纳率、人工修改率、生成失败率 | AI 建议是否可信、可用 | 修改率高：优化会员画像、话术模板和场景规则 |
| 过程指标 | 导购采纳率、触达完成率、结果回写率、未触达原因分布 | 是否跑通“建议 → 行动 → 回写”闭环 | 回写低：简化回写入口，增加默认选项 |
| 业务指标 | 客户回复率、到店/点击/领券率、复购观察、成交金额、客单价变化 | 是否开始改善经营结果 | 指标改善：扩大灰度；无改善：重看推荐人群和权益策略 |
| 风险指标 | 客户反感率、频次超限、越权拦截、敏感词/优惠误导、投诉数 | 是否可控 | 风险升高：冻结扩围，先修权限、频控和话术边界 |
| 经验沉淀 | 有效会员类型、有效话术、有效触达时间、无效场景、不建议唤醒规则 | 是否形成组织资产 | 周度沉淀：更新规则库、案例库、导购培训材料 |

## 第一版看板建议只盯 6 个数

试点早期不要做大而全看板，先抓 6 个关键数：

1. **推荐覆盖率**：系统能为多少沉默会员给出有效判断。
2. **导购采纳率**：导购是否认可 AI 的建议。
3. **触达完成率**：采纳后是否真的触达客户。
4. **客户回复率**：客户是否产生正向响应。
5. **结果回写率**：导购是否把触达结果回写 CRM。
6. **风险事件数**：是否出现反感、投诉、频次或权限问题。

这 6 个数能回答试点阶段最关键的问题：

```text
有没有推荐 → 导购用不用 → 有没有触达 → 客户理不理 → 结果有没有回写 → 风险能不能控
```

## 周度运营动作规则

| 数据表现 | 判断 | 建议动作 |
|---|---|---|
| 采纳率高、回复率高、风险低 | 场景有效 | 扩大灰度到更多门店/品牌 |
| 采纳率高、回复率低 | 导购认可，但客户不买账 | 优化会员分层、权益策略、触达时机 |
| 采纳率低、修改率高 | AI 建议不贴近一线 | 收集导购修改样例，重训话术模板和推荐理由 |
| 触达完成率低 | 流程断在导购行动 | 检查任务提醒、操作路径、导购激励 |
| 回写率低 | 闭环断在反馈沉淀 | 简化回写字段，做一键结果选择 |
| 风险事件上升 | 扩围风险高 | 先冻结扩围，补频控、权限、敏感话术拦截 |

## 今日可落地动作

今天如果推进智能导购 / 导购小龙虾评审，不要只问“Skill 做到哪了”，改问 5 个看板问题：

```text
1. 试点看板第一版准备放哪 6 个指标？
2. 每个指标的数据从哪里来，是实时查询、业务日志，还是导购回写？
3. 谁每周看这张看板，谁决定扩、改、停？
4. 哪个指标达到什么水平，才允许扩大灰度？
5. 风险指标触发后，谁有权暂停 Skill？
```

## 管理提醒

1. **Skill 看板不是展示数据，是运营动作入口。**
2. **试点早期先看链路跑通，不要一上来压 GMV。**
3. **导购采纳率和结果回写率，是判断一线是否真实接受的两个关键数。**
4. **风险指标必须和业务指标一起看，不能只看转化不看客户反感。**
5. **每周必须形成“扩、改、停、沉淀”结论，否则看板会变成摆设。**

## 晚上复盘问题

1. 今天是否明确导购沉默会员唤醒 Skill 的第一版运营看板指标？
2. 是否确认每个指标的数据来源和责任人？
3. 是否定义了扩大灰度、冻结优化、暂停使用的触发条件？
4. 是否把客户反感、频次超限、越权拦截纳入风险指标？
5. 是否能用这张看板支持下一次项目评审，而不是靠主观反馈判断？

## 一句话沉淀

导购沉默会员唤醒 Skill 要从“上线可用”升级成“运营可控”；看板的价值不是证明 AI 很忙，而是持续判断这个能力该扩、该改、该停，还是沉淀成组织资产。
