## 今日抓到的核心判断

Day45 解决的是“导购沉默会员唤醒 Skill 能不能进目录”。Day46 要继续往后走：**进目录不是结束，必须有运营看板持续判断它是否真的创造业务价值。**

> 导购沉默会员唤醒 Skill 的运营看板，不能只看“调用了多少次”，而要同时看导购是否采纳、会员是否响应、成交是否改善、风险是否可控。

如果没有看板，这个 Skill 很容易出现四类假繁荣：

1. **调用量高，但导购不采纳**：说明推荐或话术不贴近真实销售场景。
2. **导购采纳了，但客户无响应**：说明沉默会员分层或触达理由不准。
3. **短期有成交，但投诉/误触达上升**：说明权益、频次、敏感客户边界没控住。
4. **试点门店效果好，但无法复制**：说明依赖单个导购经验，没有沉淀成可配置规则。

## 导购沉默会员唤醒 Skill｜运营看板 v0.1

| 指标类型 | 要看的问题 | 建议指标 |
|---|---|---|
| 使用指标 | 有没有进入真实导购动作 | 日调用次数、活跃导购数、试点门店数、会员推荐列表打开率 |
| 质量指标 | 输出是否稳定可信 | 话术采纳率、人工修改率、推荐理由被否定率、生成失败率 |
| 业务指标 | 是否改善经营结果 | 触达完成率、会员回复率、唤醒成交率、复购金额、沉默会员回流率 |
| 风险指标 | 是否触发不可控问题 | 投诉率、误触达率、越权拦截次数、权益/价格误导次数、敏感客户人工确认次数 |

## 看板要服务的 5 类运营动作

| 动作 | 触发信号 | 对导购 Skill 的处理 |
|---|---|---|
| 扩大灰度 | 采纳率、回复率、成交率稳定提升，风险低 | 从 1 个门店扩到 3-5 个门店，保留同一指标口径 |
| 优化策略 | 调用多但采纳低、修改率高 | 调整沉默会员分层、推荐理由、话术模板和权益匹配规则 |
| 补上下文 | 推荐失败或理由空泛 | 补会员最近消费、互动记录、可用权益、导购关系、门店库存等上下文 |
| 合并能力 | 与话术生成、重点会员推荐重复 | 收口成“导购会员经营 Skill”体系，避免多套口径并行 |
| 冻结/下线 | 投诉、误触达、越权风险上升 | 暂停自动推荐，保留人工查询或低风险建议模式 |

## 今日可落地动作

给“导购沉默会员唤醒 Skill”补一张最小运营看板，不追求大而全，先固定 8 个核心字段：

```text
1. 日期 / 门店 / 导购
2. 推荐会员数
3. 导购采纳数
4. 实际触达数
5. 会员回复数
6. 唤醒成交数
7. 人工修改/否定原因
8. 投诉、误触达、越权拦截记录
```

这张表的目的不是做报表，而是支撑每周判断：这个 Skill 是该扩大灰度、继续优化、合并到更大能力，还是先冻结。

## 管理提醒

1. **不要只看调用量。** 调用量只能说明有人试用，不能证明业务有效。
2. **必须把结果回写设计前置。** 没有导购采纳、触达、回复、成交、投诉回写，就没有运营看板。
3. **业务指标和风险指标要一起看。** 不能为了唤醒成交放大骚扰、误承诺和越权风险。
4. **每个 Skill 要有运营责任人。** 产品负责业务口径，研发负责数据与权限，试点负责人负责门店反馈和复盘。

## 晚上复盘问题

1. 今天是否明确了导购沉默会员唤醒 Skill 的 8 个最小看板字段？
2. 结果回写链路是否已经覆盖：推荐 → 采纳 → 触达 → 回复 → 成交 → 风险？
3. 当前最缺的数据是使用数据、质量数据、业务结果，还是风险记录？
4. 是否能用这张看板支撑下一次灰度决策：扩、改、合、停？
5. 是否明确了谁每周看这张表，并把结论变成版本优化或运营动作？

## 一句话沉淀

导购沉默会员唤醒 Skill 真正进入组织资产，不是从“上架”开始，而是从能被运营看板持续证明价值开始。
