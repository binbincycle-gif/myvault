## 今日抓到的核心判断

Day69 解决的是：如果 Skill 值得放大，先整理成可复制的交付包，而不是直接扩围。

Day70 要继续往前走一步：**交付包能复制，不代表已经可以产品化。产品化必须补齐配置化、权限化、可观测、可回滚、可定价五件事。**

一句话：**导购沉默会员唤醒 Skill 的产品化，不是把一个 AI 推荐入口塞进 CRM，而是把“会员经营建议”变成客户可配置、角色可授权、过程可审计、结果可证明的经营能力。**

## 导购沉默会员唤醒 Skill｜产品化判断 v0.1

```text
Skill 名称：导购沉默会员唤醒建议 Skill
当前阶段：交付型 Skill 模板 → 产品化 AI 能力候选
产品化前提：完成 Day69 交付包，并通过至少一次跨门店/跨导购复制验证

1. 配置化判断
- 沉默会员定义：按品牌配置，如 30/60/90 天未消费
- 会员分层规则：按品牌会员等级、消费频次、客单价、生命周期配置
- 活动策略：按品牌/门店配置当前活动、权益、推荐重点
- 话术风格：按品牌语气、导购风格、禁用词配置
- 触达频率：按客户反感风险、最近触达记录、渠道限制配置

判断：如果以上规则还需要研发改代码，暂不进入产品化，只能作为交付模板。

2. 权限与安全判断
- 导购：只看自己或门店授权会员；只能发起建议触达，不自动执行
- 店长：可看门店范围数据，可审批高价值客户触达或权益建议
- 区域/运营：看聚合效果与配置策略，不默认看会员明细
- 品牌管理员：配置规则、话术模板、权益边界、审计策略
- 系统：必须记录谁查看、谁采纳、谁触达、触达结果、异常处理

判断：导购场景涉及会员数据和触达动作，权限没清楚前不能扩客户。

3. 可观测判断
- 使用指标：日活导购数、建议名单查看率、建议采纳率
- 过程指标：触达完成率、客户回复率、未采纳原因分布
- 结果指标：到店率、复购率、唤醒率、成交金额、客单变化
- 风险指标：重复打扰率、客户反感率、权益错误率、投诉率
- 运营指标：不同门店/导购/品牌的采纳差异和效果差异

判断：没有看板就无法证明价值，也无法判断是否值得商业化。

4. 可回滚判断
- 支持暂停某品牌/门店/导购的 Skill 使用
- 支持禁用某条策略、话术模板或权益建议
- 支持追溯错误建议来源：数据、规则、模型、配置、人工操作
- 支持恢复到上一个稳定版本
- 支持异常触达后的客户保护规则，如冷却期、黑名单、升级处理

判断：不能停、不能查、不能恢复的 AI 能力，不适合进入客户生产场景。

5. 可定价判断
- 对客户的价值表达：减少导购筛选客户时间，提升老客复购和沉默会员唤醒
- 对管理者的价值表达：让店长/运营能看见导购跟进过程和结果
- 对续费的价值表达：CRM 不只是存会员，而是持续给出经营动作建议
- 对增购的价值表达：可包装为“智能导购 / 会员经营 AI 助手”能力包
- 对交付的价值表达：通过配置和模板降低客户化成本

判断：如果客户感知不到经营结果，只能算效率工具，不能单独产品化包装。
```

## 产品化检查清单｜导购沉默会员唤醒版

| 模块 | 必须回答的问题 | 当前建议 |
|---|---|---|
| 客户差异 | 哪些规则因品牌/门店而异？ | 先沉淀为配置项，不进定制代码 |
| 权限边界 | 谁能看会员明细，谁能执行触达？ | 导购只看授权会员，敏感动作走审批 |
| 结果反馈 | 采纳、触达、回复、成交是否回写？ | 必须结构化回写 CRM |
| 风险治理 | 错误建议、重复打扰如何停？ | 做暂停、审计、回滚、异常升级 |
| 商业价值 | 客户愿意为什么付费？ | 老客复购、沉默唤醒、导购提效、管理可视化 |

## 今天可落地动作

如果今天继续推进智能导购 / 导购小龙虾，建议不要只讨论“功能清单”。今天应该补一页《导购沉默会员唤醒 Skill 产品化判断 v0.1》，重点回答：

1. **哪些差异做配置**：沉默周期、会员分层、活动策略、话术风格、触达频率。
2. **哪些动作做权限**：查看会员、生成建议、发券承诺、触达执行、异常处理。
3. **哪些指标进看板**：查看率、采纳率、触达率、回复率、复购率、反感率。
4. **哪些风险可回滚**：策略禁用、模板回退、门店暂停、异常客户保护。
5. **客户为什么付费**：导购省时间、老客多复购、管理过程可视化、CRM 从记录系统变经营系统。

管理上只问一句：**如果这个 Skill 明天卖给第二个品牌，哪些地方不需要研发介入，只靠配置和运营就能跑？**

## 管理提醒

1. **不要把“可复制交付包”误认为“产品化能力”。** 交付包解决复制，产品化解决多客户稳定运营。
2. **不要让客户差异进入代码。** 能配置就配置，不能配置再判断是否值得标准化。
3. **不要先卖再补权限。** 导购场景天然涉及会员隐私、权益承诺、触达频率，权限和审计必须前置。
4. **不要只证明 AI 建议准确。** 更要证明导购采纳后是否带来复购、唤醒、成交和管理效率。
5. **不要把 AI 能力做成黑盒。** 客户要能知道为什么推荐、谁采纳、结果如何、出了问题怎么停。
