## 今日抓到的核心判断

Day53 已经把导购沉默会员唤醒 Skill 的运营看板 v0.1 拉出来：推荐覆盖率、导购采纳率、触达完成率、客户回复率、结果回写率、风险事件数。

Day54 要补的是另一半：**风险事件不能只是看板上的一个数字，必须能反向进入异常复盘表，并推动 Skill 版本升级。**

> 导购沉默会员唤醒 Skill 的成熟度，不是“看板能展示数据”，而是当数据异常时，能不能快速定位：是输入问题、数据问题、逻辑问题、权限问题、话术问题，还是运营频控问题。

如果异常只停留在群里解释，Skill 会越用越不可信；如果异常能沉淀成规则、字段、权限和话术模板，Skill 才会越用越强。

## 导购沉默会员唤醒 Skill｜异常复盘 v0.2

### 1. 异常来源先打通运营看板

| 看板信号 | 可能异常 | 优先排查 |
|---|---|---|
| 推荐覆盖率低 | 数据缺失 / 规则过窄 | 会员沉默口径、消费记录、权益字段是否完整 |
| 导购采纳率低 | 推荐理由弱 / 人群不准 | 会员分层、推荐优先级、导购可解释信息 |
| 触达完成率低 | 任务入口弱 / 导购不信任 | 任务提醒、操作路径、话术可用性 |
| 客户回复率低 | 话术不对 / 权益不匹配 / 时机不对 | 话术模板、权益策略、触达时间 |
| 结果回写率低 | 回写太麻烦 / 字段不清 | 一键回写、默认选项、必填字段 |
| 风险事件数升高 | 权益承诺 / 越权 / 骚扰 / 投诉 | 权限、频控、敏感词、人工确认 |

### 2. 异常分类固定 6 类

| 异常类型 | 典型表现 | 修正方向 |
|---|---|---|
| 输入异常 | 导购输入过短，缺门店、活动、会员范围 | 增加输入模板、必要字段校验、追问机制 |
| 数据异常 | 沉默天数、消费记录、权益状态不准 | 增加数据时间戳、口径版本、字段缺失提示 |
| 逻辑异常 | 推荐了低价值或高风险会员 | 补会员分层、排除规则、推荐优先级 |
| 权限异常 | 导购看到非授权会员或跨门店数据 | SaaS 实时判权、拦截日志、审计记录 |
| 话术异常 | 承诺权益过满、语气骚扰、表达误导 | 敏感词拦截、权益条件校验、人工确认 |
| 运营异常 | 多导购重复触达、频次过高、冷却期缺失 | 触达冷却期、冲突检测、主维护导购规则 |

### 3. 最小异常记录表字段

```text
1. 异常时间
2. 品牌 / 门店 / 导购（必要时脱敏）
3. 会员范围或会员类型（脱敏）
4. 导购输入
5. Skill 输出：推荐名单 / 推荐理由 / 话术片段
6. 异常来源：看板指标 / 人工反馈 / 客诉 / 系统拦截
7. 异常分类：输入 / 数据 / 逻辑 / 权限 / 话术 / 运营
8. 影响判断：效率 / 成交 / 客诉 / 越权 / 信任
9. 处理动作：修规则 / 补数据 / 加拦截 / 降级 / 暂停 / 回滚
10. 版本变更：Prompt / Schema / 数据口径 / 权限校验 / 频控规则 / 话术模板
```

## 三条红线继续保留

1. **权益字段不完整，不输出承诺型话术。** 只能输出“建议人工确认后触达”。
2. **会员归属或门店权限不清，不输出会员详情。** 必须走 SaaS 实时判权。
3. **近 N 天已有触达记录，默认降级。** 输出“暂不建议触达 / 需店长确认”，防止骚扰。

## 今日可落地动作

今天如果继续推进智能导购 / 导购小龙虾，不要只看运营看板的 6 个数，要补一个“异常到版本升级”的动作闭环：

```text
风险事件数上升
  ↓
进入异常复盘表
  ↓
按 6 类异常定位
  ↓
确定修 / 降级 / 暂停 / 回滚
  ↓
形成版本变更记录
  ↓
复测同类会员、同类门店、同类活动是否不再复发
```

## 管理提醒

1. **看板发现问题，复盘解决问题。** 两者必须连起来。
2. **不要把异常都归因给模型。** 多数问题来自数据口径、权限边界、活动规则和运营频控。
3. **会员触达类 Skill 要保守。** 先给建议，不直接自动发送。
4. **每次异常必须推动版本变化。** 没有补规则、补字段、补权限、补话术，就不算真正复盘。
5. **风险指标要有暂停权。** 风险事件连续上升时，运营负责人必须有权冻结扩围。

## 晚上复盘问题

1. 今天是否把运营看板里的风险事件，接入了异常复盘表？
2. 是否明确每类异常由谁判断、谁处理、谁决定暂停或恢复？
3. 当前最容易先爆的风险，是权益承诺、权限越界，还是触达频次？
4. 是否形成一条可以写进 Skill 版本的新增规则？
5. 下一次评审时，能不能用“看板 + 异常复盘 + 版本记录”说明这个 Skill 是否可扩围？

## 一句话沉淀

导购沉默会员唤醒 Skill 要规模化，不能只证明“它能推荐”，还要证明“它出错后能被看见、被定位、被修正、被降级、被防复发”。
