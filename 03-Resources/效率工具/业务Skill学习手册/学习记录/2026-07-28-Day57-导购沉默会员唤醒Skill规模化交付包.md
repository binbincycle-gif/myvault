## 今日抓到的核心判断

Day56 解决的是灰度跑完后，凭什么决定扩大、继续观察、降级、暂停或回退。Day57 要解决下一个问题：**如果决定扩大，不能直接“多开几个门店试试”，必须先把试点经验整理成交付包。**

> 导购沉默会员唤醒 Skill 的规模化，不是扩大使用人数，而是把一套有效导购动作链变成可复制、可培训、可审计、可复盘的组织资产。

如果没有交付包，扩围会变成三种风险：

1. **口口相传**：试点负责人懂，换一个门店/导购就走样。
2. **功能复制**：只复制入口和按钮，没有复制业务动作链。
3. **风险放大**：权限、频控、权益、话术承诺等问题随范围扩大被放大。

## 导购沉默会员唤醒 Skill｜规模化交付包 v0.1

### 1. 触发说明：什么时候该用

```text
- 每日开店前：导购查看今日优先唤醒会员
- 活动前 1-2 天：筛选适合活动触达的沉默会员
- 会员沉默预警后：识别需要优先跟进的人群
- 店长复盘时：查看导购采纳、触达和结果回写情况
```

判断重点：触发时机必须贴近日常工作流，不要变成额外负担。

### 2. 输入要求：AI 必须拿到什么上下文

```text
- 导购身份、门店、品牌、可见会员范围
- 会员最近消费、沉默天数、触达历史
- 商品偏好、尺码/品类偏好、历史客单价
- 当前活动、可用权益、门店库存/主推商品
- 会员触达频控、黑名单/免打扰状态
```

判断重点：输入不完整时，Skill 应降级输出“名单 + 原因”，不要强行给高确定性话术。

### 3. 输出标准：AI 应该给什么结果

```text
- 今日建议跟进会员列表
- 每个会员的推荐理由
- 建议触达话术
- 推荐商品/活动方向
- 风险提示：频控、权益、敏感承诺、跨门店边界
- 下一步动作：触达 / 暂不触达 / 店长确认 / 运营升级
```

判断重点：输出不能只给“会员名单”，必须解释为什么建议跟进，以及下一步怎么做。

### 4. 人工确认点：哪些地方不能自动化

```text
- 是否真正触达会员：导购确认
- 是否发券/承诺权益：按品牌规则或审批确认
- 是否升级重点客户：店长或运营确认
- 是否跨门店/跨导购调整归属：不能由 Skill 自动执行
- 是否采用敏感话术：导购必须二次确认
```

判断重点：客户触达和权益承诺必须保留人工确认，不能为了效率绕过信任边界。

### 5. 反馈字段：如何知道有没有效果

```text
- 是否采纳推荐会员
- 是否实际触达
- 客户是否响应
- 是否到店 / 加购 / 成交 / 复购
- 未采纳原因
- 话术修改原因
- 异常/负反馈类型
```

判断重点：没有反馈字段，就无法从一次执行变成持续优化。

### 6. 风险边界：哪些动作禁止自动做

```text
- 不自动发送客户消息
- 不自动发券或承诺优惠
- 不跨门店查看不可见会员
- 不绕过会员免打扰/黑名单/频控
- 不输出医疗、财务、身份等敏感推断
- 不在无审计记录下修改会员归属或标签
```

判断重点：规模化复制前，风险边界必须写清楚，否则复制越快，责任越不清。

## 推广节奏建议

### 第一步：同门店多导购复制
验证问题：换导购后是否还能用。

```text
范围：同一门店 3-5 名导购
周期：1 周
看点：导购采纳率、触达率、回写完整率、话术修改原因
```

### 第二步：同品牌不同门店复制
验证问题：换门店后，会员结构和导购习惯是否影响效果。

```text
范围：同品牌 2-3 家门店
周期：1-2 周
看点：不同门店采纳差异、频控问题、店长管理动作
```

### 第三步：不同品牌小范围试点
验证问题：是否具备配置化能力，而不是只适合单一客户。

```text
范围：选择 1 个相似品牌 + 1 个差异品牌
周期：2 周
看点：字段差异、经营口径差异、权益规则差异、培训成本
```

### 第四步：沉淀为标准 Skill 模板
验证问题：是否能进入产品化或交付包。

```text
交付物：触发说明、输入输出标准、权限边界、反馈字段、培训材料、异常复盘机制
```

## 管理提醒

1. **先交付包，再扩范围。** 没有标准包的扩围，本质是放大试错。
2. **先复制动作链，再复制功能入口。** 导购要知道何时用、看什么、怎么触达、怎么回写。
3. **每扩大一层，都要重新验证。** 同门店、跨门店、跨品牌不是同一个难度。
4. **规模化最怕风险边界没写清。** 客户触达、权益承诺、会员归属、数据权限都不能靠口头约定。
5. **最终目标不是更多人用 AI，而是组织多一套可复制经营打法。**

## 一句话沉淀

导购沉默会员唤醒 Skill 要从试点走向规模化，关键不是“开放更多账号”，而是先沉淀触发、输入、输出、确认、反馈、风险六件套，再按同门店、跨门店、跨品牌的节奏复制成组织资产。
