## 今日抓到的核心判断

Day55 已经把灰度发布 v0.2 的 G1/G2/G3、暂停、降级、回退规则补齐。Day56 要解决下一个管理问题：**灰度跑了一段时间后，到底凭什么决定扩大、继续观察、降级还是暂停。**

> 导购沉默会员唤醒 Skill 的灰度复盘，不是看“导购觉得好不好用”，而是看它有没有形成真实业务动作、结果证据和可复制资产。

业务 Skill 一旦进入灰度，就不能陷入两种误区：

1. **演示型成功**：展示效果不错，但真实导购没有持续用。
2. **感觉型扩围**：少数人反馈好，就直接扩大到更多门店。

真正能扩围的 Skill，至少要有四层证据：调用证据、动作证据、结果证据、沉淀证据。

## 导购沉默会员唤醒 Skill｜灰度复盘四层证据

### 1. 调用证据：目标导购有没有持续使用

```text
- 灰度导购人数
- 实际使用导购人数
- 连续使用天数
- 每日调用次数
- 未使用导购原因
```

判断重点：不是“有没有打开过”，而是是否进入导购日常工作流。

### 2. 动作证据：使用后有没有产生真实触达

```text
- AI 推荐会员数
- 导购采纳会员数
- 实际触达会员数
- 话术是否被大量修改
- 未采纳原因分类
```

判断重点：如果只有推荐名单，没有触达动作，Skill 仍停留在“信息提示”，没有进入经营动作。

### 3. 结果证据：动作有没有带来经营变化

```text
- 客户响应数 / 响应率
- 加购 / 到店 / 成交 / 复购线索
- 沉默会员重新互动样例
- 导购节省时间
- 异常与负反馈
```

判断重点：早期不一定要求成交显著提升，但必须看到响应、互动、线索或效率上的正向信号。

### 4. 沉淀证据：是否形成可复制资产

```text
- 有效推荐规则
- 高采纳话术模板
- 会员分层判断口径
- 结果回写字段
- 风险边界与禁用规则
- 灰度复盘案例
```

判断重点：如果试点只让一个门店变好，但没有沉淀规则和模板，就还不是组织级 Skill。

## 扩围决策表 v0.1

| 决策 | 触发条件 | 下一步 |
|---|---|---|
| 扩大到 G2 | 使用稳定、采纳 ≥50%、回写 ≥80%、高风险异常为 0、有 3 个有效样例 | 增加同品牌门店，继续只建议不自动触达 |
| 继续 G1 观察 | 场景成立，但采纳、回写或话术稳定性不足 | 固定 3-5 天补数据，不扩大范围 |
| 降级使用 | 数据口径被质疑、话术大量修改、回写不足 | 降级为名单/理由建议，不输出强话术 |
| 暂停灰度 | 越权、客诉、权益误导、重复触达负反馈 | 关闭入口，进入异常复盘和版本修正 |
| 回退上一版 | 新版本上线后异常升高 | 切回稳定规则，补版本记录与复测 |

## 管理提醒

1. **不看演示，看真实使用。** 调用证据是第一层门槛。
2. **不看生成内容，看业务动作。** 推荐名单必须转成触达、回写和复盘。
3. **不看单店亮点，看复制证据。** 有规则、模板、字段，才有扩围价值。
4. **扩围前先问风险是否可控。** 客户触达、权益、会员归属、频控必须过线。
5. **每轮灰度必须有结论。** 扩、停、降级、回退都可以，最怕长期“继续试试”。

## 一句话沉淀

导购沉默会员唤醒 Skill 能不能扩围，不取决于“AI 回答得好不好”，而取决于它是否形成了调用、动作、结果、沉淀四层证据，并能支撑一次清楚的扩大、观察、降级、暂停或回退决策。
