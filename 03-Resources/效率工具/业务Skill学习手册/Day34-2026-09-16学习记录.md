# 2026-09-16 业务Skill学习记录（Day34）

## 学习内容
阅读《业务Skill学习手册》Day25《从标准 Skill 到产品能力：配置化、权限与商业化包装》。

核心判断：**一个业务 Skill 只有在换客户、换角色、换场景后，仍能通过配置、安全地持续产生可证明的经营结果，才开始成为产品能力。**

产品化前必须补齐五件事：
1. **配置化**：品牌策略、客群口径、权益和话术不能写死在交付代码中。
2. **权限化**：按角色、组织、数据范围和敏感动作分层授权。
3. **可观测**：调用、采纳、触达、成交、异常等过程和结果指标可追踪。
4. **可回滚**：错误配置、建议或触达能够停止、追溯和恢复。
5. **可定价**：明确客户节省的时间、提升的经营结果，以及对续费/增购的价值。

## 与当前主线的连接

智能导购 / CRM AI 解读当前不能只以“能生成建议”为完成标准。优先把导购会员跟进场景收敛为：

```text
品牌策略配置 → 权限内客户机会识别 → 导购建议 → 导购确认执行
→ CRM 结果回写 → 采纳与转化看板 → 规则迭代
```

一期仍坚持半自动边界：L1 建议生成，L2 导购确认后的单条执行；批量触达、高面额权益、跨门店动作必须保留审批、审计和回滚。

## 今日练习：智能导购 Skill 产品化准入表

| 维度 | 一期必须明确的内容 |
|---|---|
| 客户差异 | 品牌会员分层、活动目标、权益规则、话术禁用词，哪些可后台配置 |
| 权限边界 | 导购看本人客户；店长看本店；总部运营配置规则并查看汇总 |
| 结果回写 | 是否采纳、是否触达、使用的话术/权益、回复、到店、成交、未采纳原因 |
| 运营看板 | 调用量、采纳率、有效触达率、到店/成交转化、异常率 |
| 回滚机制 | 撤销待发送任务、停用规则版本、修正标签并保留纠偏记录 |
| 商业价值 | 减少导购筛客和写话术时间；提升有效触达、沉睡唤醒或复购表现 |

## 今天的一个动作

在智能导购 MVP / CRM AI 解读评审中，要求责任人把能力明确标注为“内部 Skill、交付型模板、产品化 AI 能力”三选一，并补齐上述六项。未能通过配置、权限、结果回写和价值指标四项校验的，不进入产品路线图承诺。

## 晚间复盘问题

1. 今天选定的场景，客户差异是否已能被拆成配置项，而不是依赖研发改逻辑？
2. 是否明确了一个可量化的客户价值指标，而不是只看生成内容是否自然？
3. 哪一项产品化前置能力仍缺失，导致它只能作为试点或交付工具？

## 一句话总结

> Skill 不是加到菜单里就成为产品；只有可配置、可治理、可回写、可证明价值，才值得进入产品化和商业化路径。
