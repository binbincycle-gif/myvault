# Day04｜角色视角：不同角色需要什么 Skill

## 今日主题
很多团队在设计 Skill 时，容易默认“同一个能力，写一份文档给所有人看就够了”。这在早期可能勉强能用，但一旦真正进入业务落地，就会很快发现：**品牌、门店、导购并不是同一种用户。**

他们面对的问题不同，关心的结果不同，使用的频率不同，甚至对同一条数据的理解方式都不同。所以，Skill 不能只看“底层能力是不是一样”，还要看：**最终是在帮谁做判断，帮谁做动作。**

## 一、为什么角色视角很重要
Skill 真正要解决的是“特定角色在特定场景下的问题”，而不是抽象能力展示。

比如同样是“会员洞察”能力：
- 品牌更关心会员结构变化、标签占比、高价值客群
- 门店更关心本店哪些会员值得重点跟进、哪些客户有流失风险
- 导购更关心今天该跟谁聊、推什么、怎么说

底层能力可以相同，但 Skill 的封装和表达绝不能完全一样。

## 二、品牌需要什么 Skill
品牌层的 Skill 更偏“经营判断型”。

他们更关注：
- 客群结构
- 标签洞察
- 销售趋势
- 活动效果
- 资源投入优先级

所以品牌 Skill 的价值表达应该是：
- 帮管理层看清经营结构
- 帮运营团队找到重点问题
- 帮品牌判断下一步资源该往哪投

## 三、门店需要什么 Skill
门店层的 Skill 更偏“经营管理型”。

他们更关注：
- 门店销售表现
- 重点会员
- 重点导购
- 复购与跟进情况
- 店长每天该盯什么动作

所以门店 Skill 的价值表达应该是：
- 帮店长更快发现经营异常
- 帮门店更聚焦重点会员和重点动作
- 帮店长提升日常管理效率

## 四、导购需要什么 Skill
导购层的 Skill 更偏“动作执行型”。

他们更关注：
- 今天该跟谁
- 推荐什么商品
- 跟进怎么说
- 客户最近有什么行为
- 哪些客户最有成交机会

所以导购 Skill 的价值表达应该是：
- 帮我更快找到今天最值得跟进的客户
- 帮我少想一点、多做一点
- 帮我提升跟进效率和成交概率

## 五、同一能力，为什么不能只写一份文档
因为同一个能力，在不同角色那里，关注点完全不同。

例如“销售线索能力”：
- 品牌会问：这个能力有没有拉动整体经营效率？
- 门店会问：这周门店哪些导购用得最好？
- 导购会问：我今天具体该跟谁？

如果你只写一份文档，最终就会出现两种结果：
1. 写得很泛，谁都觉得不够贴近自己
2. 价值表达失焦，无法支撑真正落地

## 六、正确的做法是什么
### 1. 底层能力统一
底层查询、分析、推荐能力尽量复用，不要重复建设。

### 2. Skill 按角色封装
同样的底层能力，可以封成品牌版、门店版、导购版 Skill。

### 3. 文档按角色表达
不同角色的 Skill 文档，要分别写清楚：
- 谁适合用
- 解决什么问题
- 输出什么价值
- 典型问题怎么问

## 七、今天最重要的认知
Skill 不是简单把数据能力暴露出来，而是把能力按角色重新包装成“可被使用的业务工具”。

所以真正成熟的 Skill 体系，不是一个大而全的技能库，而是：
- 统一能力底座
- 按角色封装 Skill
- 按角色组织文档和入口
