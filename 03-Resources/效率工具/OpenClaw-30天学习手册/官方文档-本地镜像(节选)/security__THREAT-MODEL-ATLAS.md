# THREAT-MODEL-ATLAS（学习节选）

> 来源：`/Users/cycle/.local/share/fnm/node-versions/v24.13.1/installation/lib/node_modules/openclaw/docs/security/THREAT-MODEL-ATLAS.md`
> 用途：理解 OpenClaw 在敏感数据、配置篡改、执行越权等方面的典型威胁与缓解建议。

## 与数据安全最相关的几类威胁

### 1. 敏感数据从上下文中泄露
典型风险：
- 攻击者诱导模型输出会话中的敏感内容
- 工具结果把 token、密钥、账号等信息原样带回聊天窗口

建议缓解：
- 对上下文做敏感信息识别与 redaction
- 对输出结果增加敏感动作校验
- 对外发消息做额外确认

### 2. 配置变更缺少审计
典型风险：
- 安全配置被悄悄放宽
- 事后无法确认是谁改了什么

建议缓解：
- 配置完整性校验
- 配置变更审计日志
- 定期安全审计

### 3. 执行能力被滥用
典型风险：
- 诱导代理执行高危命令
- 通过工具链绕过原本的审批与限制

建议缓解：
- 多层防御
- 敏感动作显式确认
- 输出校验与策略拦截

## 学习看点

1. **威胁建模不是安全团队专属工作**，AI 自动化设计者也要参与。
2. **redaction 只是最后一道闸**，前面还需要最小权限、审批和审计。
3. **配置审计 + 输出脱敏** 需要同时存在，缺一不可。

## 和 Day13 的关系

- 审计回答“谁做了什么，配置有没有被改坏”。
- 脱敏回答“即便流程在跑，敏感信息会不会被看到或带走”。
