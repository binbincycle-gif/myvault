# 管理层结论-动作-风险模板

## 适用场景

用于把复杂事项快速整理成管理层可读、可拍板、可转发的版本。

适合：

- 项目进展同步；
- 风险升级；
- 会议前准备；
- 日报 / 周报；
- 方案对齐；
- 老板需要快速判断下一步。

## 输入材料

使用前准备：

1. 当前事项背景；
2. 已发生的事实；
3. 影响范围；
4. 当前责任人 / 团队；
5. 需要老板拍板或关注的点。

## 提示词正文

```text
你是一个一线业务操盘手，擅长把复杂事项整理成管理层可直接判断的版本。

背景：
【粘贴事项背景】

当前事实：
【粘贴已知事实、数据、进展、问题】

请按「结论 → 动作 → 风险」输出一版管理层同步内容。

要求：
1. 结论先行，不要铺垫。
2. 动作必须具体到责任人 / 团队 / 时间点 / 交付物，信息不足则标注“需确认”。
3. 风险必须说明影响范围和是否需要升级。
4. 语气简洁、直接、可执行。
5. 不要写成教学材料，不要泛泛总结。
6. 最后给出 1-3 个下一步建议。
```

## 输出格式

```markdown
## 结论

## 动作
1.
2.
3.

## 风险
- 风险：
- 影响：
- 建议：

## 下一步建议
1.
2.
3.
```

## 使用示例

### 示例输入

```text
PVH 技术方案评审还未完全闭环，接口边界和上线风险需要确认，涉及后端、测试和项目负责人。
```

### 示例输出方向

```markdown
## 结论
PVH 当前不是单纯开发排期问题，而是技术方案闭环和上线风险确认问题，需要今天把接口边界、测试范围和上线口径一次性收齐。

## 动作
1. 后端负责人今天下班前补齐接口边界说明。
2. 测试负责人同步回归范围和高风险用例。
3. 项目负责人汇总上线窗口与回滚预案。

## 风险
- 风险：方案边界不清导致后续联调返工。
- 影响：影响上线节奏和客户侧预期。
- 建议：今天先收口评审，不要边开发边补口径。
```
