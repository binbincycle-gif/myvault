# OpenClaw Day1｜从"会聊天"到"能干活"

装了OpenClaw后，我想明白了一件事：AI助手不是更聪明的搜索引擎，而是一个能帮你干活的人。

分享一下Day1的核心认知：

## 1. 它不是回答问题，是在完成工作

- 传统AI：问一句答一句
- OpenClaw：理解目标 → 自动执行 → 返回结果
- 差别在于：后者有"手"和"脚"

## 2. 五个概念搞懂就入门

- **Session**：工作记忆，记得你之前说过啥
- **Tool**：AI的手和脚，能读文件、能发消息、能执行命令
- **Skill**：可复用的做事套路，封装好下次直接用
- **Cron**：定时自动触发，不用每天手动点
- **Logs**：黑匣子，出了问题能回溯

## 3. 第一周目标不是堆功能，是跑通闭环

- 最小闭环：发指令 → AI执行 → 拿到结果
- 剩下的就是不断重复这个链路
