## 后续建议补齐

如果作为 EZR Skills 的一个能力样例，建议补齐：

| 字段 | 说明 |
|---|---|
| skill_id | 如 `fitting_record_create` / `fitting_record_summary` |
| 使用场景 | 导购记录会员试穿、上身效果、偏好、不合适原因、未购原因 |
| 输入 | 吊牌图片、语音、文字、会员标识、导购标识、门店标识 |
| 输出 | 结构化试衣记录、未购原因、可跟进线索、会员画像补充字段 |
| 权限 | 导购仅能写入 / 查看自己门店或授权范围数据 |
| 风险 | 上下文污染、串单、导购身份识别不稳定、图片识别错误 |
| 审计 | 记录输入来源、导购、门店、商品、写入时间、修改历史 |
