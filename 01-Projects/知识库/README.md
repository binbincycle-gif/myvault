# 知识库 / 睿知库

## 项目定位

睿知库一期聚焦 **内部产品问题智能查询助手**，服务于运营团队和在线支持团队的客户咨询响应场景。

一期不是追求大而全的知识库覆盖，而是先跑通：

> 产品问题输入 → 知识库检索匹配 → AI 生成结构化答案初稿 → 一线直接使用 / 修改后使用 → 反馈准确性

## 一期核心原则

- 场景落地优先
- 真实使用优先
- 快速迭代优先
- 小范围闭环验证优先

## 一期核心能力

1. 产品知识库首批数据建设：帮助中心、技术方案入库，文档清洗、标签、结构化、维护 SOP。
2. AI 智能问答生成：自然语言问题匹配知识内容，生成结构化答案初稿，附参考来源，可直接复制。
3. 内部反馈通道：一线反馈答案准确性、补充问答、提交优化建议。
4. 基础知识维护机制：知识入库、更新、复测、责任人、频率、回滚修正机制。

## 一期边界

### 做

- 帮助中心、技术方案两类核心数据全量入库。
- 文本类产品问题智能问答，供内部一线团队参考使用。
- 内部验收流程闭环。
- 基础知识维护 SOP。

### 暂不做

- 直接面向品牌用户的开放入口 / 自助使用能力。

## 核心用户

- 内部 CSM 团队：郭青、杨菲菲。
- 在线支持团队。
- 一期不包含品牌侧用户。

## 关键验收标准

| 验收项 | 通过标准 | 责任人 |
|---|---|---|
| 核心链路可用性 | 从问题输入到答案生成无阻塞性 Bug，通过率 100% | 爱洋 |

1. **问答入口延期风险**：前一周已出现技术紧急需求插队，5 月 17 日节点需重点盯。
2. **数据清洗质量风险**：虽然已入库，但数据清洗结果待优化，直接影响问答准确率。
3. **查重未全量完成**：目前仅完成 50 篇文章查重，全量查重仍未完成。
4. **真实使用尚未开始**：后台和入库完成不等于业务闭环，关键是 CSM / 在线支持是否愿意持续使用。
5. **运营方案库与产品知识库双线并行**：容易分散资源，需要明确主次和阶段验收。
