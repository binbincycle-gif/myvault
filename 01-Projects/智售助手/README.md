# 智售助手

## 项目定位

围绕品牌私域经营场景，探索以 AI 能力驱动线索识别、导购跟进和转化提升的新型经营模式，推动 AI 能力在品牌侧实现真实使用和业务落地。

一句话：

> 智售助手一期不是验证“功能有没有”，而是验证“重点品牌中导购能不能稳定使用，并形成真实跟进和转化案例”。

## 一期目标

**7 月底前**，聚焦导购销售线索能力推广与落地：

- 支持 2-4 个重点品牌形成稳定使用。
- 输出 1-2 个可对外宣导的标杆案例。
- 收集卡点，沉淀高价值需求，为 2.0 做储备。

## 目标对象

- 品牌总部运营团队：决定试点是否推进、门店如何组织。
- 一线导购团队：决定销售线索能力是否真实使用、是否产生跟进和转化。

## 核心指标

### 主指标

导购活跃占比：每周跟进 5 个线索以上的导购数占比。

- 达标线：≥40%
- 良好线：≥50%
- 标杆线：≥60%

### 辅指标

- 重点门店覆盖数 / 占比 / 增长提升
- 转化商机数 / 金额占比 / 提升
- 试点门店运营 / 业绩提升
- 周使用次数
- 生成商机数 / 跟进商机数 / 转化商机数

## 重点品牌与线索

当前提到的品牌：

- 卡尔丹顿
- 固执
- 舜华鸭业
- 莱尔斯丹
- 兰卓丽
- 天创
- 奥康
- 卓诗尼

筛选维度：品牌配合度、客单价、消费频次、落地适配性、共创诉求、预期线索转化价值。

## 当前状态

**关注。**

截至 2026-05-10 周报，项目进入真实品牌试点验证阶段，主要卡点集中在：

1. 兰卓丽：商品推荐精准性仍需优化。
2. 固执：生日、优惠券、浏览行为相关话术需要更成交导向。
3. 舜华鸭业：零食品类提示词 / 技能适配延期。
4. 奥康、卓诗尼：内部平台测试中品类、性别不准确，需要统一测试方法。

- [ ] 固执生日 / 优惠券话术优化方案，预计周二前。
- [ ] 天创试点门店确认及培训。
- [ ] 固执线下门店培训。
- [ ] 单品牌周数据输出。
- [ ] 建立商品推荐初步准确性测试方法。

## 风险与阻塞

- 推荐准确性不稳定，影响导购信任。
- 话术偏通用关怀，缺少成交场景触发，例如生日、券、浏览商品后的利益点表达。
- 零食品类适配尚未跑通，可能影响舜华鸭业白测节奏。
- 内部测试效果与客户实际使用效果之间缺少统一判断标准。
