# 导购小龙虾一期项目目标与里程碑

## 项目愿景

导购小龙虾长期不是只做一个试衣记录工具，而是围绕导购工作场景，持续沉淀高价值业务数据、经验和动作，并进一步演进为导购数字员工体系中的重要角色。

## 一期目标

一期聚焦线下试衣场景，围绕：

- 试衣记录
- 高销导购判断
- 未购原因
- 会员偏好
- 相关高价值信息补录与结构化沉淀

验证一套 **轻量化、可执行、可持续的数据采集与沉淀机制** 是否成立。

## 当前要解决的核心问题

1. 线下试衣场景中，试穿相关高价值数据沉淀不足，尤其是上身效果、导购判断、会员偏好、不合适原因、未购原因等信息缺失。
2. 一线导购掌握大量一手信息，但缺少低成本、可执行、可持续的记录与补录机制。
3. 缺少结构化试衣数据，后续导购跟进、销售线索识别、高销经验沉淀和智能分析缺少可靠基础。

## 目标用户与受益角色

- 直接使用者：门店一线高销导购。
- 一期核心样本对象：高销导购。
- 直接受益角色：店长、运营、CRM / 会员运营团队。
- 一期试点对象：优先选择对试衣数据沉淀、导购跟进、后续会员运营有明确诉求的品牌门店，例如 UND、江南布衣。

## 一期希望达成的结果

1. 在试衣场景中建立导购可执行的数据补录与沉淀机制。
2. 通过拍吊牌、语音输入等轻量方式沉淀试衣数据。
3. 验证高销导购样本对该流程的实际使用情况，确认业务现场是否具备落地性和推广性。
4. 初步建立围绕试衣数据的基础分析与效果衡量能力。
5. 形成结构化、可追踪、可分析的试衣数据，为销售线索识别、导购跟进和经验沉淀提供数据基础。

## 一期边界与原则

- 不做完整会员管理。
- 不做完整导购督导。
- 先抓住“试衣但未购”这个关键数据空白。
- 会员信息若可识别则接入，暂未识别也不影响一期闭环成立。
- 轻量化优先，不走重硬件路线，不把全程录音分析作为主方案。
- 当前优先以飞书等熟悉聊天工具作为验证入口，但不把某一种承载方式固化为长期唯一形态。
- 不追求一开始做成大而全产品。

## 衡量指标

| 指标类别 | 重点指标 |
|---|---|
| 试点覆盖 | 试点品牌数、试点门店数、高销导购样本数、实际参与导购数 |
| 过程执行 | 试衣记录数、关键字段完整率 |
| 数据沉淀 | 结构化字段覆盖率、高质量试衣数据沉淀量 |
| 业务产出 | 试衣数据结构化分析、试衣未购原因分析、可跟进线索产出数 |
| 使用效率 | 单次补录耗时、导购使用频次、试点期连续使用天数 |
| 试点反馈 | 导购接受度、门店反馈、业务方对后续价值的认可度 |

## 目标完成判定标准

满足以下条件，可视为一期目标基本达成：

1. 已在试点门店中跑通“轻量化连接导购 + 数据结构化沉淀”的核心流程。
2. 高销导购样本能够在关键业务节点完成试衣数据补录，且关键字段完整率达到预设要求。
3. 已稳定沉淀出可用于后续跟进、分析和经验复用的高质量试衣数据与部分高销导购语料。
4. 能够输出高意向会员或可跟进线索等阶段性业务结果。
5. 试点业务方认可该机制对后续导购跟进、会员理解和数据沉淀具有实际价值。

## 前期飞书端试验结论

已基于飞书聊天场景做过一轮前期试验，尝试以“导购通过飞书发送图片、语音、文字，由导购小龙虾承接试衣补录”的方式验证最小交互链路。

当前已完成导购小龙虾试衣 agent 1.0 基础能力搭建，可初步承接：

- 吊牌识别
- 语音内容提取
- 试衣信息理解
- 结构化写入

轻量化入口方向具备现实可行性。

## 关键风险：上下文污染与串单

纯聊天式输入直接写入时，容易出现：

- 单张吊牌图片被过早识别并写成正式记录。
- 当前商品信息被历史上下文覆盖。
- 上一件商品试穿反馈串入下一件商品。
- 商品级上下文隔离与正式写入时机难以稳定控制。

## 当前方案原则

聊天输入不再直接等同于正式记录，而是：

> 图片 / 语音 / 文本输入 → 草稿态 → 商品或试衣轮次归并 → 结构化确认 / 卡片补录 → 正式写入

核心动作：

- 输入先进草稿态，不直接生成正式记录。
- 以商品或试衣轮次为单位做输入归并。
- 关键节点增加结构化确认或卡片补录。
- 保留飞书轻量化承载优势，同时提升数据准确性、上下文隔离能力和复用性。
