# 知识库总索引

## 一、使用说明
这个索引用于快速定位知识库内容，避免直接在整个 Vault 里盲搜。
对话检索时，优先先看这页，再按问题类型进入对应目录。

## 二、按问题类型检索
### 1. 战略 / 组织 / AI方向
入口：[[02-Areas/AI战略规划/README]]
主目录：`02-Areas/AI战略规划/`

### 2. 当前项目推进 / 方案 / 复盘
入口：`01-Projects/`
适用：具体项目方案、项目复盘、项目执行文档

### 3. 工具学习 / OpenClaw / 效率方法
入口：`03-Resources/效率工具/`
适用：OpenClaw 学习手册、Obsidian、自动化工作流

### 4. 每日复盘 / 个人感悟 / 最近上下文
入口：`02-Areas/个人成长/每日日记/2026/`
适用：日记、反思、当日关键事件

### 5. 外部资料 / 剪藏 / 行业文章
入口：`Clippings/`、`03-Resources/`
适用：行业信息、外部文章、读书摘录
